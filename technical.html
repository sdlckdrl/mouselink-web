데이터 처리와 필요한 권한을 안내합니다. 사용법은 사용 가이드를 보세요.

로컬 우선 권한 사용 데이터 처리 네트워크 조건 지원 범위 업데이트 내역

Local First

연결된 기기끼리 데이터를 직접 주고받습니다.

마우스·키보드 입력, 파일, 클립보드는 연결된 기기 사이에서 직접 오갑니다. LAN 연결은 같은 로컬 네트워크(유선 또는 Wi-Fi)를 사용합니다. Google 계정 연결은 기기 목록과 연결 신호에 계정 서버를 사용하지만, 입력이나 파일을 서버에 올리는 방식은 아닙니다.

Permissions

권한은 기능 제공에 필요한 범위로만.

Android는 버전에 따라 앱을 열 때 일부 권한을 요청합니다. 접근성과 화면 캡처 등은 아래에서 기능별로 확인할 수 있습니다.

필수

접근성 서비스

PC의 마우스·키보드로 Android를 제어하고, 원격 입력·화면 관련 동작을 처리하려면 접근성 서비스가 필요합니다. OneMouse의 핵심 기능이 여기에 의존합니다.

원격 제어 시작 시

화면 캡처 승인

모바일 원격 제어 창을 열 때 Android 시스템 팝업으로 승인합니다. 보안 화면 등 일부는 표시되지 않을 수 있습니다.

권한을 요청하는 시점

주변 Wi-Fi 기기

Android 13 이상에서 권한이 꺼져 있으면 앱을 처음 열 때 ‘주변 Wi-Fi 기기’와 알림 권한을 요청할 수 있습니다. Bluetooth를 켤 때 Android 12 이상에서 묻는 ‘주변 기기’ 권한은 별도입니다.

서비스 시작 시

알림

백그라운드 연결 상태를 표시하는 데 씁니다. 필요할 때만 요청됩니다.

밝기 사용 시

시스템 설정 변경

Alt+Shift+↑/↓로 모바일 화면 밝기를 조절할 때 처음 한 번 필요합니다.

권장

배터리 제한 예외

화면이 꺼진 뒤 연결이 끊긴다면 안정성을 위해 권장합니다. 필수는 아닙니다.

Mac 연결·입력 · 공개 지원

손쉬운 사용·로컬 네트워크

Windows 입력을 적용하려면 손쉬운 사용이 필요합니다. 로컬 네트워크 권한은 macOS 15+에서 기기 검색에 사용되며, macOS 13/14에서는 표시되지 않을 수 있습니다.

Mac 화면 공유 시

화면 녹화

Windows에서 Mac 화면이나 창을 볼 때만 필요합니다. 기본 입력과 파일·클립보드 전송에는 요구하지 않습니다.

Mac 페어링 정보

Keychain

서명된 배포 앱은 페어링 세션 키를 macOS Keychain에 보관합니다. 페어링을 해제하면 해당 연결 정보를 삭제할 수 있습니다.

Data Handling

데이터 처리 원칙

  • LAN·Bluetooth 페어링은 로그인 없이 동작합니다. 선택 Google 계정 연결은 기기 목록과 연결 신호에 계정 서버를 사용합니다. 계정 정보 처리 안내를 확인하세요.
  • 전송한 파일을 서버에 저장하지 않습니다. 선택한 기기로 직접 보냅니다.
  • 접근성 데이터를 광고나 화면 수집 용도로 사용하지 않습니다. 입력 전달·원격 제어 등 명시된 기능에만 씁니다.
  • 파일은 보낼 기기를 선택하거나 드래그로 전송합니다. 클립보드 공유가 활성화된 연결에서는 텍스트를 복사할 때마다 전송 대상을 다시 선택할 필요가 없습니다.
  • Mac 화면·창 공유 데이터는 사용자가 시작한 로컬 세션에서 Windows로 직접 전송되며 운영 서버에 저장하지 않습니다.

Network

네트워크 조건

권장 환경

  • 개인 공유기의 같은 Wi-Fi(2.4/5GHz 무관)
  • 기기 간 통신이 허용된 네트워크
  • Windows 방화벽에서 OneMouse 인바운드 허용

제약 환경

  • 게스트·회사 Wi-Fi의 기기 간 격리(client isolation)
  • ‘공용’으로 잡힌 네트워크의 인바운드 차단
  • 이럴 땐 블루투스 직접 연결 또는 개인 핫스팟 이용

두 기기가 서로 직접 통신할 수 있어야 합니다.

Support Scope

지원 플랫폼과 연결 방식

  • Windows 10·11 (x64): 다른 Windows PC, Android, Mac과 연결할 수 있습니다.
  • Android 8.0 이상: 폰·태블릿에서 Windows의 마우스·키보드 입력을 받을 수 있습니다. Android에서 Windows 원격 화면을 여는 기능은 별도입니다.
  • Apple Silicon Mac · macOS 13 이상: Windows와 LAN 또는 Google 계정으로 연결하거나 Bluetooth(베타)를 사용할 수 있습니다. Mac에서 Windows로 마우스·키보드를 보내는 Bluetooth 설정도 지원합니다.
  • Bluetooth는 지원 조합에서 Wi-Fi나 Google 로그인 없이 쓸 수 있는 베타입니다. 원격 화면 영상은 Bluetooth로 전송하지 않습니다. Windows에서 Mac 화면·창을 보려면 같은 로컬 네트워크와 Mac의 화면 녹화 권한이 필요합니다.
  • USB/ADB 연결은 공식 지원 범위가 아닙니다.
