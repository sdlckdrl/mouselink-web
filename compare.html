Windows·Mac·Android에서 쓸 마우스·키보드 공유 도구를 비교했어요.

Windows에서 Android·Mac·PC까지

OneMouse는 Windows PC의 커서를 화면 끝으로 밀어 Android 폰·태블릿, 다른 Windows PC 또는 Mac의 실제 화면에서 조작할 수 있어요. Mac은 Apple Silicon과 macOS 13 이상이 필요해요.

  • 같은 네트워크: QR 또는 인증번호로 로그인 없이 페어링
  • 가까운 Windows → Android: 공유기 없이 Bluetooth 연결(베타)
  • 지원되는 연결: 복사한 텍스트와 파일도 공유

연결 전 확인

실제 화면 조작과 미러링은 어떻게 달라요?

실제 화면 조작은 기기의 화면을 직접 보며 쓰는 방식이고, 미러링은 컴퓨터에 띄운 창을 보며 조작하는 방식이에요.

OneMouse는 Google 로그인이 필요한가요?

같은 네트워크에서 QR이나 인증번호로 페어링하거나 호환 기기를 Bluetooth로 연결할 때는 Google 로그인이 필요 없어요.
