OneMouse 연결 가이드 시안

어떤 기기를 연결할까요?

마우스와 키보드가 연결된 Windows PC에서 시작해요. 제어할 기기를 골라 같은 공유기에서 연결하거나, Google 계정으로 내 기기 찾기를 확인하세요.

Android 폰·태블릿 연결하기

QR 또는 6자리 번호, 둘 중 하나만 쓰면 돼요. PC가 유선이어도 같은 공유기에 연결돼 있으면 됩니다. Google 로그인은 필요 없어요. Google 계정으로 연결하려면

  1. 양쪽에서 OneMouse 열기

    Windows와 Android에 OneMouse를 설치하고, 같은 공유기에 연결해요. Android에서 설정 → 접근성 → 설치된 앱 → OneMouse를 켜세요. 기기에 따라 메뉴 이름이 다를 수 있어요.

  2. Windows에서 QR·인증번호 열기

    기기 관리 → 다른 방법으로 연결 → 이 PC의 QR·인증번호를 누르세요.

  3. Android에서 번호 입력 또는 QR 스캔

    홈 → 다른 방법으로 연결 → QR·인증번호로 PC 추가를 누르세요. 숫자 코드에서 번호를 입력하거나, QR 코드 스캔 → 카메라 실행으로 PC 화면을 스캔하세요.

  4. 기기 위치를 맞추고 마우스 넘기기

    Android 홈의 등록된 PC에서 연결을 확인하세요. Windows에서 폰·태블릿을 실제 놓인 방향으로 배치하고, 그쪽 가장자리의 진입 통로로 마우스를 밀어 보세요.

연결됐는데 커서가 안 넘어가나요? Android 접근성이 켜졌는지, 배치 방향과 진입 통로가 맞는지 확인해요. 문제 해결 보기
다른 연결 방법: Bluetooth

Bluetooth로 연결

두 기기의 Bluetooth를 켜고 Android의 OneMouse 설정에서 Bluetooth 모드를 켜세요. Windows Bluetooth 설정에서 폰을 페어링한 뒤 OneMouse 기기 목록의 연결 상태와 배치를 확인해요. 원격 동영상은 Bluetooth로 전송되지 않아요.

Windows에서 Mac 연결하기

Apple Silicon Mac과 macOS 13 이상이 필요해요. 두 기기를 같은 공유기의 Wi-Fi 또는 LAN에 연결하면 로그인 없이 사용할 수 있어요. Google 계정으로 Mac 연결하기

  1. Windows와 Mac에서 앱 열기

    OneMouse를 설치하고 두 기기에서 실행하세요. 연결은 Windows에서 시작해요.

  2. Mac에서 손쉬운 사용 허용

    입력을 받으려면 손쉬운 사용을 허용하세요. macOS 15 이상에서 기기 검색을 위한 로컬 네트워크 항목이 뜨면 함께 허용하세요.

  3. Mac을 고르고 6자리 코드 입력

    Windows OneMouse의 기기 관리에서 Mac을 선택하고, Mac 화면에 나온 6자리 코드를 입력하세요.

  4. Mac 방향으로 마우스 넘기기

    Windows의 배치 화면에서 Mac을 실제 놓인 방향에 배치하고, 그쪽 가장자리로 마우스를 밀어 보세요.

Mac이 목록에 안 뜨나요? 같은 네트워크인지 확인하고, macOS에서 요청한 로컬 네트워크 권한을 확인해요. Mac 문제 해결
화면 녹화 권한도 켜야 하나요?

기본 마우스·키보드 입력에는 필요하지 않아요. Windows에서 Mac 화면이나 창을 보는 기능을 사용할 때만 허용하세요. 공식 Mac 가이드

다른 Windows PC 연결하기

마우스·키보드가 꽂힌 PC에서 시작해요. 같은 공유기에 연결하면 로그인 없이 번호로 연결할 수 있어요. Google 계정으로 다른 PC 연결하기

  1. 두 PC에서 앱 열기

    양쪽 Windows에 OneMouse를 설치하고 실행해요. 두 PC가 같은 공유기의 Wi-Fi 또는 LAN을 쓰는지 확인하세요.

  2. 상대 PC에서 번호 확인

    제어할 PC에서 기기 관리 → 다른 방법으로 연결 → 이 PC의 QR·인증번호로 가서 6자리 번호를 확인하세요.

  3. 내 PC에서 상대 PC 선택·연결

    내 PC의 기기 관리 → 다른 방법으로 연결에서 상대 PC를 선택하고 코드를 넣으세요. 연결 상태를 확인하고 필요하면 연결 스위치를 켜세요.

  4. 다른 PC 방향으로 마우스 넘기기

    배치 편집기에서 상대 PC를 실제 놓인 위치에 두고, 그쪽 가장자리로 마우스를 밀어 보세요.

상대 PC가 보이지 않나요? 두 앱이 켜져 있고 같은 네트워크인지 먼저 확인하세요. 연결 문제 해결 보기

Google 계정으로 내 기기 찾기

Windows, Mac, Android의 OneMouse 앱에서 사용할 수 있어요. 양쪽 앱을 최신 버전으로 업데이트하고, 인터넷에 연결한 뒤 같은 Google 계정으로 로그인하세요.

Windows ↔ Windows

두 PC의 기기 관리에서 로그인하세요. 마우스가 연결된 PC에서 상대 PC를 고르고, 필요하면 연결 스위치를 켜세요.

Windows → Mac

Windows의 기기 관리와 Mac 앱의 기기 화면에서 로그인하세요. Windows 기기 목록에서 Mac을 골라 연결하세요. Mac에서 입력을 받으려면 손쉬운 사용을 허용하세요.

Windows → Android

Windows의 기기 관리와 Android의 OneMouse 홈에서 로그인하세요. 폰의 등록된 PC에서 내 PC를 선택해 연결하고, Android의 접근성을 켜세요.

허용 요청이 나오면 상대 기기에서 확인하세요. 로그인은 기기를 찾는 방법이에요. 실제 연결 가능 여부와 쓸 수 있는 기능은 네트워크와 기기에 따라 달라요. 기기가 안 보일 때
