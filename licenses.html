오픈소스 라이선스

OneMouse에 포함되는 오픈소스 구성요소의 라이선스와 저작권 고지입니다. 라이선스·NOTICE 원문과 해당 소스를 아래에서 확인할 수 있습니다.

최종 업데이트: 2026년 11월 5일

이 목록은 Windows MSIX 1.6.2.0, Android 1.2.43(79)의 Play·Galaxy 빌드, macOS 1.6.0의 확인된 구성요소를 기준으로 합니다. 스토어 업데이트 제공 시점은 각 스토어의 심사·공개 상태에 따라 다르며, 이전 앱 버전의 구성요소는 다를 수 있습니다.

소스 제공과 라이브러리 재구성

LazySodium Android 5.2.0의 대응 소스를 제공합니다. 원본 소스와 라이선스는 아래 자료에 포함되며, OneMouse에서 이 라이브러리의 소스는 수정하지 않았습니다.

대응 소스 — LazySodium Android 5.2.0

LazySodium Android 5.2.0 — published sources JAR

아래 Windows 버전에 포함된 zeroconf 0.151.3의 대응 소스와 재구성 자료를 제공합니다. 재구성 도구는 배포본의 컴파일된 애플리케이션 코드를 유지하면서 수정한 zeroconf 소스로 별도의 실행 파일을 만듭니다. 원본 앱을 직접 덮어쓰지 않으며, 실행 파일 안에 묶인 모듈이 자동으로 교체된다고 가정하지 않습니다.

해당 오픈소스 라이선스가 허용하는 라이브러리 수정·재구성과 그 변경을 디버깅하기 위한 역공학을 제한하지 않습니다. 재구성 결과물은 Microsoft Store 서명이 없는 별도 파일입니다. 세부 절차와 확인 범위는 안내 문서를 참고하세요.

다른 배포 버전의 대응 소스나 자료가 필요하거나 다운로드가 동작하지 않으면 앱 버전을 적어 문의해 주세요. sdlckdrl@gmail.com

빌드·테스트 도구

PyInstaller 6.22.2(GPLv2-or-later 및 부트로더 예외), Electron Builder 26.18.1(MIT), Android Gradle Plugin·Gradle·Kotlin Gradle Plugin과 테스트 도구는 앱 실행 구성요소와 구분합니다. PyInstaller 부트로더의 실제 예외 문구도 함께 제공합니다.
