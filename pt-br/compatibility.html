Compatibilidade com OneMouse

Como faço para conectar meus dispositivos?

Use o mouse e teclado do Windows em outro dispositivo. Escolha um dispositivo para configuração de rede local, descoberta de conta do Google ou Bluetooth (beta).

Que ligação devo escolher?

Se você pode usar o mesmo roteador Conecte-se através de Wi-Fi ou LAN com fio. Emparelhar com um código QR ou um código numérico não requer o login do Google.

Para encontrar seus dispositivos sem um código Faça login em ambos os aplicativos com a mesma conta do Google. Isso requer acesso à internet. A conta ajuda a encontrar dispositivos e iniciar uma conexão; recursos como visualização remota dependem da rede e dispositivos.

Para conectar dispositivos próximos sem roteador Todas as conexões Bluetooth estão em beta. Você pode conectar PCs Windows uns aos outros, conectar Windows ao Android, ou conectar Windows e Mac um-para-um. Para enviar a entrada do Mac para Windows, consulte o Guia Mac Bluetooth (beta). Bluetooth beta não carrega vídeo remoto. Use a mesma rede local (LAN ou Wi-Fi conectados), ou uma conexão de conta do Google onde suportado.

O controle remoto exibe a tela do outro dispositivo. É diferente de mover seu cursor para um dispositivo próximo. Controle o Windows remotamente a partir do Android · Ver tela de um dispositivo conectado a partir do Windows
