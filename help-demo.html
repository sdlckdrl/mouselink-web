어디에서 막혔나요?

지금 겪는 증상을 고르세요. 로그인이나 기기 등록을 다시 하기 전에, 바로 확인할 수 있는 것부터 안내해요.

커서가 내 PC로 안 돌아오나요?

Windows에서 Ctrl + Alt + Backspace를 눌러 보세요. 기본 복귀 키예요. 꺼뒀다면 마우스를 연결한 화면의 반대쪽 경계로 밀어 돌아오세요. 복귀 조건 확인

기기가 안 보여요

  1. 양쪽에서 OneMouse를 열어 주세요.
  2. QR·번호 연결이면 같은 공유기에 연결했는지 확인하세요. PC는 유선이어도 같은 공유기면 됩니다.
  3. Google 계정 연결이면 같은 계정과 인터넷 연결을 확인하고 기기 목록을 새로고침하세요.
Mac·Bluetooth·공용 Wi-Fi라면

Mac의 로컬 네트워크 권한은 해당 설정 항목이 있을 때 확인하세요. Bluetooth 연결은 양쪽 설정에서 켜짐과 연결 상태를 확인하세요. 회사나 게스트 Wi-Fi는 같은 이름의 네트워크여도 기기끼리 통신을 막을 수 있어요.

연결됐는데 커서가 안 넘어가요

  1. Android라면 설정 → 접근성 → 설치된 앱에서 OneMouse가 켜졌는지 보세요.
  2. Windows의 기기 배치가 책상 위 실제 방향과 같은지 확인하세요.
  3. 같은 방향이어도 화면 전체가 통로는 아니에요. 배치에 표시된 진입 통로로 마우스를 밀어 보세요.
Mac도 연결됐는데 클릭이 안 된다면

Mac에서 OneMouse의 손쉬운 사용 권한을 확인하세요. 방금 허용했다면 Mac 앱을 종료하고 다시 열어 보세요.

연결이 자주 끊겨요

  1. 화면이 꺼질 때만 끊긴다면 Android의 배터리·절전 설정을 확인하세요.
  2. 집에서는 되지만 다른 장소에서만 끊긴다면 게스트·회사 Wi-Fi의 기기 간 통신 제한 여부를 확인하세요.
  3. Bluetooth로 연결했다면 양쪽에서 연결 상태부터 확인하세요.

파일·복사·캡처가 안 돼요

  1. 양쪽 앱이 연결됐고, 받는 기기를 맞게 골랐는지 확인하세요.
  2. 파일을 화면 너머로 보내려면 연결한 기기를 배치한 뒤, 파일을 든 채 경계를 넘어 받는 화면 위에서 놓으세요.
  3. 캡처를 받았다면 이미지 붙여넣기를 지원하는 앱을 열어 붙여넣으세요.
수신 폴더와 캡처 사용 조건

전송 방법과 지원 기기는 앱 버전·연결 방식에 따라 달라요. 캡처는 붙여넣는 이미지와 파일로 저장하는 작업이 서로 달라요.

원격 화면이 안 되거나 검어요

  1. 화면은 나오는데 폰에서 PC를 조작할 수 없다면 보기 전용이 꺼졌는지 확인하세요.
  2. PC에서 Android 화면을 열 때는 폰에 뜨는 화면 캡처 승인을 확인하세요.
  3. PC에서 Mac 화면이 검다면 Mac의 화면 녹화 권한을 확인하세요.

폰 알림이 안 보여요

  1. Android 설정에서 OneMouse의 알림 접근 권한을 확인하세요.
  2. 폰 쪽 OneMouse에서 PC로 알림 보내기, PC에서는 기기 알림 표시를 확인하세요.
  3. 알림을 보낼 앱 목록에 원하는 앱이 들어 있는지 확인하세요.
