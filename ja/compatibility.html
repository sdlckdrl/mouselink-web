OneMouse の対応範囲

機器をどう接続しますか？

Windows PC のマウスとキーボードを別の機器で使うための案内です。機器を選び、同じネットワーク、Google アカウントでの機器検索、Bluetooth（ベータ）の手順を確認してください。

機器別の接続ガイド

Windows ↔ Windows

必要なバージョン
Windows 10 または 11
権限
Windows ファイアウォールの確認が表示されたら、OneMouse を許可します。
同じネットワークGoogle アカウントBluetooth（ベータ）

Windows → Android

対象機器
Android スマートフォン・タブレット
権限
Android で OneMouse のユーザー補助サービスを有効にします。
同じネットワークGoogle アカウントBluetooth（ベータ）

Windows → Mac

必要なバージョン
Apple Silicon、macOS 13 以降
権限
Mac でアクセシビリティを許可します。macOS 15 以降ではローカルネットワークの許可も確認してください。
同じネットワークGoogle アカウントBluetooth（ベータ）

どの方法を選べばよいですか？

同じルーターを使える場合 Wi-Fi や有線 LAN で接続します。QR コードや認証番号での接続には Google ログインは不要です。

QR コードや認証番号なしで機器を探す場合 両方のアプリで同じ Google アカウントにログインします。インターネット接続が必要です。アカウントは機器の検索と接続開始に使い、遠隔表示などの機能はネットワークと機器によって異なります。

ルーターなしで近くの機器をつなぐ場合Bluetooth 接続はすべてベータ版です。Windows 同士や Windows と Android を接続できます。Windows と Mac の接続は 1 対 1 です。Mac の入力で Windows を操作するには Mac の Bluetooth ガイド（ベータ）を参照してください。遠隔映像を見る場合は Wi-Fi または LAN で接続します。

遠隔操作は相手の画面を表示して操作する機能です。隣の機器にカーソルを移す機能とは異なります。 Android から Windows を遠隔操作 · Windows で接続先の画面を見る
