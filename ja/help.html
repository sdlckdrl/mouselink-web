ヘルプ

うまくいかないときは、段階で絞り込みましょう。

アプリの起動 → 検出 → ファイアウォール → ペアリング → 入力の順で確認してください。

下の復帰キーは既定値です。PCの設定 → ショートカットで変更した場合は保存したキーを使ってください。メインPCの全ショートカットまたは緊急復帰がオフなら、画面の境界から戻ってください。 ショートカットと適用条件を見る

まずはこの3つ

  • カーソルを見失ったとき → Ctrl+Alt+Backspaceを押すと、カーソルが自分のPC（モニターの中央）に戻ります。
  • 接続はできたのに入力できないとき → Androidのアクセシビリティサービスがオフになったか、再起動された可能性があります。アクセシビリティでOneMouseを再度オンにしてください。
  • Macで入力できないとき → 入力権限を確認

トラブル解決の手順

この順番で一段階ずつ確認してください。

1

起動と権限

両方のアプリが起動しているか確認します。入力権限は最初の確認項目をご覧ください。

2

同じネットワーク・検出

WindowsとAndroidまたはMacが同じWi-Fi/LANにあるか確認します。検索できない場合は、ネットワークが違うか、ローカル通信がブロックされています。

3

ファイアウォール・分離

スマホからはPCが見えるのにPCからスマホが見えない場合は、Windowsファイアウォールの受信（インバウンド）（ネットワークが「パブリック」か「プライベート」か）の問題かもしれません。会社やカフェのWi-Fiはクライアント分離でブロックされることもあります。

4

ペアリング・接続

デバイス管理でペアリング・接続状態を確認します。初回は接続ガイドをご覧ください。

5

入力・復帰

カーソルが画面の端を越えない場合は配置を確認します。見失ったら復帰方法をご覧ください。

送信

ファイルとクリップボードがうまくいかないとき。

  • 選択中のデバイスが合っているか確認 — 送信は選択した相手に送られます。
  • Windows PC間またはWindowsとMacのドラッグには、対象のPC・Macが接続・配置されている必要があります。Macの境界ドラッグはLAN接続を使用します。
  • ファイルをつかんだまま配置した画面の境界を越えて、相手の上で放すと送信が始まります。
  • クリップボードが渡ってこない場合は、両方のアプリが接続状態か、画面がオフで待機状態になっていないか確認します。
  • BluetoothはWi-Fiより遅いです — 大きなファイルはWi-Fiで送ってください。

スマホの通知

スマホの通知がPCに表示されないとき。

  • スマホアプリの設定PCに送る通知でPCに通知を送るをオンにし、通知へのアクセスが許可済みになっているか確認します。
  • PCに送るアプリにそのアプリが入っているか確認します。初期値はSMSアプリとKakaoTalkで、すべてのアプリを選ぶこともできます。
  • メインPCの設定 → 通知で、デバイスの通知を表示がオンになっているか確認します。
  • 認証コードのメッセージだけが「非表示」で届く場合は、Android 15以降の保護機能です。スマホアプリの認証コードの通知ブロックでPCを登録を一度押してください。Bluetoothは登録時だけオンにすれば大丈夫です。
通知履歴の保存・削除

通知は短く表示し、履歴はPC内に暗号化保存します（サーバー送信なし）。有効にした後の通知だけを記録し、認証コード・非表示の機密内容は保存しません。

履歴は初期値オン・7日・最大200件です。メインPCの設定 → 通知で1日・7日・30日または新規保存オフを選べます。既存履歴は残り、全削除で消去できます。

Macのトラブル

公開中のmacOS 13以降版で確認する項目です。

Apple Silicon Mac向け公開版をインストールし、LAN接続をWindowsから開始・管理します。MacのBluetooth接続はベータ版として提供されます（Macアプリの設定でオン）。公式サポートはLANです。

WindowsにMacが表示されない

  • WindowsとMacを同じWi-Fi/LANにつなぎます。
  • macOS 15以降ではOneMouseのローカルネットワークを許可します。macOS 13/14ではこの項目がない場合があります。
  • 両方のOneMouseを再起動し、Windowsのデバイス一覧を更新します。
  • ゲストWi-Fiや社内Wi-Fiのクライアント分離も確認します。

接続済みでも入力・画面が動かない

  • 入力できない場合は、Macのアクセシビリティ許可を確認し、変更後にOneMouseへ戻ります。
  • Mac画面が表示されない場合だけ画面収録を許可します。通常の入力には不要です。
  • Macのペアリング・配置手順を見る
  • カーソルが移らない場合は、Windowsの配置エディタでMacの位置を確認します。

よくある質問

最もよく起こる問題。

返信ボタンが表示されない、または送信できません。

PC・Androidの返信対応版と、自由入力で返信できるスマホの元の通知が必要です。メインPCのリアルタイム通知のみが対象で、内容非表示・機密通知・認証コード・履歴は除外します。

送信エラー時はスマホのロック・通知の削除/期限切れ・接続を確認してください。失敗・タイムアウトは自動再送せず、スマホの会話で確認します。「スマホのアプリに渡しました」は元のアプリへの操作転送で、相手の受信確認ではありません。返信の使い方を見る

番号を変えたいのに、順序の編集が見つかりません。

メインPCのデバイス管理にLANデバイスが2台以上あると、順序を編集できます。自動保存され、接続・リモートウィンドウの番号だけが変わり、画面配置・キーの組み合わせは維持します。Bluetoothの順序は変わらず、サブ役割のPCでは編集できません。デバイスの順序を変更する

Windowsのリモートウィンドウでブラウザーのジェスチャーが使えません。

Windows版OneMouse 1.5.4以降で、接続先ブラウザーのジェスチャー拡張・機能を有効にしてください。右ボタンのドラッグを転送し、スマホの直接操作用Android独自ジェスチャーとは別です。

複数デバイスのウィンドウを同時に開けます。同じショートカット番号を再入力すると、そのウィンドウを前面に表示します。リモートウィンドウの使い方を見る

スマホで共有したファイルがPCに届きません。

Wi-Fi・LANではスマホのホームでメイン役割のPCを既定に選び、ペアリング・接続を確認してください（サブPCは対象外）。Bluetooth接続済みなら、既定のPCを選ばず送れます。スマホからPCへ送る

PCの受信フォルダーを変更・開くことができません。

メイン・サブPCの設定 → 一般 → ファイル転送 → 受信ファイルの保存先で変更・開くを選びます。エラー時は書き込み権限・USB/ネットワーク接続を確認するか、別の使えるフォルダーを選んでください。既存ファイルは移動せず、スクリーンショットの保存先は別です。受信フォルダーの設定を見る

撮影後にカーソルが戻らない、またはプレビューが閉じます。

両側の対応版ではカーソルは操作中のデバイスに残り、メイン画面のトレイ・最小化状態を保って別のプレビューだけを表示します。コピー・保存の成功時に閉じ、保存のキャンセル・失敗時は残ります。使うときはカーソルを自分でメインPCへ戻してください。撮影結果の使い方を見る

マウスジェスチャーが始まりません。

PC・Androidの対応版で、Android設定 → 入力・クリップボードのマウスジェスチャーをオンにし、現在のアプリを選びます（初期値はオフ）。カーソルをスマホへ移し、右ボタンで描いて離すと実行します。Windows・Mac・ミラーリングウィンドウは対象外です。

「すべてのアプリ」は起動アイコンのあるインストール済みアプリとホームが対象です。OneMouse・ロック・権限確認などのシステム画面は除外し、使える操作はアプリ・画面によって異なります。

使い方とジェスチャー一覧を見る

進む・再読み込みが使えません。
進む操作は次の記事ではなく、戻った後の履歴ページに進みます。再読み込みには認識できるブラウザーの標準ボタンが必要で、選択したアプリでも画面によっては使えません。
下 → 右はアプリを閉じる操作ですか？
いいえ。下に描いてから右へ描く二段階の操作で、斜めの一本線ではありません。ホームへ移動するだけで、アプリ・タブ・最近のアプリのカードは閉じません。上 → 右は最近のアプリ一覧を開き、別のアプリを選ぶ操作です。
上下のスクロール量の調整と停止方法は？

上下に長く描くと多く、短く描くと少し移動し、右ボタンを離してから開始します（描いている間は動きません）。矢印・縦ゲージは方向と線の強さで、文書位置や正確な距離ではありません。

  • ページ本文で開始します。非常に短い線・未完成・キャンセルは実行せず、移動のない短い右クリックは従来の動作です。
  • 移動量はアプリ次第で、ホーム・アプリ一覧は1回だけスワイプします。その他の長いスクロールは複数スワイプ、最大8画面・10秒です。
  • クリック・新しいジェスチャー・アプリ切り替え・操作終了で残りをキャンセルします。カーソル移動だけでは止まりません。
10秒おきくらいに切れ続けます。
ゲスト・社内Wi-Fiのクライアント分離とWindowsファイアウォールを確認してください。 スマホの待機中に切れる場合はバッテリー・省電力設定を確認します。
スマホではPCが見えるのに、PCからスマホが見えません。
たいていはWindowsファイアウォールの受信（インバウンド）の問題です。現在のネットワークが「パブリック（Public）」だと受信がブロックされることがあるので、「プライベート（Private）」に変えるか、ファイアウォールでOneMouseの受信を許可してください。
家では使えるのに、会社やカフェのWi-Fiでは使えません。
パブリック/ゲストWi-Fiは、セキュリティのためにデバイス間の通信を分離（client isolation）していることがよくあります。この場合、同じWi-Fiでもお互いを見つけられません。Bluetooth接続や個人のテザリング（ホットスポット）を利用してください。
接続はできたはずなのに、マウス・キーボードが効きません。
Androidのアクセシビリティ確認に従い、OneMouseを再度オンにしてください。
Macとの接続はどこから始めますか？
Macの接続ガイドを見る
カーソルがスマホ/別のPCに閉じ込められて戻ってきません。
緊急復帰キーと設定を確認
画面がオフになると接続が切れます。
画面がオフになるとき、スマホのWi-Fiが省電力になったり、バッテリー最適化でアプリがスリープしたりすることがあります。AndroidでOneMouseをバッテリー最適化の除外にしておくと安定します。接続中の画面オフ防止オプションも確認してください。
Bluetooth接続・リモート画面がうまく動きません。
接続の問題は、両機器のシステムBluetooth設定で既存のペアリングを削除し、再度ペアリングしてください。 大きなファイル・モバイルのリモート画面にはWi-Fi・LANをおすすめします。Macの画面・ウィンドウ共有はLAN専用です。 Bluetoothの接続手順
