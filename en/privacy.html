Privacy Policy

OneMouse connects Windows with Android, paired Windows PCs, and Apple Silicon Macs running macOS 13+. Mac connections in the current public support scope use the local network.

Effective date: September 1, 2026

01

Core principle

OneMouse uses local communication between the user's Windows PC and a paired Android device, Windows PC, or Mac. OneMouse does not operate an account server that stores user files, clipboard content, or input content.

02

Information processed

  • Device information: Android device ID, device name, Windows or Mac computer name, device ID, platform, display information, or local network address
  • Connection information: pairing state, session key, selected device, transport, and last connection time
  • Placement information: screen size, orientation, display topology, and device position around the Windows PC
  • Transfer information: files, folders, text, and clipboard content explicitly sent by the user
  • Billing information: whether Android Pro was purchased or restored. Google Play handles payment processing.

03

Accessibility and screen permissions

Android Accessibility applies mouse and keyboard input sent from the PC to Android. On Mac, Accessibility allows the Mac to perform input received from Windows. Local Network is used for discovery on macOS 15+ and may not appear on macOS 13/14. Mac Bluetooth is outside the current public support scope. Screen & System Audio Recording is optional and used only for LAN-based Mac display sharing; OneMouse does not capture system audio. These permissions are not used for ad tracking, password collection, or remote server transmission.

04

Files and clipboard

Files, folders, and clipboard content move only when the user sends them or enables the relevant sync feature. Transfers are direct among supported devices, including Mac over LAN. Content is not uploaded to OneMouse servers.

05

Local storage and deletion

Pairing records, session keys, device lists, and placement settings may be stored in each app's local storage. The Mac app stores its paired session key in the macOS Keychain. Clearing pairing removes the trusted session record; users can separately remove app data and settings from their devices.

06

Ads and billing

Google Play Billing, when applicable, is limited to the Android distribution, and no ads SDK is included in any app. The Windows and macOS apps do not process purchases or transfer Android Pro entitlement between platforms. Google's own terms and privacy policies may apply to Android billing services.

07

Website analytics and cookies

This website uses Google Analytics 4 (measurement ID G-MJ73H86TWX) to understand visit statistics, which stores cookies in your browser. It processes visit data such as the pages you view, the time of the visit, an approximate region, and your browser and device type. It does not collect directly identifying information such as your name or contact details.

The download button on the home page queries the GitHub releases list so it can point to the latest version. Your IP address and browser information are sent to GitHub as part of that request.

You can opt out by blocking cookies in your browser or by installing Google's Google Analytics Opt-out Browser Add-on. This applies to the website only — the OneMouse apps contain no analytics SDK.

08

App update checks

Each app periodically downloads a version information file so it can tell you about new versions and about compatibility between your devices. The Android app checks version information on onemouse.pages.dev; the Windows and macOS apps check GitHub release information.

These requests contain no device identifiers, pairing information, account information, or usage statistics — the apps only download the file. As with any internet request, your IP address and the time of the request may appear in server logs. Installer downloads happen only when you explicitly choose to download.
