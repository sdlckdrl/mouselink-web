Privacy Policy

OneMouse currently connects Windows with Android and paired Windows PCs. The macOS 13+ build is awaiting distribution and real-Mac validation; this policy also describes its planned local processing.

Effective date: July 28, 2026

01

Core principle

OneMouse currently uses local communication between the user's Windows PC, Android device, and paired Windows PC. The planned Mac build follows the same local-only model. OneMouse does not operate an account server that stores user files, clipboard content, or input content.

02

Information processed

  • Device information: Android device ID, device name, Windows or Mac computer name, device ID, platform, display information, or local network address
  • Connection information: pairing state, session key, selected device, transport, and last connection time
  • Placement information: screen size, orientation, display topology, and device position around the Windows PC
  • Transfer information: files, folders, text, and clipboard content explicitly sent by the user
  • Billing information: whether Android Pro was purchased or restored. Google Play handles payment processing.
  • Advertising signals: the Android distribution may use Google Mobile Ads SDK to process advertising identifiers and related signals when ads are enabled.

03

Accessibility and screen permissions

Android Accessibility applies mouse and keyboard input sent from the PC to Android. In the planned Mac build, Accessibility allows the Mac to perform input received from Windows. Local Network is used for discovery on macOS 15+ and may not appear on macOS 13/14. Bluetooth access is requested only when the user enables a Bluetooth connection. Screen & System Audio Recording is optional and used only for LAN-based Mac display sharing; OneMouse does not capture system audio. These permissions are not used for ad tracking, password collection, or remote server transmission.

04

Files and clipboard

Files, folders, and clipboard content move only when the user sends them or enables the relevant sync feature. Current transfers are direct among supported devices; the planned Mac build follows the same rule. Content is not uploaded to OneMouse servers.

05

Local storage and deletion

Pairing records, session keys, device lists, and placement settings may be stored in each app's local storage. A released Mac build stores its paired session key in the macOS Keychain. Clearing pairing removes the trusted session record; users can separately remove app data and settings from their devices.

06

Ads and billing

Ads and Google Play Billing, when applicable, are limited to the Android distribution. The Windows and macOS apps do not process purchases or transfer Android Pro entitlement between platforms. Google's own terms and privacy policies may apply to Android billing and advertising services.
