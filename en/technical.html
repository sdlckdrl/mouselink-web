Local First

Data travels directly between connected devices.

Mouse and keyboard input, files, and clipboard data travel directly between connected devices. A LAN connection uses the same local network (wired or Wi-Fi). Google account linking uses an account service for device lists and connection signals, not for uploading input or files.

Permissions

Only what a feature actually needs.

Android may ask for some permissions when the app opens. See below for feature-specific requirements, such as accessibility and screen capture.

Required

Accessibility Service

To control Android with your PC's mouse and keyboard and to handle remote input and screen-related actions, the Accessibility Service is required. OneMouse's core features depend on it.

When starting remote control

Screen capture approval

Approved through an Android system prompt when you open the mobile remote control window. Some content, such as secure screens, may not appear.

When the app asks

Nearby Wi-Fi devices

On Android 13 and later, the app can ask for Nearby Wi-Fi devices and notification permissions when you first open it. On Android 12 and later, Bluetooth mode can ask for the separate Nearby devices permission.

When the service starts

Notifications

Used to show the background connection status. Requested only when needed.

When using brightness

Modify system settings

Needed once the first time you adjust the mobile screen brightness with Alt+Shift+↑/↓.

Recommended

Battery optimization exception

Recommended for stability if the connection drops after the screen turns off. It isn't required.

Mac · macOS 15+ only

Local Network

Allows the Mac to discover the Windows PC on macOS 15+. macOS 13/14 may not show this permission and the runtime treats it as not required.

Required on Mac

Accessibility

Allows the Mac to perform mouse and keyboard input received from Windows. Basic input receiving does not require Input Monitoring.

Mac screen sharing only

Screen & System Audio Recording

Used only when sharing the Mac's display with Windows. OneMouse does not capture system audio.

Data Handling

Data handling

  • LAN/Bluetooth pairing needs no sign-in. Optional Google account linking uses an account service for device lists and connection signals. See account data handling.
  • Files you send aren't stored on a server. They go straight to the device you pick.
  • Accessibility data is never used for advertising or screen collection. It's used only for the stated features, such as passing input and remote control.
  • Send files by choosing a device or dragging them to it. With clipboard sharing active, you do not have to pick a destination each time you copy text.
  • The Mac app stores its paired session key in the macOS Keychain. Clearing pairing removes the trusted connection.

Network

Network conditions

Recommended setup

  • The same Wi-Fi on a personal Wi-Fi router (2.4 or 5 GHz, either is fine)
  • A network that allows device-to-device communication
  • OneMouse allowed inbound in the Windows firewall
  • On macOS 15+, Local Network access allowed for OneMouse on the Mac

Limited setup

  • Client isolation on guest or corporate Wi-Fi
  • Inbound blocked on a network marked as "Public"
  • In these cases, use a direct Bluetooth connection or a personal hotspot

Devices must be able to communicate directly with each other.

Support Scope

Supported platforms and connections

  • Windows 10 or 11 (x64): connects with another Windows PC, Android, or Mac.
  • Android 8.0 or later: phones and tablets can receive Windows mouse and keyboard input. Opening a Windows remote screen from Android is a separate feature.
  • Apple Silicon Mac with macOS 13 or later: connect to Windows over LAN, with a Google account, or over Bluetooth (beta). Mac-to-Windows mouse and keyboard input can also be set up over Bluetooth.
  • Bluetooth is a beta option for supported pairs and needs neither Wi-Fi nor Google sign-in. It does not carry remote video. To view a Mac screen or window from Windows, use the same local network and grant Screen Recording permission on the Mac.
  • USB/ADB connections are not officially supported.
