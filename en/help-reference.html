When it won't work, narrow it down step by step.

Check apps → discovery → firewall → pairing → input in that order.

The return key below is the default. If you changed it in PC Settings → Shortcuts, use your saved key. If all shortcuts or emergency return are off on the main PC, return across the screen edge. See shortcuts and their conditions

Start with these two

  • Lost your cursor? → Press Ctrl + Alt + Backspace and the cursor returns to your own PC (center of the monitor).
  • Connected but input does not work? → The Android Accessibility Service may be off or may have restarted. Check Accessibility, arrangement and the entry passage in order.

What is happening now?

Expand the matching topic and check each step in order before clearing your sign-in or pairing.

Connected, but the cursor will not move onto the phone
  1. Accessibility: check that OneMouse is enabled under Android Settings → Accessibility → Installed apps (or Downloaded apps). If it is enabled but input still fails, turn it off and on again. For the Test app, check OneMouse Test.
  2. Arrangement: check which side of the PC screen the target device occupies in Phone placement. Matching the phone’s physical position makes the direction easier to follow.
  3. Entry passage: use the configured passage on that edge. If the passage is in the middle, the screen corners will not let you cross. See the arrangement screen
  4. App versions: update Windows and Android to the latest public versions and restart OneMouse on both. Check that the Accessibility Service is still enabled.

If you lose the cursor, the default Ctrl + Alt + Backspace returns it to the PC. If you changed that shortcut, use your saved key combination.

A device is missing from my Google account or will not connect
  1. Check that both OneMouse apps show the same Google account address, both devices have internet access, and both apps are running.
  2. Refresh the device list and connect the target device. Confirm any request on the other device. Account connection steps
  3. If asked to verify your Google account again, complete the sign-in verification. If you see “Cannot create more connections,” close unused remote screens and connections, then try again after a short wait. Removing an account device and ending a connection are different actions.

To connect without signing in on the same Wi-Fi, choose QR/code pairing. Account connections do not require the same router.

I can see the PC screen on my phone, but cannot control it
  1. Check that View only is off in the remote-screen control panel.
  2. Touch mode clicks where you touch. In Cursor mode, slide your finger to position the pointer, then tap.
  3. If a control request appears on the PC, allow it. Use supported, up-to-date versions on both Windows and Android. A Bluetooth-only connection cannot open remote video.

Troubleshooting order

Check one step at a time, in this order.

1

Power and permissions

Check that both apps are running. For input permissions, see the quick checks.

2

Check your chosen connection method

QR/code: use the same router and check local-network permissions and discovery. Google account: check the shared account and internet access on both devices. Bluetooth: check that Bluetooth is on, paired and connected.

3

Firewall & isolation

For a Wi-Fi/LAN connection, if the phone can see the PC but the PC cannot see the phone, it may be a Windows firewall inbound issue (whether the network is set to "Public" or "Private"). Office and café Wi-Fi can also block it with client isolation.

4

Pairing & connection

Check pairing and connection status in Devices. For the first connection, follow the setup guide.

5

Input & return

Check the arranged direction and configured cursor entry passage. Follow the input checks; if you lose the cursor, see how to bring it back.

Transfer

When files and clipboard won't go through.

  • Confirm the selected device is correct — a transfer goes to the target you selected.
  • Desktop-to-desktop drag requires the target Windows PC or Mac to be connected and arranged. Mac edge drag currently uses LAN.
  • Keep holding the file, cross the arranged screen edge, and drop it on the target to start the transfer.
  • If the clipboard doesn't come through, check that both apps are connected and whether a screen is off and idle.
  • Bluetooth is slower than Wi-Fi — send large files over Wi-Fi.

Phone notifications

When phone notifications don't show on the PC.

  • In the phone app's Notifications to PC settings, turn on Send notifications to PC and check that Notification access says allowed.
  • Check that the app is in Apps to send to PC. The defaults are your SMS app and KakaoTalk; you can also choose all apps.
  • On the main PC, open Settings → Notifications and make sure Device notifications is on.
  • If only verification-code messages arrive as "hidden", that is Android 15's protection. In the phone app's Verification-code notifications block, tap Register PC once. Bluetooth is only needed while registering.
Notification history and deletion

Notifications appear briefly; history is encrypted locally on the PC, never uploaded. Only notifications received after enabling are recorded; verification codes and hidden sensitive content are not saved.

History defaults to on, 7 days, and up to 200 entries. Main-PC Settings → Notifications offers 1/7/30 days or no new entries. Existing history stays; Clear all deletes it.

Mac · Troubleshooting

Checks for the public macOS 13+ app.

Install the public Apple Silicon build and start the LAN connection from OneMouse on Windows.

The Mac does not appear in Windows Devices.
Put both computers on the same Wi-Fi or LAN. On macOS 15+, allow OneMouse under Privacy & Security → Local Network; macOS 13/14 may not show this item. Return to OneMouse and refresh Devices in Windows.
The Mac is connected, but mouse and keyboard input do not work.
Allow OneMouse under macOS Privacy & Security → Accessibility, then return to the app so it can recheck the permission. Basic input receiving does not require Input Monitoring.
The Mac screen is blank in the Windows remote-control window.
Allow OneMouse under macOS Privacy & Security → Screen & System Audio Recording. This optional feature is LAN-only and is not provided over Bluetooth; OneMouse does not capture system audio.
Can Windows and Mac connect over Bluetooth?
Yes, as a beta: enable Bluetooth in the Mac app settings (off by default). LAN remains the officially supported path. Mac screen and window sharing is LAN-only.
Where do I start a Mac connection?
Follow the Mac connection guide

Mac can send input to Windows or receive it from Windows. To send input from Mac, allow Accessibility and Input Monitoring. To receive input on Mac, allow Accessibility. Mac Bluetooth setup

Connections and input

My devices use the same Google account. Why is one missing?

Open OneMouse on both devices, check that both are online and signed in to the same Google account, then refresh the device list. If the device appears but the cursor won't cross, check the connection and device layout separately. Google account setup

Why does the connection keep dropping?

When the screen is on, check whether both devices are still on the intended network and whether the problem follows a particular router. If it only drops on screen-off, check Android power settings rather than treating the interval as a diagnosis. Automatic LAN reconnection

Why does my phone see the PC, but the PC can't see my phone?

For LAN discovery, check that both OneMouse apps are open and connected to the same router. Check whether Windows Firewall allows OneMouse on that trusted network. Don't turn off the firewall or mark a public network as private.

Why does pairing work at home but not on office or guest Wi-Fi?

Some networks block device-to-device traffic, even on Wi-Fi with the same name. Seeing a device under the same Google account does not guarantee that every feature works on that network. Try a trusted network that allows devices to communicate, or Bluetooth (beta) for a supported device pair.

It says connected. Why don't mouse and keyboard input work on Android?

On Android, go to Settings → Accessibility → Installed apps and check OneMouse. If it's on but the service is disconnected, turn it off and back on. In the PC layout, check that the cursor is crossing the marked entry area. Set up Android input

The Mac shows up, but why can't I click or type?

On the Mac, open System Settings → Privacy & Security → Accessibility and check OneMouse. After granting access, reopen OneMouse, then try moving the cursor over and typing in a plain text field. Mac permissions

Why does my Mac screen or window look black?

On the Mac, check OneMouse's Screen Recording permission (called Screen & System Audio Recording on some versions of macOS). If you changed it, reopen the app if macOS asks, then start the share again. Mac Screen Recording permission

How do I get my cursor back to the PC?

On Windows, the default emergency return is Ctrl + Alt + Backspace. If you changed it, use the saved shortcut. If it's disabled, move the cursor back across the return edge. Return shortcut settings

Why does the connection drop only when the Android screen goes off?

Check whether Android restricts OneMouse's background battery use. On phones that offer it, try allowing unrestricted use for OneMouse. The exact labels and behavior vary by manufacturer.

What should I check first for Bluetooth (beta)?

Bluetooth does not require Wi-Fi or prior LAN setup. Pair the devices in your system settings, then turn on the connection in OneMouse.

Check that Bluetooth is on and the supported devices are paired and connected in OneMouse. For remote screens, use the connection method listed for your device pair. Basic Bluetooth input working doesn't mean screen sharing is supported over Bluetooth. Support by device pair

Why can't I reorder devices on Windows?

On the main PC, open Device Management and look for Edit list order when at least two eligible registered devices are listed. Supported numbered shortcuts follow the list order; screen layout stays the same. Bluetooth devices are excluded. Device list order guide

Notifications, files and screenshots

Why can't I reply to a notification from my PC?

Check that the original Android notification provides a reply field and is still active. On the main PC, try the live notification, not a history item. Hidden or sensitive notifications aren't eligible. If a reply times out, check the original app before trying again. Both the PC and Android apps need versions that support replies. “Passed to phone app” means the reply reached the original app; it does not confirm delivery to the recipient. Notification and reply settings

Why doesn't a file shared from my phone reach the PC?

If Bluetooth is active, the connected PC takes priority. Otherwise, check that the Wi-Fi/LAN default PC in Android OneMouse is paired, available and set as the main PC. If the default is unavailable, select another eligible paired PC in the file sharing screen. Send files and text from your phone

Where are received files saved on Windows?

In OneMouse, open Settings → General → File transfer and check the receive folder. If it won't open, try a writable folder on a drive that's connected. Changing this folder doesn't move files you already received. Screenshots have their own save location. Change the receive folder

Why does the screenshot preview close, or the cursor not return?

When supported by both devices, screenshot capture can leave your cursor on the controlled device rather than forcing it back. Move the cursor back to operate the preview. Successful copy or save closes the preview. Canceling a save or a save error keeps it open.

Mouse gestures and remote windows

Why don't browser gestures work inside a Windows remote window?

A right-button drag in a Windows remote window is relayed to the remote device. Enable gesture support in the target browser if it offers it. This is separate from OneMouse's gestures when controlling Android directly. Remote window guide

How do I start a OneMouse mouse gesture on Android?

In Android OneMouse, open Settings → Input & clipboard, enable Mouse gestures and allow the app you want. Move the PC cursor onto Android, hold the right button, draw, and release. Android system and permission screens aren't gesture targets. These Android gestures do not run on Windows, Mac or separate remote viewing windows. Mouse gesture guide

Why don't Forward and Reload work in some Android apps?

Forward revisits a page after Back; it doesn't advance to the next item in a feed. Reload depends on a compatible browser control, so it may be unavailable on some screens, even in an enabled app.

Does drawing down, then right close my Android app?

No. Draw down first, then turn right before releasing. It goes to Home without closing the app or tab. Up, then right opens Recents. A diagonal stroke is not the same gesture.

How do I control or stop a scroll gesture on Android?

Draw up or down in the content area and release the right mouse button. Nothing scrolls while drawing. A longer stroke usually scrolls farther than a shorter one; distance varies by app. The arrow and vertical gauge show direction and stroke strength, not document position. An extended scroll lasts up to 8 screens or 10 seconds. Clicking, starting a new gesture, switching apps or ending control cancels the rest. Pointer movement alone does not stop it.
