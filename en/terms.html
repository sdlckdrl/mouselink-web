Terms of Use

These terms describe the basic conditions for using the OneMouse app and website across a Windows PC, Android, another Windows PC, and an Apple Silicon Mac running macOS 13+.

Effective date: August 5, 2026

01

Service summary and connections

OneMouse starts and manages connections from Windows 10/11 to Android, another Windows PC, or an Apple Silicon Mac running macOS 13+ for input control, file and folder transfer, clipboard features, and supported remote screen features. Current public Mac connections use LAN.

02

Connection requirements

The devices generally need to be on the same Wi-Fi or LAN and able to communicate directly. They may alternatively connect over Bluetooth after system pairing. Guest Wi-Fi, AP isolation, company security policy, firewalls, antivirus software, or denied Local Network permission on macOS 15+ may prevent connection.

03

User permissions and responsibility

Users are responsible for allowing the operating-system permissions needed for the features they choose. Android input requires Accessibility. The Mac app requires Accessibility for input, and Local Network is requested on macOS 15+. Mac Bluetooth is outside the current public support scope. Screen & System Audio Recording is optional and used only for LAN-based Mac display sharing.

04

Free / Pro and platform scope

Android purchase or trial policies are handled inside the Android distribution. The Windows app does not process purchases, validate Android Pro status, or transfer Android entitlement between platforms. The macOS app requires neither a login nor a separate paywall.

05

Android store billing

Google Play Billing is used for applicable Pro purchases and restoration in the Google Play Android app. The Galaxy Store build may be distributed as a paid app. The relevant store's terms and policies apply to those transactions.

06

Support scope

Current official support covers connections started from Windows 10/11 to Android and another Windows PC over Wi-Fi/LAN or Bluetooth, and to Apple Silicon Macs running macOS 13+ over LAN. Mac Bluetooth is outside the current public support scope. Mac screen and window sharing is LAN-only. USB/ADB connection is not included in the user-facing support scope.

07

Limitations

OneMouse depends on network state, operating-system permissions, security software, hardware, and device manufacturer behavior. Continuous connection, input, screen sharing, or transfer cannot be guaranteed in every environment.
