How to use each feature

Choose what you want to do to see the steps.

Send files or share the clipboardFiles, copied text, screenshots

Send files

Drop files into the Transfer tab or Quick Drop (Ctrl+Alt+D) and choose a recipient. You can also drag files across the screen edge to a supported Windows PC or Mac. On Android, use the Transfer tab or OneMouse in the share menu.

Files received on your PC: Settings → General → File transfer → Received files location → Open folder.

Use copied text on another device

On supported connections, copy text on one device and paste on the other. To send selected Android text directly to a PC, open the selection menu and choose More → OneMouse to PC.

Capture only the area you need

On Windows, use Ctrl+Alt+Sto capture an area, then copy or save it from the preview. You can send it over a supported Wi-Fi or LAN connection. Paste the received image into an app that accepts images.

If files, copy or capture does not work

Open a remote screenControl a PC from a phone, or view devices from a PC

Open Windows from Android

On both supported apps, connect over a local network or through your Google account. In the list of registered PCs on Android, open Remote screenand accept the request in Windows if prompted. Turn on View only if you do not want to control the PC.

View a connected device from Windows

Open the remote window in Device management. On Android, approve screen capture on the phone. Sharing a Mac screen or window requires the same network and screen recording permission.

Touch and pointer controls on Android

Touch mode clicks where you tap. In pointer mode, swipe to move the pointer, then tap. Touch and hold, then release for a right-click. At 1× zoom, move two fingers to scroll.

◎Tap to click↔Swipe to move the pointer⇅Scroll with two fingers
Control the PC with an Android gamepad

Supported Windows and Android apps can use an Xbox-style on-screen gamepad or a physical controller.

Bluetooth (beta) does not carry remote video. Supported apps can adjust quality and frame rate in the control panel.

If the remote screen does not appear

View Android notificationsMessage alerts and verification codes

Grant notification access on Android and turn on Send notifications to PC. Choose which apps to include and turn on device notifications in Windows. Check past alerts and the retention period in Windows Settings.

For supported apps and notifications, reply or copy a verification code from your PC. Android protections may hide some notifications or codes.

If notifications are missing

Use mouse gesturesGo back or scroll on Android

These gestures use the pointer on your Android screen. In both supported apps, go to Settings → Input & clipboard → Mouse gestures and choose the apps. Gestures start off disabled.

While holding right-click on the Android screen, trace the gesture, then release.

● The dot marks the start and arrows show the direction. Follow 1 → 2 without releasing for a two-part gesture.

Back

← Left

Return to the previous page or screen.

Forward

→ Right

Return to the page you went back from.

Scroll up

↑ Up

Draw upward and release. A longer stroke scrolls farther.

Scroll down

↓ Down

Draw downward and release. A longer stroke scrolls farther.

Minimize app

↓ Down → Right

Return to Home without closing the app.

Refresh

① Up, ② back down the same line

Reload the page in supported browsers.

Recent apps

↑ Up → Right

Open the list of recently used apps.

To refresh, hold the right mouse button, draw upward, then return downward along the same line in one gesture.
