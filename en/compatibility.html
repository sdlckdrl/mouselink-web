OneMouse compatibility

How do I connect my devices?

Use your Windows mouse and keyboard on another device. Choose a device for local network setup, Google account discovery, or Bluetooth (beta).

Which connection should I choose?

If you can use the same router Connect over Wi-Fi or wired LAN. Pairing with a QR code or a numeric code does not require Google sign-in.

To find your devices without a code Sign in to both apps with the same Google account. This requires internet access. The account helps find devices and start a connection; features such as remote viewing depend on the network and devices.

To connect nearby devices without a router All Bluetooth connections are in beta. You can connect Windows PCs to each other, connect Windows to Android, or connect Windows and Mac one-to-one. To send Mac input to Windows, see the Mac Bluetooth guide (beta). For remote video, connect over Wi-Fi or LAN.

Remote control displays the other device’s screen. It is different from moving your cursor to a nearby device. Control Windows remotely from Android · View a connected device’s screen from Windows
