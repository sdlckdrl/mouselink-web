# 홈페이지 문서 목록

홈페이지 작업은 [저장소 소개](../README.md)에서 시작합니다. 사용자 설치 절차는 공개
HTML 가이드에서, 홈페이지 개발·배포 관련 절차는 아래 문서에서 관리합니다.

| 문서 | 역할 |
| --- | --- |
| [소스 지도](source-map-ko.md) | 페이지·언어·CSS·JavaScript·매니페스트·테스트의 관계와 수정 진입점 |
| [유지보수 안내](maintenance-guide-ko.md) | 로컬 미리보기, 다국어 수정, 다운로드·호환성 갱신, 검증·푸시 |
| [공개 사용 가이드](https://onemouse.pages.dev/guide) | 앱 설치·권한·페어링·파일 전송·단축키 |
| [공개 도움말](https://onemouse.pages.dev/help) | 사용자 문제 해결 |
| [앱 문서 목록](https://github.com/sdlckdrl/MouseLink/blob/main/docs/README.md) | 앱 구현·빌드·플랫폼별 릴리스·현재 정책 |

`llms.txt`는 검색·AI 도구용 제품 요약입니다. 사용 절차, 경쟁사 비교, 릴리스 절차를
복제하지 않고 해당 페이지로 연결합니다. 같은 안내를 바꾸면 요약도 함께 확인합니다.

과거 릴리스는 [GitHub Releases](https://github.com/sdlckdrl/mouselink-web/releases)와 Git
이력에서 확인합니다. 현재 버전은 문서 예시가 아니라 매니페스트와 실제 배포 자산을 기준으로
판단합니다.
