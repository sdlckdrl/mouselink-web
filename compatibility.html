OneMouse 지원 범위

내 기기는 어떻게 연결할까요?

Windows PC의 마우스·키보드를 다른 기기에서 쓰는 기준이에요. 아래에서 기기를 골라 같은 네트워크, Google 계정으로 기기 찾기, Bluetooth(베타) 안내를 확인하세요.

기기별 연결 가이드

Windows ↔ Windows

필요한 버전
Windows 10·11
권한
방화벽에서 앱 허용을 요청하면 확인하세요.
같은 네트워크Google 계정Bluetooth (베타)

Windows → Android

대상
Android 폰·태블릿
권한
Android에서 OneMouse 접근성을 켜세요.
같은 네트워크Google 계정Bluetooth (베타)

Windows → Mac

필요한 버전
Apple Silicon · macOS 13 이상
권한
Mac의 손쉬운 사용을 켜세요. macOS 15 이상은 로컬 네트워크 요청도 확인하세요.
같은 네트워크Google 계정Bluetooth (베타)

어떤 방법을 고를까요?

같은 공유기를 쓸 수 있다면 Wi-Fi나 유선 LAN으로 연결하세요. QR이나 인증번호를 쓰면 Google 로그인이 필요 없어요.

QR·인증번호 없이 내 기기를 찾으려면 두 앱에 같은 Google 계정으로 로그인하세요. 인터넷이 필요해요. 계정은 기기를 찾고 연결을 시작하는 방법이라, 원격 화면 등 실제 기능은 네트워크와 기기에 따라 달라요.

공유기 없이 가까운 기기를 연결하려면 Bluetooth는 모두 베타예요. Windows끼리 또는 Windows와 Android를 연결할 수 있어요. Windows와 Mac은 한 대씩 연결할 수 있어요. Mac에서 Windows로 마우스·키보드를 보내는 방법도 Mac Bluetooth 가이드 (베타)에 있어요. 원격 화면 영상은 Wi-Fi·LAN으로 연결하세요.

화면을 띄워 조작하는 원격 제어는 커서를 옆 기기로 넘기는 기능과 달라요. Android에서 Windows 원격 조작 · Windows에서 연결 기기 화면 보기
