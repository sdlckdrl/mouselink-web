마우스와 키보드는 하나로 쓰고, 필요할 때는 파일을 보내거나 다른 기기의 화면을 열어 보세요.

01 · 소프트웨어 KVM

마우스를 화면 끝으로, 키보드는 그대로.

Windows에서 연결하고 기기를 책상 위에 놓인 방향대로 배치하세요. 배치에 표시된 화면 가장자리 통로로 커서를 넘기면 옆 기기에서 클릭·스크롤·입력을 이어서 할 수 있어요.

PC 마우스로 Android 제스처 쓰기

02 · 공유

방금 복사한 글, 파일도 옆 기기로.

파일 보내기

전송 화면이나 빠른 드롭존에 파일을 놓고 받을 기기를 고르세요. 연결한 Windows PC나 Mac은 지원되는 경우 배치한 화면 경계 너머로 드래그할 수 있어요.

빠른 드롭존은 기본 Ctrl+Alt+D로 열어요. Android에서 PC로 보낼 때는 전송 탭이나 Android 공유 메뉴에서 OneMouse를 고르세요.

파일 보내기 체험 · 전송이 안 될 때

복사한 텍스트 보내기

지원되는 연결에서는 한쪽에서 복사한 텍스트를 다른 쪽에서 붙여넣을 수 있어요. 폰에서 PC로 보낼 때는 연결할 PC를 정하고, Android 텍스트 선택 메뉴의 더보기 → OneMouse to PC를 누르세요.

복사·붙여넣기 체험

필요한 화면만 찍기

Windows 기본 Ctrl+Alt+S로 영역을 캡처한 뒤 미리보기에서 복사하거나 저장해요. 지원되는 Wi-Fi·LAN 전송을 쓰면 다른 기기로 보낼 수 있어요.

받은 쪽에서는 이미지 붙여넣기를 지원하는 앱을 사용하세요.

캡처 전송 체험 · 문제 해결

PC에서 받은 파일 찾기: 설정 → 일반 → 파일 전송 → 수신 파일 저장 위치에서 폴더 열기를 선택하세요.

기기와 연결 방식에 따라 달라요. 지원 범위 확인

03 · 원격 화면

다른 기기의 화면도 열어 보세요.

마우스를 넘길 때와 달리, 원격 화면은 상대 기기의 화면을 지금 쓰는 기기에서 보고 조작하는 기능이에요.

Android 폰 → Windows

Android에서 등록된 PC의 원격 화면을 열고, PC에서 요청을 허용하세요. 지원되는 앱의 같은 Wi-Fi 또는 Google 계정 연결에서 사용해요.

터치나 커서 모드로 조작하고, 확대·스크롤·키보드 입력을 사용할 수 있어요. 보기만 할 때는 보기 전용을 켜세요.

폰으로 PC 조작 체험

Windows → 연결한 기기

기기 관리에서 지원되는 기기의 원격창을 열어요. Android 화면은 폰에서 화면 캡처를 승인하고, Mac 화면·창 공유는 같은 네트워크와 화면 녹화 권한이 필요해요.

원격 화면이 안 나올 때

터치와 커서 조작

Android에서 Windows를 원격 조작할 때 쓰는 방식이에요. 터치 모드는 누른 자리를 클릭하고, 커서 모드는 손가락으로 포인터를 옮긴 뒤 탭으로 클릭해요. 길게 누르고 떼면 우클릭할 수 있고, 1배에서는 두 손가락 이동으로 스크롤할 수 있어요.

◎탭으로 클릭↔밀어서 커서 이동⇅두 손가락으로 스크롤
폰으로 PC 게임 조작 체험
폰에서 게임패드로 조작하기

Android 폰이나 태블릿에서 Windows PC를 원격으로 조작할 때 Xbox 방식 화면 게임패드나 실물 게임패드를 사용할 수 있어요. 양쪽에 이 기능을 지원하는 OneMouse 앱 버전이 필요해요.

폰으로 미니 레이싱 체험 · 공식 Google Play 업데이트 안내

Bluetooth는 원격 화면 영상을 전송하지 않아요. 지원되는 앱의 제어 패널에서 화질·프레임 속도를 조절할 수 있습니다.

04 · Android 알림

폰 알림을 PC에서 보고, 필요할 때 답장.

알림 보기

폰의 알림 접근 권한을 허용하고 PC로 알림 보내기를 켠 뒤, 보낼 앱을 선택해요. Windows 설정의 기기 알림 표시도 켜 주세요. 같은 설정에서 지난 알림과 보관 옵션을 확인할 수 있어요.

지원되는 알림에 답장

양쪽 앱이 답장을 지원하고 원래 알림에 직접 답장 기능이 있으면 PC에서 답장을 보낼 수 있어요.

인증번호 복사

지원되는 알림은 인증번호 복사 버튼을 사용할 수 있어요. Android 보호 정책에 따라 일부 알림이나 번호는 표시되지 않을 수 있어요.

알림 설정 점검

기기별로 필요한 권한만 켜세요.

Android 입력은 접근성, Mac 입력은 손쉬운 사용을 허용해요. Mac 검색에는 macOS 15 이상에서 로컬 네트워크 권한이 필요할 수 있어요. 화면 캡처·녹화 승인은 원격 화면을 열 때 별도로 요청돼요.

기기별 지원·권한 확인

05 · PC 기본 단축키

필요한 동작은 키보드로 바로.

Ctrl+Alt+1~9

메인 PC에서 번호가 지정된 LAN 기기 입력에 연결하거나 해제해요.

Ctrl+Alt+Shift+1~9

해당 LAN 기기의 원격창을 열거나 앞으로 가져와요.

Ctrl+Alt+D

빠른 드롭존을 열거나 숨겨요.

Ctrl+Alt+S

캡처 도구를 열어요. 제어 중인 대상의 앱과 권한에 따라 달라요.

Ctrl+Alt+V

인증번호가 포함된 폰 알림이 떠 있을 때 지원되는 번호를 복사해요.

Ctrl+Alt+Backspace

다른 기기에서 마우스를 내 PC로 가져와요.
