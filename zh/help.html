请按启动应用 → 发现 → 防火墙 → 配对 → 输入的顺序检查。

先看这三点

  • 找不到光标时 → 按 Ctrl+Alt+Backspace，光标会回到自己的电脑（显示器中央）。
  • 已连接但无法输入时 → Android 的无障碍服务可能已关闭或被重启。请依次检查无障碍、布局和进入通道。
  • Mac 无法输入时 → 检查输入权限

按症状查找

现在遇到了哪种情况？

展开对应项目，从上往下检查。无需先删除现有登录信息或配对记录。

显示已连接，但光标无法移到手机
  1. 无障碍：在 Android 设置 → 无障碍 → 已安装的应用（或已下载的应用）→ OneMouse 中确认服务已开启。已开启仍无法输入时，请关闭后重新开启。使用 Test 应用时，请检查 OneMouse Test。
  2. 设备布局：在 PC 的手机布局中，确认目标设备位于屏幕的哪个方向。让设置与手机实际位置一致，可以避免混淆。
  3. 进入通道：从所设方向的通道移过去。如果通道位于边缘中央，从屏幕角落无法通过。查看布局画面
  4. 应用版本：将 PC 和 Android 更新到最新公开版本，并重新启动两端的 OneMouse。也请确认无障碍服务仍保持开启。

找不到光标时，可按默认快捷键 Ctrl+Alt+Backspace 返回 PC。如果改过快捷键，请使用自己设置的组合键。

Google 账号中看不到设备或无法连接
  1. 确认两端 OneMouse 使用同一 Google 账号邮箱，并检查两台设备的互联网连接和应用运行状态。
  2. 刷新设备列表并连接目标设备。若出现确认请求，请在对方设备上允许。账号连接步骤
  3. 若提示重新验证 Google 账号，请进行登录确认。若提示无法创建更多连接，请关闭不使用的远程画面或连接，稍候重试。从账号中移除设备与结束连接是不同的操作。

若要在同一 Wi-Fi 下免登录连接，也可以选择二维码或号码配对。账号连接并不要求两台设备连接同一路由器。

手机能看到 PC 画面，但无法操作
  1. 确认远程画面控制面板中的仅查看已关闭。
  2. 触摸模式会点击触摸的位置；光标模式则先用手指滑动来移动指针，再轻点。
  3. 如果 PC 上显示控制请求，请允许。确认 PC 和 Android 均为受支持的最新版本。仅连接 Bluetooth 时，无法打开远程视频画面。

排查顺序

请按这个顺序，一步步确认。

1

开关与权限

确认两端应用已启动。输入权限请看先看这三点。

2

连接方式与网络

Google 账号：检查同一账号和两端的互联网连接。二维码/号码：确认处于同一路由器的 Wi-Fi/LAN。Bluetooth：确认两端系统设置中的 Bluetooth 已开启。

3

防火墙·隔离

手机能看到电脑、电脑却看不到手机时，可能是 Windows 防火墙入站（网络是“公用”还是“专用”）的问题。公司、咖啡馆的 Wi-Fi 有时会因客户端隔离而被拦截。

4

配对·连接

在设备管理中确认配对和连接状态。首次连接请看连接指南。

5

输入·返回

检查布局方向和设置的光标进入通道。请按输入检查步骤排查；找不到光标时，请查看返回方法。

传输

文件和剪贴板不工作时。

  • 确认选中的设备是否正确 —— 传输会发往你选定的目标。
  • Windows PC 之间或 Windows 与 Mac 的边界拖放需要目标电脑已连接并完成布局；Mac 边界拖放使用 LAN。
  • 要抓着文件越过布局中的屏幕边界，在目标上方松手，传输才会开始。
  • 剪贴板传不过来时，确认两端应用是否都处于已连接状态，或屏幕是否已息屏进入待机。
  • Bluetooth 比 Wi-Fi 慢 —— 大文件请用 Wi-Fi 发送。

手机通知

手机通知没有显示在电脑上时。

  • 在手机应用设置的发送到电脑的通知里打开发送通知到电脑，并确认通知访问权限为已允许。
  • 确认该应用在发送到电脑的应用列表里。默认是短信应用和 KakaoTalk，也可以选择所有应用。
  • 在主电脑的设置 → 通知中，确认显示设备通知已开启。
  • 如果只有验证码短信以“已隐藏”送达，那是 Android 15 及以上的保护机制。在手机应用的验证码通知区块点按注册电脑一次即可。只需在注册时打开蓝牙。
通知历史保存与删除

通知短暂显示，历史记录在电脑本地加密保存，不上传服务器。仅记录启用后收到的通知，不保存验证码及隐藏的敏感内容。

历史默认开启、7天、最多200条。主电脑设置 → 通知可选1天/7天/30天或停止新记录。已有记录仍保留，可通过全部删除清除。

Mac 排查

适用于公开 macOS 13+ 版本的检查项。

请安装 Apple 芯片 Mac 公开版，并从 Windows OneMouse 发起和管理 LAN 连接。

Windows 找不到 Mac。
确认 Mac 是 macOS 13+，两端 OneMouse 都已运行并连接到同一本地网络。macOS 15+ 请在系统设置 → 隐私与安全性中允许 OneMouse 使用本地网络；macOS 13/14 可能不会显示该项目。发现和选择操作由 Windows 端发起并管理。
已经配对，但鼠标和键盘无法控制 Mac。
请在系统设置 → 隐私与安全性 → 辅助功能中开启 OneMouse，然后回到应用确认状态已更新。
6 位配对代码应该输入到哪一端？
查看 Mac 连接步骤。
Windows 上看不到 Mac 屏幕或窗口。
只有使用这项功能时才需要在 Mac 允许屏幕录制。允许后停止并重新开始屏幕或窗口共享；该功能需要 LAN，不通过 Bluetooth 提供画面传输。
Windows 与 Mac 可以通过 Bluetooth 连接吗？
可以，作为测试版：在 Mac 应用设置中开启蓝牙（默认关闭）。官方支持范围仍为 LAN；Mac 屏幕与窗口共享仅支持 LAN。

常见问题

大家最常遇到的问题。

没有回复按钮，或回复无法发送。

电脑与Android需使用支持回复的版本，手机原始通知需支持自由输入回复。仅主电脑实时通知可用；隐藏/敏感内容、验证码及历史记录除外。

发送出错时检查手机锁定、通知删除/过期及连接。失败或超时不自动重发，请查看手机会话。“已传给手机应用”仅表示调用原应用回复，不是对方接收确认。查看回复方法

想更改设备编号，却找不到编辑顺序。

主电脑设备管理中有两台以上LAN设备时可编辑顺序。自动保存并更新连接/远程窗口编号，屏幕布局与按键组合不变。蓝牙顺序不变，副电脑角色不可编辑。更改设备顺序

Windows远程窗口中的浏览器手势不起作用。

使用Windows版OneMouse 1.5.4以上，并启用目标浏览器的手势扩展或功能。远程窗口转发右键拖动，与手机直接控制用的Android内置手势不同。

可同时打开多台设备的远程窗口；再次输入同一快捷键编号会将对应窗口置前。查看远程窗口使用方法

从手机分享的文件没有发送到电脑。

Wi-Fi/LAN发送需在手机主页选择主电脑角色的默认电脑，检查配对与连接（副电脑除外）。蓝牙已连接时，无需默认电脑即可发送。从手机发送到电脑

无法更改或打开电脑的接收文件夹。

主/副电脑均可在设置 → 常规 → 文件传输 → 接收文件保存位置中更改或打开文件夹。出错时检查写入权限、USB/网络连接，或选择其他可访问文件夹。已有文件不移动，截图保存位置独立。查看接收文件夹设置

截图后光标没有返回，或预览窗口关闭了。

两端支持版本会让光标留在受控设备，仅显示独立预览；主窗口保持托盘/最小化状态。复制/保存成功后关闭，取消保存或失败时保留。使用预览前，请自行将光标移回主电脑。

鼠标手势无法启动。

使用PC/Android支持版本，在Android设置 → 输入 · 剪贴板启用鼠标手势并选择当前应用（默认关闭）。光标移入手机，右键拖动后松开执行，不适用于Windows、Mac或镜像窗口。

“所有应用”包含有启动图标的已安装应用及主屏幕。OneMouse、锁屏、权限对话框等系统界面除外，支持动作因应用/界面而异。

查看手势使用方法和完整列表

前进或刷新不起作用。
前进是返回后恢复历史页面，不是进入下一篇文章。刷新需要可识别的浏览器原生按钮，已选应用的部分界面也可能不支持。
下 → 右会关闭应用吗？
不会。先向下再向右绘制，是两段顺序动作，不是一条斜线。仅返回主屏幕，不关闭应用、标签页或最近任务卡片。上 → 右打开最近应用列表，便于选择其他应用。
如何调整和停止上下滚动？

上下笔画越长滚动越多，越短越少；松开右键后才执行（绘制时不移动）。箭头和竖向进度条表示方向及笔画强度，不是文档位置或准确距离。

  • 从页面正文开始。过短、未完成或取消的笔画不执行，不移动的短右击保留原有功能。
  • 移动量因应用而异；主屏幕/应用抽屉仅滑动一次。其他长滚动分多次滑动，最多8屏/10秒。
  • 点击、新手势、切换应用或结束控制会取消剩余滚动。仅移动光标不会停止。
每隔 10 秒左右就一直断开。
检查访客/公司 Wi-Fi 的客户端隔离和Windows 防火墙。 手机待机时断开，请检查电池和省电设置。
手机能看到电脑，但电脑看不到手机。
多半是 Windows 防火墙入站的问题。如果当前网络是“公用（Public）”，入站可能被拦截，请改为“专用（Private）”，或在防火墙中允许 OneMouse 的入站。
在家能用，但在公司、咖啡馆的 Wi-Fi 用不了。
公用/访客 Wi-Fi 为了安全，常会隔离设备之间的通信（客户端隔离）。这种情况下，即使是同一个 Wi-Fi 也彼此找不到。请改用 Bluetooth 连接或个人热点。
说是连上了，可鼠标、键盘不起作用。
按Android 无障碍检查方法重新开启 OneMouse。
光标卡在手机/另一台电脑上回不来。
检查紧急返回键及其设置。
屏幕一息屏，连接就断了。
屏幕息屏时，手机的 Wi-Fi 可能进入省电，或应用因电池优化而休眠。在 Android 中把 OneMouse 设为电池优化例外会更稳定。也请查看连接期间的防止息屏选项。
Bluetooth 连接或远程画面不正常。
连接出错时，在两端系统 Bluetooth 设置中删除原有配对，再重新配对。 大文件和手机远程画面建议使用 Wi-Fi 或 LAN。Mac 屏幕和窗口共享仅支持 LAN。 Bluetooth 连接步骤
