帮助

用不了时，一步步缩小范围。

请按 开关 → 发现 → 防火墙 → 配对 → 输入·返回 的顺序逐步排查。Mac 相关内容是仍在准备公证发布与真机验证的辅助版预备指南。

先看这两点

  • 找不到光标时 → 按 Ctrl+Alt+Backspace，光标会回到自己的电脑（显示器中央）。
  • 连上了但无法输入时 → Android 的无障碍服务可能已关闭或被重启。请在无障碍设置里重新开启 OneMouse。
  • 公开后的 Mac 无法输入时 → 在 Mac 的系统设置 → 隐私与安全性 → 辅助功能中允许 OneMouse。

排查顺序

请按这个顺序，一步步确认。

1

开关与权限

确认 Windows 主设备与目标设备上的应用都已打开。Android 需要无障碍服务；Mac 接收输入必须允许辅助功能，macOS 15+ 使用 LAN 发现时还需允许本地网络。

2

同一网络·发现

看看 Windows 与手机或 Mac 是否在同一个 Wi-Fi（同一个 Wi-Fi 路由器）下。搜索不到时，多半是网络不同、权限未允许或发现被拦截了。

3

防火墙·隔离

手机能看到电脑、电脑却看不到手机时，可能是 Windows 防火墙入站（网络是“公用”还是“专用”）的问题。公司、咖啡馆的 Wi-Fi 有时会因客户端隔离而被拦截。

4

配对·连接

Android 请确认 QR 或 6 位代码配对。Mac 公开版发布后，将在 Windows 设备管理中输入Mac 上显示的 6 位代码。

5

输入·返回

把鼠标推向布局中设定的边缘，看是否能越过去；越不过去就检查位置布局。光标跑到别处时，用 Ctrl+Alt+Backspace 让它返回。

传输

文件和剪贴板不工作时。

  • 确认选中的设备是否正确 —— 传输会发往你选定的目标。
  • Windows PC 之间的边界拖放需要辅助设备已连接并完成布局；Mac 边界拖放仍在公开前真机验证中。
  • 要抓着文件越过布局中的屏幕边界，在目标上方松手，传输才会开始。
  • 剪贴板传不过来时，确认两端应用是否都处于已连接状态，或屏幕是否已息屏进入待机。
  • Bluetooth 比 Wi-Fi 慢 —— 大文件请用 Wi-Fi 发送。

Mac 排查 · 发布准备中

公开版推出后使用的预备检查项。

公证安装包与 Mac 真机验证尚未完成。

Windows 找不到 Mac。
确认 Mac 是 macOS 13+，两端 OneMouse 都已运行并连接到同一本地网络。macOS 15+ 请在系统设置 → 隐私与安全性中允许 OneMouse 使用本地网络；macOS 13/14 可能不会显示该项目。发现和选择操作应在 Windows 主设备上进行。
已经配对，但鼠标和键盘无法控制 Mac。
Mac 只能作为辅助设备。请在系统设置 → 隐私与安全性 → 辅助功能中开启 OneMouse，然后回到应用确认状态已更新；不需要把 Mac 改成主设备。
6 位配对代码应该输入到哪一端？
代码显示在 Mac 上。请在 Windows OneMouse 的设备管理中选择该 Mac，再输入 Mac 显示的 6 位代码。
Windows 上看不到 Mac 屏幕或窗口。
只有使用这项功能时才需要在 Mac 允许屏幕录制。允许后停止并重新开始屏幕或窗口共享；该功能需要 LAN，不通过 Bluetooth 提供画面传输。
为什么 Mac 下载按钮显示“即将推出”？
macOS 13+ 客户端目前仅作为辅助设备，Developer ID 公证安装包尚未公开。请勿把开发构建当作正式发布版。

常见问题

大家最常遇到的问题。

每隔 10 秒左右就一直断开。
主要有四个原因：① 访客/公司 Wi-Fi 的客户端隔离、② 电池优化切断了手机的后台连接、③ Windows 防火墙拦截入站、④ 屏幕息屏后 Wi-Fi 进入省电（休眠）。请开启电池优化例外，在防火墙中允许 OneMouse 入站，尽量使用私人 Wi-Fi。
手机能看到电脑，但电脑看不到手机。
多半是 Windows 防火墙入站的问题。如果当前网络是“公用（Public）”，入站可能被拦截，请改为“专用（Private）”，或在防火墙中允许 OneMouse 的入站。
在家能用，但在公司、咖啡馆的 Wi-Fi 用不了。
公用/访客 Wi-Fi 为了安全，常会隔离设备之间的通信（客户端隔离）。这种情况下，即使是同一个 Wi-Fi 也彼此找不到。请改用 Bluetooth 连接或个人热点。
说是连上了，可鼠标、键盘不起作用。
很可能是 Android 的无障碍服务被关闭或被系统重启了。请在 Android 设置 → 无障碍中重新开启 OneMouse。
光标卡在手机/另一台电脑上回不来。
按 Ctrl+Alt+Backspace，光标会强制返回到自己电脑的显示器中央。
屏幕一息屏，连接就断了。
屏幕息屏时，手机的 Wi-Fi 可能进入省电，或应用因电池优化而休眠。在 Android 中把 OneMouse 设为电池优化例外会更稳定。也请查看连接期间的防止息屏选项。
用 Bluetooth 远程控制屏幕不太顺畅。
手机屏幕的远程控制数据量大，不建议在 Bluetooth 上使用。远程控制请用 Wi-Fi。Bluetooth 适合鼠标、键盘、剪贴板和文件。
