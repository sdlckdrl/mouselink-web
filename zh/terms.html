使用条款

这些条款说明使用 OneMouse 应用和网站的基本条件。

生效日期：2026年8月5日

01

服务概述

OneMouse 由 Windows 10/11 端发起并管理连接，通过本地网络或受支持的 Bluetooth 连接 Android 和另一台 Windows PC，并通过 LAN 连接 macOS 13+ Apple 芯片 Mac。

02

本地网络与权限要求

通常要求 Windows 端与连接目标处于同一本地网络。访客 Wi-Fi、AP 隔离、防火墙和安全软件可能会阻止连接。Mac 接收输入需要“辅助功能”；macOS 15+ 使用 LAN 发现时还需允许“本地网络”，macOS 13/14 可能不会显示该项目。Mac Bluetooth 不属于当前公开支持范围；Mac 屏幕或窗口共享仅支持 LAN，并需要“屏幕录制”。

03

Free / Pro

Free 与 Pro 的购买、试用和限制政策适用于相应 Android 发行版。Windows 不处理购买；Mac 不继承 Android 的 Pro 权益。

04

结算

适用的 Pro 购买和恢复使用 Google Play Billing，仅在 Android 应用中提供。应用不展示广告。Windows 与 Mac 不使用这些 SDK。

05

限制

OneMouse 依赖网络状态、操作系统权限、安全软件和设备厂商行为，无法保证在所有环境中持续连接或传输。Mac 屏幕或窗口共享需要 LAN。

06

Mac 的连接与可用性

macOS 13+ Apple 芯片 Mac 与 Android、另一台 Windows PC 同为连接目标，连接由 Windows 端发起并管理。Mac 的当前公开支持使用 LAN；当前公开版不支持 Mac Bluetooth。
