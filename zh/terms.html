使用条款

这些条款说明使用 OneMouse 应用和网站的基本条件。

生效日期：2026年7月28日

01

服务概述

OneMouse 目前由 Windows 10/11 端发起并管理连接，通过本地网络或受支持的 Bluetooth 连接 Android 和另一台 Windows PC。macOS 13+ Mac 支持将在公证发布与真机验证完成后提供。

02

本地网络与权限要求

通常要求 Windows 端与连接目标处于同一本地网络。访客 Wi-Fi、AP 隔离、防火墙和安全软件可能会阻止连接。计划中的 Mac 版接收输入需要“辅助功能”；macOS 15+ 使用 LAN 发现时还需允许“本地网络”，macOS 13/14 可能不会显示该项目。Bluetooth 连接需允许 Bluetooth 访问；Mac 屏幕或窗口共享仅支持 LAN，并需要“屏幕录制”。

03

Free / Pro

Free 与 Pro 的购买、试用和限制政策适用于相应 Android 发行版。Windows 不处理购买；计划中的 Mac 版不继承 Android 的 Pro 权益。

04

广告和结算

仅 Android 发行版的 Free 模式广告通过 Google Mobile Ads SDK 显示，适用的 Pro 购买和恢复使用 Google Play Billing。Windows 与计划中的 Mac 版不使用这些 SDK。

05

限制

OneMouse 依赖网络状态、操作系统权限、安全软件和设备厂商行为，无法保证在所有环境中持续连接或传输。Mac 屏幕或窗口共享需要 LAN。

06

Mac 的连接与可用性

macOS 13+ Mac 与 Android、另一台 Windows PC 同为连接目标，连接由 Windows 端发起并管理。Mac 客户端的 Developer ID 公证安装包尚未公开；网站上的“即将推出”不代表已经可以下载或正式发布。
