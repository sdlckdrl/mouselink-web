先看这三点

  • 找不到光标时 → 按 Ctrl+Alt+Backspace，光标会回到自己的电脑（显示器中央）。

按症状查找

现在遇到了哪种情况？

展开对应项目，从上往下检查。无需先删除现有登录信息或配对记录。

显示已连接，但光标无法移到手机
  1. 无障碍：在 Android 设置 → 无障碍 → 已安装的应用（或已下载的应用）→ OneMouse 中确认服务已开启。已开启仍无法输入时，请关闭后重新开启。使用 Test 应用时，请检查 OneMouse Test。
  2. 设备布局：在 PC 的手机布局中，确认目标设备位于屏幕的哪个方向。让设置与手机实际位置一致，可以避免混淆。
  3. 进入通道：从所设方向的通道移过去。如果通道位于边缘中央，从屏幕角落无法通过。查看布局画面
  4. 应用版本：将 PC 和 Android 更新到最新公开版本，并重新启动两端的 OneMouse。也请确认无障碍服务仍保持开启。

找不到光标时，可按默认快捷键 Ctrl + Alt + Backspace 返回 PC。如果改过快捷键，请使用自己设置的组合键。

Google 账号中看不到设备或无法连接
  1. 确认两端 OneMouse 使用同一 Google 账号邮箱，并检查两台设备的互联网连接和应用运行状态。
  2. 刷新设备列表并连接目标设备。若出现确认请求，请在对方设备上允许。账号连接步骤
  3. 若提示重新验证 Google 账号，请进行登录确认。若提示无法创建更多连接，请关闭不使用的远程画面或连接，稍候重试。从账号中移除设备与结束连接是不同的操作。

若要在同一 Wi-Fi 下免登录连接，也可以选择二维码或号码配对。账号连接并不要求两台设备连接同一路由器。

手机能看到 PC 画面，但无法操作
  1. 确认远程画面控制面板中的仅查看已关闭。
  2. 触摸模式会点击触摸的位置；光标模式则先用手指滑动来移动指针，再轻点。
  3. 如果 PC 上显示控制请求，请允许。确认 PC 和 Android 均为受支持的最新版本。仅连接 Bluetooth 时，无法打开远程视频画面。

排查顺序

请按这个顺序，一步步确认。

1

开关与权限

确认两端应用已启动。输入权限请看先看这三点。

2

连接方式与网络

Google 账号：检查同一账号和两端的互联网连接。二维码/号码：确认处于同一路由器的 Wi-Fi/LAN。Bluetooth：确认两端系统设置中的 Bluetooth 已开启。

3

防火墙·隔离

手机能看到电脑、电脑却看不到手机时，可能是 Windows 防火墙入站（网络是“公用”还是“专用”）的问题。公司、咖啡馆的 Wi-Fi 有时会因客户端隔离而被拦截。

4

配对·连接

在设备管理中确认配对和连接状态。首次连接请看连接指南。

5

输入·返回

检查布局方向和设置的光标进入通道。请按输入检查步骤排查；找不到光标时，请查看返回方法。

传输

文件和剪贴板不工作时。

  • 确认选中的设备是否正确 —— 传输会发往你选定的目标。
  • Windows PC 之间或 Windows 与 Mac 的边界拖放需要目标电脑已连接并完成布局；Mac 边界拖放使用 LAN。
  • 要抓着文件越过布局中的屏幕边界，在目标上方松手，传输才会开始。
  • 剪贴板传不过来时，确认两端应用是否都处于已连接状态，或屏幕是否已息屏进入待机。
  • Bluetooth 比 Wi-Fi 慢 —— 大文件请用 Wi-Fi 发送。

手机通知

手机通知没有显示在电脑上时。

  • 在手机应用设置的发送到电脑的通知里打开发送通知到电脑，并确认通知访问权限为已允许。
  • 确认该应用在发送到电脑的应用列表里。默认是短信应用和 KakaoTalk，也可以选择所有应用。
  • 在主电脑的设置 → 通知中，确认显示设备通知已开启。
  • 如果只有验证码短信以“已隐藏”送达，那是 Android 15 及以上的保护机制。在手机应用的验证码通知区块点按注册电脑一次即可。只需在注册时打开蓝牙。
通知历史保存与删除

通知短暂显示，历史记录在电脑本地加密保存，不上传服务器。仅记录启用后收到的通知，不保存验证码及隐藏的敏感内容。

历史默认开启、7天、最多200条。主电脑设置 → 通知可选1天/7天/30天或停止新记录。已有记录仍保留，可通过全部删除清除。

连接与输入

设备使用同一个 Google 账号，为什么有一台不显示？

在两台设备上打开 OneMouse，确认两台设备均已联网，并登录了同一个 Google 账号，然后刷新设备列表。如果设备已显示，但鼠标指针无法移过去，请分别检查连接状态和设备布局。 Google 账号连接

为什么连接总是断开？

屏幕亮起时，检查两台设备是否仍连接到您要使用的网络，以及问题是否只在使用某台路由器时出现。如果只在熄屏后断开，请检查 Android 的电池设置，不要仅凭多久断开来判断原因。 局域网自动重连

为什么手机能看到电脑，电脑却看不到手机？

如果使用局域网发现设备，请确认两台设备都已打开 OneMouse，并连接到同一台路由器。检查 Windows 防火墙是否允许 OneMouse 在这个可信网络上通信。请勿关闭防火墙，也不要把公共网络设为专用网络。

为什么在家能配对，在办公室或访客 Wi-Fi 上却不行？

即使连接到同名 Wi-Fi，某些网络也会阻止设备之间通信。使用同一 Google 账号能看到设备，并不保证该网络支持所有功能。可改用允许设备互通的可信网络，或在设备组合支持时使用蓝牙（测试版）。

显示已连接，为什么在 Android 上无法使用鼠标和键盘？

在 Android 上打开「设置」→「无障碍」→「已安装的应用」，检查 OneMouse。如果已开启但服务仍显示断开，请关闭后重新开启。在电脑的设备布局中，确认鼠标指针经过了标记的进入区域。 设置 Android 输入

列表里有 Mac，为什么无法点击或输入？

在 Mac 上打开「系统设置」→「隐私与安全性」→「辅助功能」，检查 OneMouse。授予权限后重新打开 OneMouse，再把指针移到 Mac 上，试着在普通文本框里输入。 Mac 权限

为什么 Mac 的屏幕或窗口显示为黑色？

在 Mac 上检查 OneMouse 的「屏幕录制」权限。某些 macOS 版本称其为「屏幕与系统音频录制」。如果更改了权限，请按 macOS 的提示重新打开应用，然后重新开始共享。 Mac 屏幕录制权限

怎样让鼠标指针回到电脑？

在 Windows 上，默认的紧急返回快捷键是 Ctrl + Alt + Backspace。如果修改过，请使用保存的快捷键。如果禁用了快捷键，请将指针移过用于返回的屏幕边缘。 返回快捷键设置

为什么只在 Android 熄屏后断开连接？

检查 Android 是否限制 OneMouse 在后台使用电池。如果手机提供相关设置，可以试着将 OneMouse 的电池使用设为「不受限制」。具体的选项名称和行为因厂商而异。

使用蓝牙（测试版）时，应该先检查什么？

蓝牙不需要 Wi-Fi 或预先注册 LAN。先在系统设置中配对，再到 OneMouse 中开启连接。

确认蓝牙已开启，且受支持的设备已在 OneMouse 中配对并连接。如需使用远程屏幕，请采用设备组合对应的连接方式。蓝牙能传输基本的鼠标和键盘输入，并不代表它支持屏幕共享。 按设备组合查看支持范围

为什么在 Windows 上无法调整设备顺序？

在主电脑的“设备管理”中，若列表中有至少两台可调整顺序的已注册设备，请查找“编辑列表顺序”。支持编号快捷键的设备会按列表顺序排列，屏幕布局不变。蓝牙设备不参与排序。 设备列表排序指南

通知、文件与截图

为什么在电脑上无法回复通知？

确认 Android 上的原始通知提供回复框，并且仍然有效。在主电脑上，请从当前显示的通知尝试回复，不要从历史记录回复。被隐藏的通知或敏感通知不支持回复。如果回复超时，请先查看原应用，再重试。 电脑和 Android 两端都需要支持回复的应用版本。“已传给手机应用”只表示回复已交给原始应用，并不代表对方确认接收。 通知和回复设置

为什么从手机分享的文件没有传到电脑？

蓝牙连接已启用时，优先使用当前连接的电脑。否则，请在 Android 版 OneMouse 中确认 Wi-Fi 或局域网的默认电脑已配对、可用且为主电脑。若默认电脑不可用，可在文件分享界面选择其他符合条件的已配对电脑。 从手机向电脑发送文件和文本

在 Windows 上收到的文件保存在哪里？

在 OneMouse 中打开「设置」→「常规」→「文件传输」，查看接收文件夹。如果无法打开该文件夹，请尝试选择已连接驱动器上可写入的文件夹。更改位置不会移动已接收的文件。截图保存在单独的位置。 更改接收文件夹

为什么截图预览会关闭，或者鼠标指针没有返回？

两台设备均支持时，截图可以让指针留在被控设备上，而不是强制返回。将指针移回来即可操作预览。复制或保存成功后，预览会关闭；取消保存或保存失败时，预览会保留。

鼠标手势与远程窗口

为什么在 Windows 远程窗口里无法使用浏览器手势？

在 Windows 远程窗口中按住鼠标右键拖动时，操作会转发到远程设备。如果目标浏览器支持手势，请在该浏览器中启用。这与直接控制 Android 时使用的 OneMouse 手势是两项不同的功能。 远程窗口指南

怎样在 Android 上使用 OneMouse 鼠标手势？

在 Android 版 OneMouse 中打开「设置」→「输入与剪贴板」，开启鼠标手势，并允许在目标应用中使用。将电脑的指针移到 Android 上，按住鼠标右键画出手势，然后松开。Android 系统界面和权限设置界面不支持手势。 此 Android 手势不适用于 Windows、Mac 或单独打开的远程窗口。 鼠标手势指南

为什么部分 Android 应用不支持「前进」或「重新加载」？

「前进」会回到执行「后退」前所看的页面，不会跳到信息流中的下一项。「重新加载」依赖兼容的浏览器控件，即使已允许在该应用中使用手势，某些界面也可能不支持。

先向下、再向右画，会关闭 Android 应用吗？

不会。先向下画，再转向右侧，然后松开鼠标右键。这样会返回主屏幕，不会关闭应用或标签页。先向上、再向右会打开最近使用的应用列表。斜着画不等于这个手势。

怎样控制或停止 Android 上的滚动手势？

在正文区域向上或向下绘制，然后松开鼠标右键。绘制时不会滚动。笔画越长滚动越多，越短滚动越少，实际距离因应用而异。箭头和竖向指示条表示方向和笔画强度，并非文档位置。长距离滚动最多 8 屏或 10 秒。点击、开始新手势、切换应用或结束控制可以取消剩余滚动。仅移动光标不会停止。
