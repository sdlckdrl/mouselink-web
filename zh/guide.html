5 分钟连接

首次连接只要照着这个顺序做就行。

以下按 PC 与 Android 当前界面说明首次连接步骤，适用于同一 Wi-Fi 下的 LAN 配对。控制 Android 需要无障碍权限。Mac 请参阅Mac 连接指南。

选择 Google 账号连接时

在 PC 和 Android 两端登录同一 Google 账号，然后查看账号设备列表。Google 登录是可选的；下方通过二维码或 6 位代码进行的 LAN 配对无需登录。

1

打开两端应用并连接同一 Wi-Fi

在 Windows 和 Android 上运行 OneMouse，并连接同一 Wi-Fi。

2

允许 Android 无障碍服务

要接收 PC 的操作，请在 Android 上开启 OneMouse 无障碍服务。Android 13 及以上系统可能还会请求“附近 Wi-Fi 设备”权限，以搜索 PC。

3

打开 PC 的二维码和验证码

在 PC 上打开设备管理 → 其他连接方式 → 此 PC 的二维码和验证码，查看当前显示的 6 位代码或二维码。

4

从手机添加 PC

在 Android 首页打开其他连接方式 → 通过二维码或配对码添加 PC。可在号码代码页输入 6 位代码并点击连接，或在二维码扫描页点击打开相机扫描 PC 上的二维码。任选一种即可。

5

确认 PC 已注册且连接正常

在 Android 的已注册PCs列表中确认目标 PC 已出现，并检查连接状态。

6

设置手机位置并开始使用

在手机布局中选择手机实际放置的方向。将鼠标移到 PC 屏幕对应边缘，即可用 PC 鼠标和键盘操作手机。

查看最新版配对界面PC 代码 → 手机添加 → 数字代码或二维码

方式 A 和方式 B 二选一，无需先输入代码再扫描二维码。

图片中的代码和设备名称仅为示例，请使用您自己的 PC 应用当前显示的代码。 点击图片可查看原图。

在布局界面将各设备拖到实际摆放的位置。光标会从对应的屏幕边缘移入。

远程控制

从设备管理打开远程画面。

在设备管理中，点击已配对 Android 那一行的远程控制图标，就会打开一个显示手机画面的独立窗口。首次打开时需要授权 Android 屏幕捕获。

Android 窗口中的操作

  • 左键点击、拖动、滚轮会被原样传递。
  • 右键 = 返回，滚轮点击 = 主屏。
  • PC 键盘（含中文）会输入到手机当前的输入框。
  • 如果画面看起来是空的，请确认捕获授权弹窗，并把远程控制关掉再打开。

Windows 远程窗口支持按住右键拖动

在设备管理中点击远程控制图标，或使用默认的 Ctrl+Alt+Shift+1~9 打开窗口。 按住右键拖动可使用目标 PC 浏览器已配置的手势扩展，与 Android 自带手势不同。

在手机上打开 PC 画面并进行操作。

查看 PC 画面的同时，可以触控点击、移动光标，也能用手机键盘输入文字。 PC 和 Android 都需要支持此功能的最新应用版本。

打开远程屏幕

  1. 在 PC 上运行 OneMouse。通过同一 Wi-Fi 配对，或使用同一 Google 账号连接设备。
  2. 在 Android 应用的已注册 PC 列表中，点击目标 PC 的远程屏幕。
  3. 在 PC 上确认请求后点击允许。如果以后还要从自己的手机连接，可以选择 始终允许此设备。
  4. 画面连接后即可触控操作。点击右侧设置图标可打开控制面板。

选择适合自己的操作模式

  • 触控模式：点击画面中的目标位置，按住并移动即可拖动。
  • 光标模式：滑动手指移动指针，轻点即可单击。
  • 长按可执行右键操作。光标模式下，轻点两次并在第二次按住，即可拖动。
  • 双指张合可缩放画面。在 1 倍缩放下，双指滑动会滚动 PC 内容；放大后，双指滑动会 移动当前查看的画面。
  • 使用键盘输入文字；只想观看时，可开启仅查看。

画质、帧率与结束连接

可在控制面板中选择画质和最大帧率。支持画质切换的 PC 可保持连接并应用新设置。 实际分辨率和帧率取决于设备性能与网络状况。

结束时点击控制面板 → 断开连接。结束远程连接后，PC 仍会保持开机。 Bluetooth 连接不传输远程视频。

Android鼠标手势

按住右键绘制，快速完成操作。

查看启用方法、7种手势及支持范围。

1. 启用手势

在设置 → 输入 · 剪贴板中启用鼠标手势并选择应用（默认关闭）。PC和Android都需要支持手势的版本。

选择所有应用可在应用和主屏幕使用手势。 查看支持范围

2. 按住、绘制、松开

将PC光标移到Android手机或平板，打开已选应用。

  1. 在页面内容上按住鼠标右键。
  2. 按显示的方向顺序绘制，在红色轨迹旁确认操作。
  3. 松开后执行操作；绘制时页面不会滚动。

箭头和竖向量条表示方向及绘制长度对应的滚动强度，而非页面位置或精确移动距离。

手势操作
← 返回向左绘制以返回上一页或上一个界面。
→ 前进向右绘制，恢复返回前的页面。
↑ 向上滚动向上绘制并松开；笔画越长滚动越多，越短滚动越少。
↓ 向下滚动向下绘制并松开；笔画越长滚动越多，越短滚动越少。
↓ → 最小化应用返回主屏幕，但不关闭正在使用的应用。
↑ ↓ 刷新在支持此功能的浏览器中刷新当前页面。
↑ → 最近应用打开最近应用列表，选择另一个应用。

手势无效时

  • 用于Android直接控制，不适用于Windows、Mac或镜像窗口。
  • 前进恢复历史页面；前进和刷新需要浏览器支持。
  • 在页面内容上开始滚动；短暂右击且不移动时保留原有行为。
  • 实际滚动距离因应用而异；主屏幕和应用列表只滑动一次。

文件与剪贴板

文件可通过传输界面、快速拖放区或电脑间边界拖动来发送。

  • 把文件放到传输界面或屏幕上的小拖放区，就会发送到选定的 Android、Windows PC 或 Mac。
  • Windows PC 之间或 Windows 与 Mac 的 LAN 连接可拖着文件越过布置好的屏幕边界，放到目标设备上即可传输（目标需已连接并完成布局）。
  • 从 Android 发送到 PC
  • 如果无法开始，请检查连接状态和所选的设备。

快速拖放区

  • 用 Ctrl+Alt+D 隐藏或显示拖放区。
  • 位置和状态会保存在 PC 应用中。

截图与发送

截取需要的部分，发送到要使用的设备。

不仅能截取本机 PC 画面，也能截取正在控制的其他设备画面。在预览中复制、保存， 或发送到已连接设备的剪贴板。

截图与发送步骤

  1. 在 Windows 上按默认快捷键 Ctrl+Alt+S。如果正在控制另一台设备，就截取该设备 的画面；如果没有控制其他设备，则截取本机 PC 画面。
  2. 拖动选择需要的区域，或点击工具栏中的全屏。
  3. 在 PC 上弹出的预览小窗中点击复制或保存。若要在另一台设备上使用， 点击发送并选择接收设备。
  4. 在接收设备上打开支持图片粘贴的应用，然后粘贴。

如果修改过快捷键，请使用自己设置的组合键。选择区域时按 Esc 或点击取消， 即可关闭截图而不发送图片。

检查连接与权限

  • 图片发送需要 Wi-Fi/LAN 连接，且两端应用都支持此功能。仅通过 Bluetooth 连接的 设备不能作为发送目标。
  • 截取 Android 画面需要 Android 11 或更高版本及无障碍权限；截取 Mac 画面需要 屏幕录制权限。受保护的画面可能无法截取。
  • 发送到 Android 的图片应在支持粘贴的应用中使用。发送后不会自动粘贴，也不会自动保存到相册。

手机 → PC

把手机中选好的文件和文本发送到 PC。

通过 LAN 发送时，请先在移动应用的首页选择默认 PC，并确认已配对、连接。 文件可从传输标签或 Android 分享菜单发送；文本可从选择菜单中的 OneMouse to PC 发送。

发送文件

  1. 在移动应用的传输标签中，点击选择文件并发送到 PC。
  2. 选择要发送的文件后，会发送到当前选中的 PC。
  3. 在照片或文档应用中，也可以点击分享并选择 OneMouse。

发送文本

  1. 在 Android 中长按并选择文本，然后打开更多。
  2. 点击OneMouse to PC，文本会发送到 PC 剪贴板。
  3. 若第一次没有显示，请先在应用管理中启用一次 OneMouse，再重新选择。

在 PC 上查找收到的文件

在 PC 的设置 → 常规 → 文件传输 → 接收文件保存位置中，点击更改文件夹 选择保存位置，点击打开文件夹查看。主、副电脑均可使用。

通知与回复

在 PC 上查看手机通知，并回复支持的通知。

接收通知与查看历史记录

在 Android 应用中启用向 PC 发送通知，允许通知访问权限，并选择要发送通知 的应用。在主电脑的设置 → 通知中启用设备通知显示。

同一界面可查看通知历史和保留设置。 通知设置详情

回复实时通知

PC 和 Android 均支持回复，且手机原始通知提供自由文本回复时，才显示回复。 输入后点击发送或按Ctrl+Enter，由手机原应用发送（Enter换行）。

没有回复按钮或无法发送时

数字快捷键

用设备列表的编号直接连接。

Ctrl + Alt + 1~9

  • 默认情况下，主电脑设备列表前 9 个 LAN 设备会绑定 Ctrl+Alt+1~9。修改按键请参阅快捷键说明。
  • 按下编号就会连接到对应设备。
  • 再次按当前正在控制设备的同一编号，即可解除输入控制。

自动重连

  • 开启后，当上次的设备再次出现，或只有一个已就绪的设备时，PC 应用会自动重新连接。

更改设备顺序与快捷键编号

主电脑上有至少两台 LAN 设备时，点击设备管理 → 编辑顺序。拖动手柄或使用 ↑/↓ 按钮移动，自动保存后点击完成。连接和远程窗口快捷键使用相同的设备顺序。

找不到编辑顺序时

Bluetooth

没有 Wi-Fi 路由器，也能用 Bluetooth 连接。

Windows 可通过 Bluetooth 与 Android 或另一台 Windows PC 交换输入、剪贴板和文件。

这些情况很好用

  • 没有共享 Wi-Fi 的房间、户外、车里
  • 访客 Wi-Fi 或防火墙挡住设备搜索时
  • 以键盘、剪贴板为主的轻度使用

须知

  • 大文件和移动端远程画面建议使用 Wi-Fi 或 LAN。
  • Mac 蓝牙为测试版（在应用设置中开启，默认关闭）。官方支持为 LAN，Mac 屏幕和窗口共享仅支持 LAN。

另一台 PC

Windows PC 之间按设备管理 → 连接 → 布局的顺序接入。

建立连接

  • 在两台 Windows PC 上运行 OneMouse。登录同一 Google 账号，或将两台 PC 接入同一网络以进行 LAN 配对。
  • 通过 LAN 连接时，在控制端 PC 的设备管理 → 其他连接方式中选择另一台 Windows PC，输入其 6 位代码并点击配对。代码可在另一台 PC 的设备管理 → 其他连接方式 → 此 PC 的二维码和验证码中查看。LAN 配对无需登录。
  • 确认已注册 PC 的连接状态，必要时开启连接开关，然后在布局编辑器中按设备的实际位置摆放。
  • 朝对应方向移过鼠标即可控制另一台 PC，也可将文件拖过边界来互传。

Mac 连接目标 · 公开支持

从 Windows 选择 Mac，再输入 Mac 上显示的 6 位代码。

在 Apple 芯片 Mac 上安装公开 DMG，再从 Windows OneMouse 发起并管理 LAN 连接。按以下 5 步完成设置。

1

在 Windows 和 Mac 上打开公开版 OneMouse

让 Windows 端与 macOS 13+ Apple 芯片 Mac 连接到同一个本地网络，并在两端运行 OneMouse。

2

在 Mac 上允许必要权限

“辅助功能”是接收 Windows 鼠标和键盘输入所必需的。macOS 15+ 还需允许“本地网络”；macOS 13/14 可能不会显示该项目。

3

在 Windows 上选择找到的 Mac

连接由 Windows 端发起并管理；请在 Windows OneMouse 的设备管理中从发现列表选择这台 Mac。

4

在 Windows 输入 Mac 显示的 6 位代码

查看 Mac OneMouse 窗口中的 6 位配对代码，并把该代码输入 Windows。配对完成后，Mac 会作为连接目标出现在设备管理中。

5

布置位置并开始使用

在 Windows 的布局编辑器中把 Mac 放到实际方向，随后把鼠标移过对应边缘。只有要在 Windows 查看 Mac 屏幕或窗口时，才需要在 Mac 额外允许“屏幕录制”。

权限

Android 与 Mac 所需的权限不同。

Android 输入需要无障碍服务，Mac 输入需要“辅助功能”。 查看 Android 或 Mac 的远程画面还需要单独批准屏幕捕获或录制。

键盘快捷键及适用条件。

以下 PC 快捷键是默认值。可在 PC 设置 → 快捷键中更改组合、单独关闭某项或关闭全部快捷键。如果更改过，请使用已保存的组合。

Windows 应用默认快捷键

默认快捷键 操作与条件
Ctrl+Alt+1~9 主电脑：连接列表中对应设备的输入控制。再次按当前正在控制设备的同一编号，解除该设备的输入控制。
Ctrl+Alt+Shift+1~9 主电脑：打开对应设备的远程窗口，或将已打开的窗口置于前台。再次按下不会关闭窗口。 与连接快捷键使用相同的 LAN 设备编号；Bluetooth 设备不参与编号。

用 Windows 键盘控制 Mac 时

默认 Windows 快捷键映射将 Ctrl 作为 Command、Alt 作为 Option 发送。可在 Mac 应用的键盘设置中改为 Mac 原生修饰键映射。这并不表示要把上方 Windows 应用快捷键的 Ctrl 改成 Command。
