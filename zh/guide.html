推荐 · 连接到同一个路由器

连接 Android 手机或平板

二维码和 6 位数验证码任选一种即可。电脑使用网线也可以，只要连接到同一个路由器。无需登录 Google。 使用 Google 账号连接 · 通过蓝牙连接（测试版）

  1. 打开应用并开启 Android 无障碍服务

    在 Windows 和 Android 上 安装 OneMouse，并连接到同一个路由器。接着在手机上按以下步骤开启 OneMouse 的 无障碍服务。以下以三星 Galaxy 为例，菜单名称可能因设备和 Android 版本而异。

  2. 在 Windows 上打开二维码和验证码

    设备管理 → 通过其他方式连接 → 本机二维码和验证码。

  3. 在 Android 上输入验证码或扫描二维码

    首页 → 通过其他方式连接 → 用二维码或验证码添加电脑。 数字验证码中输入验证码，或选择 扫描二维码 → 打开相机并扫描电脑屏幕。 “用二维码或验证码添加电脑”按钮的位置（韩语界面）

  4. 按设备的实际位置摆放布局并移过去

    在 Android 首页的 已注册的电脑中确认连接。在 Windows 中按手机或平板的实际摆放方向调整布局，然后把光标移向那一侧屏幕边缘的切换区域。

其他连接方式：蓝牙（测试版）

通过蓝牙连接（测试版）

打开两台设备的蓝牙。在 Android OneMouse 中选择 启动蓝牙模式，然后在 Windows 的蓝牙设置中配对设备。连接后，在 OneMouse 的设备列表中确认状态与布局。蓝牙不能传输远程视频。

各连接方式的功能范围

推荐 · 连接到同一个网络

从 Windows 连接 Mac

需要搭载 Apple 芯片且运行 macOS 13 或更高版本的 Mac。将两台设备连到同一个路由器的 Wi-Fi 或有线网络，即可免登录使用。 使用 Google 账号连接 Mac · 通过蓝牙连接（测试版）

  1. 在 Windows 和 Mac 上打开应用

    安装 OneMouse，并在两台设备上打开。请在 Windows 上发起连接。

  2. 在 Mac 上授予辅助功能权限

    要让 Mac 接收 Windows 的鼠标和键盘输入，请在 Mac 上授予 辅助功能权限。界面布局可能因 macOS 版本而异。

    如果列表中没有 OneMouse，请点击 +并添加已安装的 OneMouse。在 macOS 15 或更高版本中，如果系统请求访问 本地网络 ，也请允许。

  3. 在 Mac 上查看验证码，在 Windows 上输入

    在 Mac OneMouse 的 设备管理 → 通过其他方式连接 → 查看这台 Mac 的验证码中查看验证码。再打开 Windows OneMouse 的 设备管理 → 通过其他方式连接，在“同一 Wi-Fi · 配对”部分找到 Mac，输入 6 位数验证码，然后点击 配对。

    使用你自己的 Mac 上显示的验证码，不要使用示例中的数字。

  4. 将光标移向 Mac 所在的一侧

    在 Windows 的布局界面中按 Mac 的实际摆放方向设置位置，再把光标移向该侧的屏幕边缘。

列表中找不到 Mac？ 确认两台设备连接到同一个网络，并检查 macOS 请求的本地网络权限。 排查 Mac 连接问题
通过蓝牙连接 Windows 和 Mac（测试版）

此方式每次直连一台设备。无需连接同一个 Wi-Fi，也无需登录 Google。请先在两台设备各自的系统蓝牙设置中完成配对。

在 Mac OneMouse 的 设备管理 → 通过其他方式连接，展开后在 Bluetooth 卡片上点击 开启。连接期间，卡片可能会直接出现在“设备管理”中。

  • 从 Windows 控制 Mac： 将 Mac 的输入方向切换为 接收鼠标和键盘输入，然后在 Windows 的 设备管理蓝牙列表中开启 Mac 的连接。
  • 从 Mac 控制 Windows： 在 Windows 的 设备管理 → 通过其他方式连接 → 蓝牙中开启 接收鼠标和键盘输入。然后将 Mac 的输入方向切换为 发送鼠标和键盘输入，再从列表中选择 Windows 电脑。

Mac 接收输入时需要 辅助功能 权限；发送输入时还需要 输入监控 权限。支持鼠标和键盘、文字剪贴板以及文件和文件夹传输。

Mac 屏幕和窗口共享仅支持 Wi-Fi 或有线局域网，无法通过蓝牙查看屏幕或窗口。

也需要授权屏幕录制吗？

只用鼠标和键盘时不需要。 如果要在 Windows 上查看 Mac 的屏幕或窗口，或用 OneMouse 在 Mac 上截图，请在 相关 Mac上授权。

在 Mac 的 系统设置 → 隐私与安全性 → 屏幕与系统音频录制中开启 OneMouse。菜单名称可能因 macOS 版本而异。 远程画面指南

推荐 · 在同一网络中使用 6 位数验证码

连接另一台 Windows 电脑

从接有鼠标和键盘的电脑开始。两台电脑接入同一个路由器，即可免登录使用验证码连接。 使用 Google 账号连接另一台电脑 · 通过蓝牙连接（测试版）

  1. 在两台电脑上打开设备管理

    在接入同一个路由器的两台 Windows 电脑上 安装 OneMouse并打开应用，然后在左侧菜单中选择 设备管理。

  2. 在另一台电脑上查看验证码

    在要控制的电脑上，打开 设备管理 → 通过其他方式连接 → 本机二维码和验证码并查看 6 位数验证码。

  3. 在自己的电脑上选择并连接另一台电脑

    在自己的电脑上打开 设备管理 → 通过其他方式连接，选择另一台电脑并输入验证码。确认连接状态，必要时打开连接开关。

  4. 将光标移向另一台电脑

    在布局编辑器中按另一台电脑的实际摆放方向设置位置，再把光标移向对应的屏幕边缘。

通过蓝牙连接两台 Windows 电脑（测试版）
  1. 先在 Windows 的蓝牙设置中配对两台电脑。
  2. 在接收方电脑的 OneMouse 中，打开 设备管理 → 通过其他方式连接 → 蓝牙并选择 接收鼠标和键盘输入。蓝牙未开启时请先开启。
  3. 在发送方电脑的同一菜单中，按需切换为 发送鼠标和键盘输入，再在列表中打开接收方电脑的连接开关，并调整设备布局。

无需登录 Google，也不需要路由器。要查看远程画面，请使用同一个网络。

找不到另一台电脑？ 先确认两台电脑上的应用都在运行，而且都连到了同一个网络。 查看连接排查步骤

已经连接，但光标移不到另一块屏幕？

  1. 布局方向： 检查 Windows 中的设备布局是否与实际摆放方向一致。
  2. 切换区域： 将光标移向布局中标出的屏幕边缘区域。
  3. 接收设备的权限： 在 Android 上检查 OneMouse 的无障碍服务；在 Mac 上检查辅助功能权限。

如何通过 Google 账号找到自己的设备

Windows、Mac 和 Android 上的 OneMouse 都支持此方式。更新两端应用并接通互联网，然后使用 同一个 Google 账号登录。

Windows ↔ Windows

在两台电脑的 设备管理中登录。在连接鼠标的电脑上选中另一台电脑，必要时打开连接开关。

Windows → Mac

在 Windows 的 设备管理和 Mac 应用的 设备管理中登录。然后在 Windows 的设备列表中选择 Mac 并连接。 Windows 登录按钮的位置（韩语界面） · 要让 Mac 接收输入，请授予 辅助功能权限。

Windows → Android

在 Windows 的 设备管理和 Android 的 OneMouse 首页登录。在手机的 已注册的电脑中选中自己的电脑并连接，然后开启 Android 的 无障碍服务。

手机 → PC

把手机中选好的文件和文本发送到 PC。

通过 LAN 发送时，请先在移动应用的首页选择默认 PC，并确认已配对、连接。 文件可从传输标签或 Android 分享菜单发送；文本可从选择菜单中的 OneMouse to PC 发送。

发送文件

  1. 在移动应用的传输标签中，点击选择文件并发送到 PC。
  2. 选择要发送的文件后，会发送到当前选中的 PC。
  3. 在照片或文档应用中，也可以点击分享并选择 OneMouse。

发送文本

  1. 在 Android 中长按并选择文本，然后打开更多。
  2. 点击OneMouse to PC，文本会发送到 PC 剪贴板。
  3. 若第一次没有显示，请先在应用管理中启用一次 OneMouse，再重新选择。

在 PC 上查找收到的文件

在 PC 的设置 → 常规 → 文件传输 → 接收文件保存位置中，点击更改文件夹 选择保存位置，点击打开文件夹查看。主、副电脑均可使用。

键盘快捷键及适用条件。

以下 PC 快捷键是默认值。可在 PC 设置 → 快捷键中更改组合、单独关闭某项或关闭全部快捷键。如果更改过，请使用已保存的组合。

Windows 应用默认快捷键

默认快捷键 操作与条件
Ctrl+Alt+1~9 主电脑：连接列表中对应设备的输入控制。再次按当前正在控制设备的同一编号，解除该设备的输入控制。
Ctrl+Alt+Shift+1~9 主电脑：打开对应设备的远程窗口，或将已打开的窗口置于前台。再次按下不会关闭窗口。 与连接快捷键使用相同的 LAN 设备编号；Bluetooth 设备不参与编号。
Ctrl+Alt+D 显示 / 隐藏快速拖放区。
Ctrl+Alt+S 在正在控制的 Windows PC、Mac 或 Android 屏幕上选择区域，并在主电脑接收截图。不控制其他设备时，截取本机屏幕。两端应用都需支持此功能，目标设备还需具有截图权限。
Ctrl+Alt+V 主电脑：手机验证码通知显示在 PC 上期间，复制其中的验证码。请先开启手机通知转发。
Ctrl+V 接收并粘贴在另一台 PC 上复制的共享文件。没有待接收的共享文件时，仍可使用普通粘贴。
Ctrl+Alt+Backspace 主电脑：控制其他设备时，立即将光标返回本机显示器中央。

直接控制 Android 时

以下是发送给 Android 的输入组合，与上方 PC 应用快捷键设置不同。文本编辑效果取决于目标应用和输入框的支持情况。

默认快捷键 操作与条件
PrintScreen Android 11 及以上：直接控制手机时截取手机屏幕并发送到 PC。需要无障碍权限。
Alt+Shift+↑ / Alt+Shift+↓ 提高 / 降低 Android 屏幕亮度。需要修改系统设置的权限。
Alt+↑ / Alt+↓ 提高 / 降低 Android 媒体音量。
Alt+Tab / Alt+Shift+Tab 切换最近应用 / 反向切换。松开 Alt 后进入选中的应用。
Ctrl+A / Ctrl+C / Ctrl+X / Ctrl+V 在支持的输入框中全选 / 复制 / 剪切 / 粘贴。
Ctrl+Insert / Shift+Insert / Shift+Delete 在支持的输入框中复制 / 粘贴 / 剪切。
Ctrl+Z 在支持的应用和输入框中撤销操作。

用 Windows 键盘控制 Mac 时

默认 Windows 快捷键映射将 Ctrl 作为 Command、Alt 作为 Option 发送。可在 Mac 应用的键盘设置中改为 Mac 原生修饰键映射。这并不表示要把上方 Windows 应用快捷键的 Ctrl 改成 Command。
