如何使用手势

各功能的使用方法

选择想做的操作即可查看步骤。

发送文件或共享剪贴板文件、复制的文字和截图

发送文件

将文件放入传输标签或快速投放区（Ctrl+Alt+D），然后选择接收设备。也可以把文件拖过屏幕边缘，发送到受支持的 Windows 或 Mac。Android 上可使用传输标签，或在分享菜单中选择 OneMouse。

在电脑上查找接收的文件： 设置 → 常规 → 文件传输 → 接收文件保存位置 → 打开文件夹。

在另一台设备上使用复制的文字

在支持的连接中，可以在一台设备上复制文字、在另一台设备上粘贴。要从 Android 直接发送选中的文字，请打开选择菜单，点按更多 → OneMouse to PC。

只截取需要的区域

在 Windows 上按 Ctrl+Alt+S截取区域，在预览中复制或保存。可通过受支持的 Wi-Fi 或 LAN 连接发送，将收到的图片粘贴到支持图片的应用中。

文件、复制或截图不可用时

打开远程屏幕用手机操作电脑，或在电脑上查看已连接设备

在 Android 上打开 Windows

在两个受支持的应用中通过本地网络或 Google 账号连接。在 Android 的已注册电脑列表中打开 远程屏幕，如 Windows 显示请求，请批准。只需观看时，打开仅查看模式。

在 Windows 上查看已连接设备的屏幕

在设备管理中打开远程窗口。Android 需要在手机上批准屏幕捕获。共享 Mac 屏幕或窗口需要处于同一网络并授予屏幕录制权限。

Android 触控和指针操作

触控模式会点击点按的位置。指针模式下，先滑动移动指针，再点按。长按后松开可右击，在 1 倍缩放时用双指移动可滚动。

◎点按以点击↔滑动移动指针⇅双指滚动
通过 Android 游戏手柄操作电脑

受支持的 Windows 和 Android 应用可使用 Xbox 风格的屏幕游戏手柄或实体手柄。

蓝牙（测试版）不传输远程屏幕视频。受支持的应用可在控制面板中调整画质和帧率。

远程屏幕无法显示时

查看 Android 通知消息通知、复制验证码

在 Android 上允许读取通知并启用 将通知发送到电脑。选择要发送通知的应用，并在 Windows 端启用设备通知。历史通知和保存期限可在 Windows 端的应用设置中查看。

对于受支持的应用和通知，可以在电脑上回复或复制验证码。Android 的保护规则可能会隐藏部分通知或验证码。

看不到通知时

使用鼠标手势在 Android 上返回和滚动

此功能需要将指针移至 Android 屏幕。在两个受支持的应用中打开设置 → 输入和剪贴板 → 鼠标手势，选择适用的应用。默认关闭。

在 Android 屏幕上按住鼠标右键，按图示移动，然后松开。

● 圆点是起点，箭头指示移动方向。两段式手势按 1 → 2 的顺序连续绘制。

检查设备权限Android 无障碍、Mac 辅助功能、屏幕录制

Android 输入需要 无障碍权限，而 Mac 输入需要 辅助功能权限。在 macOS 15 或更高版本中，如果发现不了 Mac，请检查本地网络权限。打开远程屏幕时，屏幕捕获或录制需要单独授权。
