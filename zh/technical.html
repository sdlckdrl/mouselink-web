Local First

只在你配对过的设备之间运行。

输入、文件和剪贴板，只在你自己的 Windows 端与已配对的连接目标之间往来，不会经过外部服务器上传到某个账号。Mac 的公开支持使用本地 LAN 连接。

Connection Direction

Windows 发起并管理连接；Android、另一台 Windows PC 与 Mac 是连接目标。

macOS 13+ Apple 芯片 Mac 已作为 LAN 连接目标公开支持。

连接控制端

  • 使用 Windows 10/11。
  • 负责设备发现、选择目标、布局和发送鼠标与键盘输入。
  • 与 Mac 配对时，在 Windows 输入 Mac 上显示的 6 位代码。

连接目标

  • 当前公开支持 Android、另一台 Windows PC 与 macOS 13+ Apple 芯片 Mac。
  • Mac 连接由 Windows 端发起并管理，使用 LAN 传输输入、文件和剪贴板。

Permissions

权限只用于提供功能所需的范围。

Android 与 Mac 权限都在使用相应功能时请求，不会一次性全部申请。

Android · 必需

无障碍服务

要用 Windows 的鼠标和键盘控制 Android，并处理远程输入及屏幕相关操作，就需要无障碍服务。

Android · 开始远程控制时

屏幕捕获授权

打开手机远程控制窗口时，通过 Android 系统弹窗进行授权。安全屏幕等部分内容可能无法显示。

Android · 连接时

附近的 Wi-Fi 设备

在 Android 13 及以上查找 Windows 时可能会请求。不是在启动应用时，而只在搜索的那一刻才询问。

启动服务时

通知

用于显示后台连接状态。只在需要时才请求。

使用亮度调节时

修改系统设置

用 Alt+Shift+↑/↓ 调节手机屏幕亮度时，首次需要一次。

推荐

电池优化例外

如果息屏后连接会中断，为了稳定性建议开启。并非必需。

Mac · macOS 15+

本地网络

通过 LAN 发现 Windows 时需要允许。macOS 13/14 可能不会显示该权限项目，应用会将其视为无需单独授权。

Mac · 输入必需

辅助功能

用于把 Windows 发送的鼠标和键盘输入应用到 Mac。没有该权限时 Mac 会保持未就绪状态。

Mac · 共享画面时

屏幕录制

只有从 Windows 查看 Mac 屏幕或窗口时才需要。一般输入、文件和剪贴板功能不需要该权限。画面共享仅支持 LAN。

Mac · 当前公开支持范围外

Bluetooth

当前公开版不支持 Mac Bluetooth。Mac 的连接和画面共享请使用 LAN。

Data Handling

输入、文件和剪贴板，都在你选定的范围内。

  • 不创建远程账号 — 无需登录，通过配对即可运行。
  • 不会把你发送的文件保存到服务器。而是直接发送到你选择的设备。
  • 不会把无障碍数据用于广告或屏幕采集用途。只用于输入传递、远程控制等明示的功能。
  • 剪贴板和文件传输，只在你选定对象并执行时才会发生。

Network

连接质量会受本地网络条件的影响。

推荐环境

  • Windows 端与连接目标位于个人路由器下的同一 Wi-Fi（2.4/5GHz 均可）
  • 允许设备间通信的网络
  • 在 Windows 防火墙中允许 OneMouse 的入站连接
  • 连接 Mac，以及查看 Mac 屏幕或窗口时使用 LAN

受限环境

  • 访客或公司 Wi-Fi 中的客户端隔离（client isolation）
  • 被识别为“公用”的网络会阻止入站连接
  • 此时请改用 Bluetooth 直接连接或个人热点

OneMouse 不经过互联网中继服务器，因此需要两台设备能够彼此直接找到的环境。

Support Scope

公开指南以 Wi-Fi/LAN 和 Bluetooth 连接为准。

  • 连接控制端：Windows 10/11。设备发现、布局和输入发送均从 Windows 进行。
  • 当前公开连接目标：Android、另一台 Windows PC 与 Apple 芯片 Mac。
  • Mac：支持 macOS 13+ Apple 芯片机型，连接由 Windows 端发起并管理，当前公开支持使用 LAN。
  • Mac 权限：“辅助功能”是接收输入所必需的；macOS 15+ 使用 LAN 发现时需允许“本地网络”，macOS 13/14 可能不会显示该项目。
  • 连接：当前公开功能支持同一网络下的 Wi-Fi/LAN，以及 Android、Windows PC 等受支持设备间的 Bluetooth。当前公开版不支持 Mac Bluetooth；Mac 画面共享仅支持 LAN。
  • 不含：通过 USB/ADB 的连接不在官方支持范围内。
  • Windows↔Windows 可在两台电脑之间直接交换输入与数据。Windows↔Mac 可通过 LAN 交换输入、文件和剪贴板。
