连接与安全

Local First

数据在已连接的设备之间直接传输。

鼠标和键盘输入、文件及剪贴板数据在已连接设备之间直接传输。LAN 连接使用同一个本地网络（有线或 Wi-Fi）。Google 账号连接通过账号服务处理设备列表和连接信令，不会将输入或文件上传到服务器。

Connection Direction

按设备查看连接指南

Windows 10 或 11（x64）：可连接另一台 Windows 电脑、Android 设备或 Mac。 搭载 Apple 芯片且运行 macOS 13 及以上的 Mac：可通过 LAN、Google 账号或蓝牙（测试版）连接 Windows。也可以设置通过蓝牙将 Mac 的鼠标和键盘输入发送给 Windows。

Permissions

权限只用于提供功能所需的范围。

视 Android 版本而定，应用可能在打开时请求部分权限。无障碍功能、屏幕捕获等功能所需的权限请参见下文。

Android · 必需

无障碍服务

要用 Windows 的鼠标和键盘控制 Android，并处理远程输入及屏幕相关操作，就需要无障碍服务。

Android · 开始远程控制时

屏幕捕获授权

打开手机远程控制窗口时，通过 Android 系统弹窗进行授权。安全屏幕等部分内容可能无法显示。

应用请求权限时

附近的 Wi-Fi 设备

Android 13 及以上版本可能在首次打开应用时请求附近的 Wi-Fi 设备权限和通知权限。Android 12 及以上版本启用蓝牙时请求的“附近的设备”是另一项权限。

启动服务时

通知

用于显示后台连接状态。只在需要时才请求。

使用亮度调节时

修改系统设置

用 Alt+Shift+↑/↓ 调节手机屏幕亮度时，首次需要一次。

推荐

电池优化例外

如果息屏后连接会中断，为了稳定性建议开启。并非必需。

Mac · macOS 15+

本地网络

通过 LAN 发现 Windows 时需要允许。macOS 13/14 可能不会显示该权限项目，应用会将其视为无需单独授权。

Mac · 输入必需

辅助功能

用于把 Windows 发送的鼠标和键盘输入应用到 Mac。没有该权限时 Mac 会保持未就绪状态。

Mac · 共享画面时

屏幕录制

只有从 Windows 查看 Mac 屏幕或窗口时才需要。一般输入、文件和剪贴板功能不需要该权限。画面共享仅支持 LAN。

Data Handling

数据处理

  • LAN/Bluetooth 配对无需登录。可选 Google 账号连接使用账号服务处理设备列表和连接信令。请参阅账号信息处理说明。
  • 不会把你发送的文件保存到服务器。而是直接发送到你选择的设备。
  • 不会把无障碍数据用于广告或屏幕采集用途。只用于输入传递、远程控制等明示的功能。
  • 可以选择目标设备发送文件，也可以直接拖过去。启用剪贴板共享后，每次复制文字都不必重新选择目标。

Network

网络条件

推荐环境

  • Windows 端与连接目标位于个人路由器下的同一 Wi-Fi（2.4/5GHz 均可）
  • 允许设备间通信的网络
  • 在 Windows 防火墙中允许 OneMouse 的入站连接
  • 从 Windows 查看 Mac 屏幕或窗口时使用 LAN

受限环境

  • 访客或公司 Wi-Fi 中的客户端隔离（client isolation）
  • 被识别为“公用”的网络会阻止入站连接
  • 此时请改用 Bluetooth 直接连接或个人热点

设备之间必须能够直接通信。

Support Scope

支持的平台与连接方式

  • Windows 10 或 11（x64）：可连接另一台 Windows 电脑、Android 设备或 Mac。
  • Android 8.0 及以上：手机和平板可以接收 Windows 的鼠标和键盘输入。从 Android 打开 Windows 远程画面是另一项功能。
  • 搭载 Apple 芯片且运行 macOS 13 及以上的 Mac：可通过 LAN、Google 账号或蓝牙（测试版）连接 Windows。也可以设置通过蓝牙将 Mac 的鼠标和键盘输入发送给 Windows。
  • 蓝牙是受支持设备之间的测试版连接方式，无需 Wi-Fi 或 Google 登录，但不传输远程视频。要在 Windows 上查看 Mac 屏幕或窗口，两台设备须在同一本地网络，且 Mac 须授予屏幕录制权限。
  • USB/ADB 连接不在官方支持范围内。
