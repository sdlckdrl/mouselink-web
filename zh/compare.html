鼠标和键盘共享工具对比

对比适用于 Windows、Mac 和安卓设备的键鼠共享工具。

用 Windows 操作 Android、Mac 和其他电脑

用 OneMouse 把光标移过 Windows 的屏幕边缘，就能在安卓手机或平板、另一台 Windows 电脑或 Mac 的实际屏幕上操作。Mac 需要搭载 Apple 芯片并运行 macOS 13 或更新版本。

  • 同一网络：扫码或输入配对码，无需登录
  • 附近的 Windows → Android：无需路由器的蓝牙连接（测试版）
  • 在支持的连接方式下，可共享复制的文本和文件

安卓设备操控方式

OneMouse 和 Samsung Multi Control 会把光标移到手机屏幕上，scrcpy 则通过电脑里的投屏窗口操控安卓设备。

工具如何操控安卓设备连接方式和要求
OneMouse光标移到设备的实际屏幕上兼容的安卓设备、无障碍权限、Wi-Fi/LAN 或蓝牙（测试版）
Samsung Multi Control光标移到受支持的 Galaxy 设备的实际屏幕上受支持的 Galaxy 设备、同一个三星账号、Wi-Fi 和蓝牙
scrcpy在电脑的投屏窗口中操控Windows、macOS 或 Linux，通过 USB 或 TCP/IP 网络连接

连接前常见问题

直接操作与投屏有什么区别？

直接操作时，你看的是设备自己的屏幕。投屏时，你在电脑里的窗口中操作设备。

OneMouse 需要登录 Google 账号吗？

在同一网络中扫码或输入配对码，或通过蓝牙连接兼容设备时，无需登录 Google 账号。
