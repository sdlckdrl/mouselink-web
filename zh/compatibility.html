OneMouse 兼容性

如何连接我的设备？

以下说明适用于用 Windows PC 的鼠标和键盘操作其他设备。选择设备，查看同一网络、通过 Google 账号查找设备或蓝牙（测试版）的连接方法。

按设备查看连接方法

Windows ↔ Windows

版本要求
Windows 10 或 11
权限
如果 Windows 防火墙提示，请允许 OneMouse。
同一网络Google 账号蓝牙（测试版）

Windows → Android

设备
Android 手机和平板
权限
在 Android 上开启 OneMouse 无障碍服务。
同一网络Google 账号蓝牙（测试版）

Windows → Mac

版本要求
Apple 芯片，macOS 13 或更高版本
权限
在 Mac 上授予辅助功能权限。macOS 15 或更高版本还需留意本地网络授权提示。
同一网络Google 账号蓝牙（测试版）

该选哪种连接方式？

如果可以使用同一路由器 使用 Wi-Fi 或有线局域网。用二维码或配对码连接时，无需登录 Google。

如果想不输配对码就找到设备 在两台设备的应用中登录同一 Google 账号，需要互联网连接。账号可帮助查找设备并开始连接，远程画面等功能仍取决于网络和设备。

如果没有路由器且设备在附近所有蓝牙连接均为测试版。可连接两台 Windows PC，也可将 Windows 与 Android 连接；Windows 与 Mac 支持一对一连接。要用 Mac 控制 Windows，请参阅 Mac 蓝牙连接指南（测试版）。远程画面请使用 Wi-Fi 或局域网连接。

远程控制会显示另一台设备的画面，与把光标切换到旁边设备不同。 在 Android 上远程控制 Windows · 在 Windows 上查看已连接设备的画面
