隐私政策

OneMouse 在用户的本地环境中，由 Windows 端发起并管理与 Android 和另一台 Windows PC 的连接；macOS 13+ Mac 支持仍在准备公证发布和真机验证。本政策说明处理的信息、设备权限以及广告和结算 SDK 的使用方式。

生效日期：2026年7月28日

01

基本原则

OneMouse 以用户的 Windows 端与已配对的 Android 或另一台 Windows PC 之间的本地通信为核心；计划中的 Mac 版沿用同一本地处理原则。OneMouse 不运营用于保存用户文件、剪贴板内容或输入内容的独立账号服务器。

02

处理的信息

可能会按需处理设备名称与标识、平台和角色、连接与配对状态、设备布局、用户明确发送的文件/文本/剪贴板内容、购买状态以及广告信号。这些连接数据用于发现和连接用户选择的设备。

03

设备权限

Android 无障碍服务用于接收 Windows 的鼠标和键盘输入。计划中的 Mac 版以“辅助功能”接收输入；macOS 15+ 使用 LAN 发现时需允许“本地网络”，macOS 13/14 可能不会显示该项目。启用 Bluetooth 连接时才请求 Bluetooth 访问；只有通过 LAN 从 Windows 查看 Mac 屏幕或窗口时才请求“屏幕录制”。

04

文件和剪贴板

文件和剪贴板内容仅在用户发送或启用相关同步功能时传输，不会上传到 OneMouse 服务器。

05

广告和结算

仅 Android 发行版的 Free 模式横幅广告使用 Google Mobile Ads SDK，适用的 Pro 购买和恢复使用 Google Play Billing。Windows 与计划中的 Mac 版不使用这些 Google 广告或结算 SDK。

06

Mac 的连接与发布状态

macOS 13+ Mac 的连接由 Windows 端发起并管理。公开版计划把配对会话密钥保存在本机 macOS Keychain 中；解除配对时可删除对应连接信息。Developer ID 公证安装包与真机验证尚未完成。
