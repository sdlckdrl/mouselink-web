Privacy Policy

隐私政策

OneMouse 连接 Windows 与 Android、其他 Windows PC 和 Mac。本政策说明现有 LAN/Bluetooth 配对和可选 Google 账号连接的信息处理及权限使用。

生效日期：2026年9月1日 · 最后更新日期：2026年10月31日

Google 账号信息处理 · 请求删除账号及数据

01

基本原则

现有 LAN/Bluetooth 配对无需登录。在支持的应用版本中，可选 Google 账号连接用于查找同一账号的设备，并尝试跨网络直接连接。OneMouse 账号服务器处理连接信息和信令，不存储或中转文件、剪贴板、输入或视频内容。

02

处理的信息

可能会按需处理设备名称与标识、平台和角色、连接与配对状态、设备布局、用户明确发送的文件/文本/剪贴板内容与购买状态。这些连接数据用于发现和连接用户选择的设备。 如果你在Android应用中打开“发送通知到电脑”并允许通知访问权限，所选应用的通知标题和正文会发送到已配对的电脑并短暂显示。Windows电脑可以在本地加密保存通知的标题、正文、应用与设备信息、接收时间以及是否包含图片。这些历史记录不会上传到服务器。

通知历史记录默认开启，仅保存电脑新收到的通知，默认保留7天，最多200条，不会导入手机上更早的通知。你可以在电脑的通知选项卡中选择保留1天、7天或30天，关闭新记录的保存，或删除全部历史记录。

被识别为包含验证码的通知以及内容被隐藏或遮盖的通知不会存入历史记录。剪贴板内容、照片和头像图片也不会存入历史记录。系统无法自动识别所有敏感内容。如果操作系统的安全加密不可用，则不保存历史记录。

关闭保存不会删除已有记录；这些记录会保留到到期或由你删除。应用关闭期间到期的记录会在下次启动时清理。删除电脑上的历史记录不会删除手机上的通知。

03

设备权限

Android 无障碍服务用于接收 Windows 的鼠标和键盘输入。Mac 以“辅助功能”接收输入；macOS 15+ 使用 LAN 发现时需允许“本地网络”，macOS 13/14 可能不会显示该项目。Mac Bluetooth 不属于当前公开支持范围；只有通过 LAN 从 Windows 查看 Mac 屏幕或窗口时才请求“屏幕录制”。

04

文件和剪贴板

文件和剪贴板内容仅在用户发送或启用相关同步功能时传输，不会上传到 OneMouse 服务器。

05

结算

适用的 Pro 购买和恢复使用 Google Play Billing，仅在 Android 应用中提供；所有应用均不包含广告 SDK。Windows 与 Mac 不使用这些 Google 结算 SDK。

06

Mac 的连接与本地存储

macOS 13+ Apple 芯片 Mac 的 LAN 连接由 Windows 端发起并管理。配对会话密钥保存在本机 macOS Keychain 中；解除配对时可删除对应连接信息。

07

网站访问分析

本网站使用 Cloudflare Web Analytics 了解访问统计。该工具不会在浏览器中存储任何 Cookie 或数据，也不会生成用于识别访问者的标识，仅处理所浏览的页面、来源、国家/地区以及浏览器和设备类型等汇总统计，不收集姓名、联系方式等可直接识别个人身份的信息。

首页的下载按钮会查询 GitHub 发行版列表以指向最新版本。该请求会将访问者的 IP 地址和浏览器信息发送给 GitHub。

本条仅适用于网站，OneMouse 应用中不包含任何分析 SDK。

08

应用的更新检查

各应用会定期获取版本信息文件，以便告知新版本以及设备之间的兼容情况。Android 应用会查询 onemouse.pages.dev 上的版本信息，Windows 与 Mac 应用会查询 GitHub 的发行版信息。

这些请求不包含设备标识符、配对信息、账户信息或使用统计，应用只会下载该文件。与其他互联网请求一样，访问者的 IP 地址和时间可能会记录在服务器日志中。安装文件的下载仅在用户明确选择时进行。

09

可选 Google 账号连接

我们使用经 Google 验证的账号标识符（sub）及已验证的邮箱地址（如有提供）识别和显示账号。不会接收 Google 密码，也不会访问联系人、邮件内容或 Google Drive 文件。

账号服务保存注册设备的公钥、基于公钥的 ID、名称和类型、可选 LAN 设备 ID、PC 角色（主机/副机）、注册和最后连接时间、会话到期信息及连接状态，用于同账号设备发现、连接验证和安全保护。设备私钥及 Google 访问/ID 令牌不保存在服务器上，应用会话令牌以哈希形式保存。

Google 用于验证登录身份；Cloudflare Workers 和 SQLite Durable Objects 用于保存账号及设备信息并转发连接信令。SDP/ICE 信令可能包含 IP 地址等网络信息，会转发给对方设备，但不保存在 OneMouse 账号数据库中。Google、Cloudflare 等服务提供商在处理请求时可能处理 IP 地址等网络信息。

账号和设备注册信息可能保留至解除相应设备注册或删除 OneMouse 账号。应用会话最长有效 7 天，临时登录流程最长 10 分钟，一次性连接票据有效 30 秒。过期临时信息由服务器定期清理；防重放和速率限制记录也按有效期清理。关闭应用、断开网络或卸载应用本身不会删除服务器注册信息。

仅登录不会开始屏幕共享。同账号连接请求仍由应用验证当前设备、会话和签名。部分网络环境可能无法直接连接。

10

请求删除 OneMouse 账号及数据

在 Android 应用中打开 Google 账号 → 账号管理 → 删除账号关联，可删除服务器上的 OneMouse 账号、注册设备及会话。如需重新验证，请退出后重新登录，并在五分钟内重试。此操作不会删除 Google 账号本身或现有 LAN/Bluetooth 配对。

如果无法使用应用或已卸载，仍可向 sdlckdrl@gmail.com 发送账号删除请求。请注明登录 OneMouse 使用的 Google 邮箱地址及删除账号的请求。我们可能需要验证账号所有权。请勿发送密码或登录令牌。

退出登录用于解除当前设备的账号注册和会话，不等于删除整个 OneMouse 账号。如果无法连接服务器，可能仅完成本地退出，服务器注册仍会保留。已传输文件和本地通知记录需在各设备上分别删除。
