Compatibilidad de OneMouse

¿Cómo conecto mis dispositivos?

Esta guía explica cómo usar el ratón y el teclado de Windows en otro dispositivo. Elige uno para ver cómo conectarlo por la red local, encontrarlo con Google o usar Bluetooth (beta).

Guías por dispositivo

Windows ↔ Windows

Versión necesaria
Windows 10 u 11
Permisos
Si el firewall de Windows lo solicita, permite OneMouse.
Red localCuenta de GoogleBluetooth (beta)

Dispositivo

Versión necesaria
Apple Silicon, macOS 13 o posterior
Permisos

¿Qué método de conexión elijo?

Si puedes usar el mismo router Conecta los dispositivos por Wi-Fi o LAN por cable. No necesitas iniciar sesión en Google al usar un código QR o numérico.

Para encontrar tus dispositivos sin código Inicia sesión en las dos apps con la misma cuenta de Google. Se necesita internet. La cuenta sirve para encontrar dispositivos e iniciar la conexión; funciones como la pantalla remota dependen de la red y de los dispositivos.

Para conectar dispositivos cercanos sin router Todas las conexiones Bluetooth están en beta. Puedes conectar dos PC Windows, Windows y Android, o Windows y Mac de uno a uno. Para enviar la entrada del Mac a Windows, consulta la guía de Bluetooth para Mac (beta). La conexión Bluetooth beta no transmite vídeo remoto. Usa la misma red local (LAN por cable o Wi-Fi) o una conexión con cuenta de Google donde esté disponible.

El control remoto muestra la pantalla del otro dispositivo. No es lo mismo que mover el cursor a un equipo cercano. Controlar Windows desde Android · Ver la pantalla de otro dispositivo desde Windows
