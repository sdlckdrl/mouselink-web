먼저 이 세 가지

  • 커서를 잃었을 때 → Ctrl + Alt + Backspace를 누르면 커서가 내 PC(모니터 중앙)로 돌아옵니다.
  • 연결은 됐는데 입력이 안 될 때 → Android 접근성 서비스가 꺼졌거나 재시작됐을 수 있습니다. 접근성·배치·진입 통로를 순서대로 확인하세요.

증상으로 찾기

지금 어떤 상태인가요?

해당 항목을 펼쳐 위에서부터 확인하세요. 기존 로그인·페어링을 지우기 전에 확인할 수 있습니다.

연결됨인데 폰으로 커서가 안 넘어가요
  1. 접근성: Android 설정 → 접근성 → 설치된 앱(또는 다운로드한 앱) → OneMouse에서 사용 중인지 확인합니다. 켜져 있어도 입력이 안 되면 껐다 켭니다. Test 앱을 사용한다면 OneMouse Test를 확인하세요.
  2. 기기 배치: PC의 폰 배치에서 대상 기기가 화면의 어느 방향에 놓였는지 확인합니다. 실제 폰 위치와 설정이 같아야 헷갈리지 않습니다.
  3. 진입 통로: 그 방향의 설정한 통로로 넘깁니다. 통로가 가운데에 있다면 화면 모서리로는 넘어가지 않습니다. 배치 화면 보기
  4. 앱 버전: PC와 Android를 최신 공개 버전으로 업데이트한 뒤 양쪽 OneMouse를 다시 실행합니다. 접근성 서비스가 계속 켜져 있는지도 확인하세요.

커서를 잃었다면 기본 Ctrl + Alt + Backspace로 PC에 복귀합니다. 단축키를 바꿨다면 지정한 키를 사용하세요.

Google 계정에 기기가 안 보이거나 연결이 안 돼요
  1. 양쪽 OneMouse에서 같은 Google 계정 주소인지 확인하고, 두 기기의 인터넷 연결과 앱 실행 상태를 확인합니다.
  2. 기기 목록을 새로고침하고 대상 기기를 연결합니다. 확인 요청이 표시되면 상대 기기에서 허용합니다. 계정 연결 순서
  3. ‘Google 계정을 다시 확인’하라는 안내에는 로그인 확인을 진행합니다. ‘연결을 더 만들 수 없습니다’라면 사용하지 않는 원격 화면·연결을 닫고 잠시 후 다시 시도합니다. 계정에서 기기 제거와 연결 종료는 다른 작업입니다.

같은 Wi-Fi에서 로그인 없이 연결하려면 QR·번호 페어링을 선택할 수 있습니다. 계정 연결을 위해 반드시 같은 공유기에 있을 필요는 없습니다.

폰에서 PC 화면은 보이는데 조작이 안 돼요
  1. 원격 화면 제어 패널의 보기 전용이 꺼져 있는지 확인합니다.
  2. 터치 모드는 누른 위치를 클릭합니다. 커서 모드는 손가락을 밀어 포인터를 옮긴 뒤 탭합니다.
  3. PC에 제어 허용 요청이 표시되면 허용하고, PC와 Android 모두 지원되는 최신 버전인지 확인합니다. Bluetooth만 연결한 상태에서는 원격 영상이 열리지 않습니다.

문제 해결 순서

이 순서대로 한 단계씩 확인하세요.

1

전원과 권한

양쪽 앱이 실행 중인지 확인하세요. 입력 권한은 먼저 확인할 항목을 봅니다.

2

선택한 연결 방식 확인

QR·번호: 같은 공유기에 연결하고 로컬 네트워크 권한·기기 검색을 확인합니다. Google 계정: 같은 계정과 양쪽 인터넷 연결을 확인합니다. Bluetooth: Bluetooth 켜짐·페어링·연결 상태를 확인합니다.

3

방화벽·격리

같은 Wi-Fi/LAN 연결에서 폰은 PC를 보는데 PC가 폰을 못 보면 Windows 방화벽 인바운드(네트워크가 ‘공용’인지 ‘개인’인지) 문제일 수 있습니다. 회사·카페 Wi-Fi는 기기 간 격리로 막히기도 합니다.

4

페어링·연결

기기 관리에서 페어링·연결 상태를 확인하세요. 처음이라면 연결 가이드를 따르세요.

5

입력·복귀

배치한 방향과 설정한 커서 진입 통로를 확인하세요. 입력 점검 순서를 따르고, 커서를 잃었다면 복귀 방법을 보세요.

Mac · 공개 지원

Mac 연결 문제를 이 순서로 확인하세요.

Apple Silicon과 macOS 13+용 서명·공증 앱을 기준으로 안내합니다.

검색되지 않음

로컬 네트워크

Mac과 Windows가 같은 LAN인지 확인하세요. macOS 15+에서는 개인정보 보호 및 보안에서 OneMouse의 로컬 네트워크 접근을 허용합니다. macOS 13/14에는 이 항목이 없을 수 있으므로 Windows 방화벽과 네트워크를 확인하세요.

입력되지 않음

손쉬운 사용

macOS 개인정보 보호 및 보안 → 손쉬운 사용에서 OneMouse를 켭니다. 방금 허용했다면 앱을 완전히 종료한 뒤 다시 실행하세요.

화면이 보이지 않음

화면 녹화

LAN에서 Windows로 Mac 화면·창을 볼 때만 화면 녹화 권한이 필요합니다. Bluetooth에서는 화면 공유를 제공하지 않습니다.

연결 방식

Mac은 LAN으로 연결

공식 지원 범위는 Windows와 같은 로컬 네트워크 연결입니다. Mac Bluetooth 연결은 베타로 제공됩니다(Mac 앱 설정에서 켜기, 기본 꺼짐).

Mac 연결은 Windows에서 시작합니다

Mac 연결 가이드 보기

전송

파일과 클립보드가 안 될 때.

  • 선택된 기기가 맞는지 확인 — 전송은 선택한 대상으로 갑니다.
  • Windows PC와 Mac의 경계 드래그는 연결할 기기가 배치돼 있어야 합니다.
  • 파일을 잡은 채 배치한 화면 경계를 넘어 대상 위에서 놓아야 전송이 시작됩니다.
  • 클립보드가 안 넘어오면 양쪽 앱이 연결 상태인지, 화면이 꺼져 대기 상태인지 확인합니다.
  • 블루투스는 Wi-Fi보다 느립니다 — 큰 파일은 Wi-Fi로 보내세요.

폰 알림

폰 알림이 PC에 안 뜰 때.

  • 폰 앱 설정의 PC로 보내는 알림에서 PC로 알림 보내기를 켜고, 알림 접근 권한이 허용됨인지 확인합니다.
  • PC로 보낼 앱에 그 앱이 있는지 확인합니다. 기본은 문자 앱과 카카오톡이고, 모든 앱을 고를 수도 있습니다.
  • 메인 PC 앱의 설정 → 알림에서 기기 알림 표시가 켜져 있는지 확인합니다.
  • 인증번호 문자만 "가려짐"으로 오면 Android 15 이상의 보호 기능입니다. 폰 앱의 인증번호 알림 블록에서 PC 등록하기로 이 PC를 한 번 등록하세요. 블루투스는 등록할 때만 켜면 됩니다.
지난 알림 보관·삭제

알림은 잠깐 표시되며 기록은 PC에 암호화 보관됩니다(서버 전송 없음). 켠 뒤 받은 알림만 기록하며 인증번호·가려진 민감 내용은 저장하지 않습니다.

기록은 기본 켜짐·7일·최대 200개입니다. 메인 설정 → 알림에서 1일·7일·30일 또는 새 기록 저장 끄기를 선택하세요. 기존 기록은 남으며 지난 알림에서 전체 삭제할 수 있습니다.

자주 묻는 질문

기기와 연결 방식에 맞는 질문을 골라 열어 보세요. 필요한 설정부터 확인할 수 있어요.

  • 연결과 입력
  • 알림·파일·캡처
  • 마우스 제스처와 원격창

연결과 입력

같은 Google 계정인데 상대 기기가 안 보여요.

양쪽에서 OneMouse를 열고 두 기기가 인터넷에 연결됐는지, 같은 Google 계정에 로그인했는지 확인한 뒤 기기 목록을 새로고침하세요. 기기가 보이는데 커서만 안 넘어가면 연결 상태와 기기 배치를 따로 확인하세요. Google 계정 연결

연결이 자꾸 끊겨요.

화면이 켜져 있을 때 끊기면 양쪽 기기가 의도한 네트워크에 연결돼 있는지, 특정 공유기에서만 반복되는지 먼저 확인하세요. 화면을 끌 때만 끊긴다면 주기만으로 원인을 판단하기보다 Android의 전원 설정부터 확인하세요. LAN 자동 재연결

폰에는 PC가 보이는데 PC에서는 폰이 안 보여요.

LAN 연결이라면 양쪽 OneMouse가 열려 있고 같은 공유기에 연결됐는지 확인하세요. 신뢰하는 네트워크에서 Windows 방화벽이 OneMouse를 허용하는지도 확인하세요. 방화벽을 끄거나 공용 네트워크를 개인 네트워크로 바꾸지 마세요.

집에서는 되는데 회사·게스트 Wi-Fi에서는 연결이 안 돼요.

같은 Wi-Fi에 연결돼도 기기 간 통신이 차단될 수 있어요. 같은 Google 계정으로 기기가 목록에 보여도 해당 네트워크에서 모든 기능을 쓸 수 있다는 뜻은 아니에요. 기기 간 통신이 허용되는 신뢰할 수 있는 네트워크나 지원되는 조합의 Bluetooth(베타)를 이용하세요.

연결됐는데 Android에서 마우스·키보드가 안 돼요.

Android 설정 → 접근성 → 설치된 앱에서 OneMouse를 확인하세요. 스위치가 켜져 있는데 서비스가 연결되지 않았다면 껐다 켜세요. PC의 기기 배치에 표시된 진입 통로로 커서를 넘기고 있는지도 확인하세요. Android 입력 준비

Mac은 보이는데 클릭이나 입력이 안 돼요.

Mac의 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 OneMouse를 확인하세요. 권한을 허용한 뒤 앱을 다시 열고, 커서를 Mac으로 넘겨 텍스트 입력란에서 확인해 보세요. Mac 권한 안내

Mac 화면이나 창이 검게 보여요.

Mac에서 OneMouse의 화면 기록 권한을 확인하세요. macOS 버전에 따라 ‘화면 및 시스템 오디오 녹음’으로 표시될 수 있어요. 권한을 바꾼 뒤 macOS가 요청하면 앱을 다시 열고 화면 공유를 다시 시작하세요. Mac 화면 기록 권한

커서를 내 PC로 어떻게 돌려보내나요?

Windows의 기본 긴급 복귀 키는 Ctrl + Alt + Backspace예요. 변경했다면 저장된 단축키를 사용하세요. 단축키가 꺼져 있다면 화면의 복귀 경계로 커서를 밀어 돌아오세요. 복귀 단축키 조건

Android 화면을 끌 때만 연결이 끊겨요.

Android가 OneMouse의 백그라운드 배터리 사용을 제한하는지 확인하세요. 해당 옵션이 있는 폰에서는 OneMouse의 제한을 해제해 보세요. 메뉴 이름과 동작은 제조사마다 다를 수 있어요.

Bluetooth(베타) 연결은 무엇부터 확인하나요?

양쪽 Bluetooth가 켜져 있고 지원되는 기기가 시스템에서 페어링된 뒤 OneMouse에서도 연결됐는지 확인하세요. 마우스 입력이 된다고 같은 Bluetooth 연결에서 원격 화면도 된다는 뜻은 아니에요. 기기 조합별 원격 화면 연결 방식을 확인하세요. 기기 조합별 지원 범위

Windows에서 기기 순서를 바꿀 수 없어요.

메인 PC의 기기 관리에 순서를 바꿀 수 있는 등록 기기가 두 대 이상 표시될 때 ‘목록 순서 편집’을 확인하세요. 목록 순서를 바꾸면 지원되는 번호 단축키 순서도 바뀌지만 화면 배치는 그대로예요. Bluetooth 기기는 순서 편집에서 제외돼요. 기기 목록 순서 안내

알림·파일·캡처

PC 알림에 답장 버튼이 없거나 답장이 안 보내져요.

원본 Android 알림이 직접 입력하는 답장을 지원하고 아직 남아 있는지 확인하세요. 메인 PC의 실시간 알림에서 시도하세요. 지난 알림, 내용이 숨겨진 알림, 민감한 알림에서는 답장할 수 없어요. 시간 초과가 나면 다시 보내기 전에 폰의 원본 앱에서 확인하세요. PC와 Android 모두 답장 지원 버전이어야 해요. ‘폰 앱으로 전달됨’은 원본 앱에 넘겼다는 뜻이며 상대방의 수신 확인은 아니에요. 알림과 답장 설정

폰에서 공유한 파일이 PC에 안 와요.

Bluetooth 연결이 활성화돼 있으면 연결된 PC가 먼저 사용돼요. 그 외에는 Android OneMouse에서 Wi-Fi·LAN 기본 PC가 페어링돼 있고 전송 가능한 메인 PC인지 확인하세요. 기본 PC를 사용할 수 없다면 파일 공유 화면에서 다른 페어링된 PC를 선택할 수 있어요. 폰에서 PC로 파일·텍스트 보내기

Windows에서 받은 파일은 어디에 있나요?

OneMouse 설정 → 일반 → 파일 전송에서 ‘수신 파일 저장 위치’를 확인하세요. 폴더가 열리지 않으면 연결된 드라이브에서 쓰기 가능한 폴더를 선택하세요. 저장 위치를 바꿔도 기존 파일은 이동하지 않으며 캡처 저장 위치는 별도예요. 수신 폴더 변경 방법

캡처 후 커서가 안 돌아오거나 미리보기가 닫혀요.

양쪽 기기가 이 동작을 지원하면 캡처 후에도 커서가 제어 중인 기기에 남을 수 있어요. 미리보기를 조작하려면 커서를 직접 PC로 옮기세요. 복사·저장에 성공하면 미리보기가 닫히고, 저장 취소나 오류 시에는 유지돼요.

마우스 제스처와 원격창

Windows 원격창에서 브라우저 제스처가 안 돼요.

Windows 원격창의 우클릭 드래그는 상대 기기로 전달돼요. 상대 브라우저에서 제스처를 지원하는 경우 그 기능이나 확장을 켜 보세요. Android 화면에 커서를 직접 넘겨 쓰는 OneMouse 마우스 제스처와는 별개예요. Windows 원격창 안내

Android에서 OneMouse 마우스 제스처는 어떻게 시작하나요?

Android OneMouse의 설정 → 입력 · 클립보드에서 ‘마우스 제스처’를 켜고 사용할 앱을 선택하세요. PC 커서를 Android 화면으로 넘겨 우클릭을 누른 채 그린 다음 놓으세요. 시스템과 권한 화면에는 적용되지 않아요. Windows·Mac 화면이나 별도 원격창에서는 이 Android 제스처가 실행되지 않아요. 마우스 제스처 사용법

Android 앱에 따라 ‘앞으로’나 ‘새로고침’이 안 돼요.

‘앞으로’는 ‘뒤로’ 갔던 페이지를 다시 여는 기능이며, 피드의 다음 글로 넘어가는 기능은 아니에요. 새로고침은 인식 가능한 브라우저 기본 버튼이 필요해요. 선택한 앱이라도 화면에 따라 동작하지 않을 수 있어요.

Android에서 ‘아래 → 오른쪽’은 앱을 닫나요?

아니요. 아래로 그린 뒤 오른쪽으로 꺾고 놓으면 홈으로 이동해요. 앱이나 탭은 닫히지 않아요. ‘위 → 오른쪽’은 최근 앱을 열어요. 대각선으로 한 번에 긋는 동작과 달라요.

Android 스크롤 제스처의 이동량은 어떻게 조절하고 멈추나요?

본문에서 위나 아래로 그린 뒤 우클릭을 놓으세요. 그리는 중에는 스크롤되지 않아요. 길게 그으면 더 많이, 짧게 그으면 더 적게 이동하고 거리는 앱마다 달라요. 화살표와 세로 게이지는 방향과 획의 강도이지 문서 위치가 아니에요. 긴 스크롤은 최대 8화면 또는 10초까지예요. 클릭, 새 제스처, 앱 전환 또는 제어 종료로 남은 스크롤을 취소할 수 있어요. 커서 이동만으로는 멈추지 않습니다.
