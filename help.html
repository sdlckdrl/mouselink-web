원인을 전원 → 발견 → 방화벽 → 페어링 → 입력·복귀 순서로 좁혀보세요. Android, 다른 Windows PC, Mac에 공통으로 적용한 뒤 플랫폼별 권한을 확인하면 됩니다.

아래 복귀 키는 기본값입니다. PC 설정 → 단축키에서 변경했다면 지정한 키를 사용하세요. 메인 PC의 전체 단축키 또는 긴급 복귀를 껐으면 화면 경계로 돌아오세요. 단축키·적용 조건 자세히 보기

먼저 이 세 가지

  • 커서를 잃었을 때 → Ctrl+Alt+Backspace를 누르면 커서가 내 PC(모니터 중앙)로 돌아옵니다.
  • 연결은 됐는데 입력이 안 될 때 → Android 접근성 서비스가 꺼졌거나 재시작됐을 수 있습니다. 접근성에서 OneMouse를 다시 켜세요.
  • Mac에 입력이 안 될 때 → macOS 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 OneMouse를 허용하세요.

문제 해결 순서

이 순서대로 한 단계씩 확인하세요.

1

전원과 권한

Windows와 연결할 기기 앱이 모두 켜져 있는지 확인합니다. Android는 접근성 서비스, Mac은 입력을 위한 손쉬운 사용이 필요합니다. Mac 로컬 네트워크 권한은 macOS 15+에서만 표시될 수 있습니다.

2

같은 네트워크·발견

Windows와 연결할 기기가 같은 Wi-Fi(같은 공유기)에 있는지 봅니다. 검색이 안 되면 대개 네트워크가 다르거나 로컬 네트워크 권한·검색이 막힌 경우입니다.

3

방화벽·격리

폰은 PC를 보는데 PC가 폰을 못 보면 Windows 방화벽 인바운드(네트워크가 ‘공용’인지 ‘개인’인지) 문제일 수 있습니다. 회사·카페 Wi-Fi는 기기 간 격리로 막히기도 합니다.

4

페어링·연결

QR 또는 6자리 코드 페어링이 끝났는지, 기기 관리에서 연결 상태인지 확인합니다. 페어링 전에는 입력·파일 채널이 열리지 않습니다.

5

입력·복귀

배치한 가장자리로 마우스를 밀어 넘어가는지, 안 넘어가면 위치 배치를 확인합니다. 커서가 엉뚱한 데 있으면 Ctrl+Alt+Backspace로 복귀시킵니다.

Mac · 공개 지원

Mac 연결 문제를 이 순서로 확인하세요.

Apple Silicon과 macOS 13+용 서명·공증 앱을 기준으로 안내합니다.

검색되지 않음

로컬 네트워크

Mac과 Windows가 같은 LAN인지 확인하세요. macOS 15+에서는 개인정보 보호 및 보안에서 OneMouse의 로컬 네트워크 접근을 허용합니다. macOS 13/14에는 이 항목이 없을 수 있으므로 Windows 방화벽과 네트워크를 확인하세요.

입력되지 않음

손쉬운 사용

macOS 개인정보 보호 및 보안 → 손쉬운 사용에서 OneMouse를 켭니다. 방금 허용했다면 앱을 완전히 종료한 뒤 다시 실행하세요.

화면이 보이지 않음

화면 녹화

LAN에서 Windows로 Mac 화면·창을 볼 때만 화면 녹화 권한이 필요합니다. Bluetooth에서는 화면 공유를 제공하지 않습니다.

연결 방식

Mac은 LAN으로 연결

공식 지원 범위는 Windows와 같은 로컬 네트워크 연결입니다. Mac Bluetooth 연결은 베타로 제공됩니다(Mac 앱 설정에서 켜기, 기본 꺼짐).

Mac 연결은 Windows에서 시작합니다

Windows 앱의 기기 관리에서 Mac을 선택하고 Mac에 표시된 6자리 코드로 연결합니다.

전송

파일과 클립보드가 안 될 때.

  • 선택된 기기가 맞는지 확인 — 전송은 선택한 대상으로 갑니다.
  • Windows PC와 Mac의 경계 드래그는 연결할 기기가 배치돼 있어야 합니다.
  • 파일을 잡은 채 배치한 화면 경계를 넘어 대상 위에서 놓아야 전송이 시작됩니다.
  • 클립보드가 안 넘어오면 양쪽 앱이 연결 상태인지, 화면이 꺼져 대기 상태인지 확인합니다.
  • 블루투스는 Wi-Fi보다 느립니다 — 큰 파일은 Wi-Fi로 보내세요.

폰 알림

폰 알림이 PC에 안 뜰 때.

  • 폰 앱 설정의 PC로 보내는 알림에서 PC로 알림 보내기를 켜고, 알림 접근 권한이 허용됨인지 확인합니다.
  • PC로 보낼 앱에 그 앱이 있는지 확인합니다. 기본은 문자 앱과 카카오톡이고, 모든 앱을 고를 수도 있습니다.
  • 메인 PC 앱의 설정 → 알림에서 기기 알림 표시가 켜져 있는지 확인합니다.
  • 인증번호 문자만 "가려짐"으로 오면 Android 15 이상의 보호 기능입니다. 폰 앱의 인증번호 알림 블록에서 PC 등록하기로 이 PC를 한 번 등록하세요. 블루투스는 등록할 때만 켜면 됩니다.
  • 알림은 잠깐 표시되며 기록은 PC에 암호화 보관됩니다(서버 전송 없음). 켠 뒤 받은 알림만 기록하며 인증번호·가려진 민감 내용은 저장하지 않습니다.
  • 기록은 기본 켜짐·7일·최대 200개입니다. 메인 설정 → 알림에서 1일·7일·30일 또는 새 기록 저장 끄기를 선택하세요. 기존 기록은 남으며 지난 알림에서 전체 삭제할 수 있습니다.

자주 묻는 질문

가장 많이 겪는 문제들.

알림에 답장 버튼이 없거나 전송이 안 돼요.

PC·Android의 답장 지원 버전과 자유 입력 답장이 있는 폰 원본 알림이 필요합니다. 메인 PC 실시간 알림만 대상이며 내용 숨김·민감 알림·인증번호·지난 기록은 제외됩니다.

전송 오류는 폰 잠금·원본 알림 삭제/만료·연결을 확인하세요. 실패·시간 초과는 자동 재전송하지 않으니 폰 대화에서 확인하세요. ‘폰 앱으로 전달됨’은 원본 앱 전달을 뜻하며 상대방 수신 확인은 아닙니다. 답장 사용법 보기

기기 번호를 바꾸고 싶은데 순서 편집이 안 보여요.

메인 PC의 기기 관리에 LAN 기기가 2대 이상이면 순서 편집이 표시됩니다. 자동 저장되며 연결·원격창 단축키 번호만 바뀌고 화면 배치·키 조합은 유지됩니다. Bluetooth 순서는 그대로이며 서브 역할 PC에서는 편집할 수 없습니다. 기기 순서 바꾸기

Windows 원격창에서 브라우저 제스처가 안 돼요.

Windows용 OneMouse 1.5.4 이상에서 대상 브라우저의 제스처 확장·기능을 켜세요. 원격창의 우클릭 드래그를 전달하며, 폰 직접 제어용 Android 자체 제스처와는 별개입니다.

여러 기기의 원격창을 함께 열 수 있고, 같은 단축키 번호를 다시 누르면 해당 창을 앞으로 가져옵니다. 원격창 사용법 보기

폰에서 파일을 공유했는데 PC로 보내지지 않아요.

Wi-Fi·LAN은 폰 홈에서 기본 PC를 메인 역할 PC로 지정하고 페어링·연결을 확인하세요(서브 PC는 제외). 이미 Bluetooth로 연결돼 있으면 기본 PC 지정 없이 보낼 수 있습니다. 폰에서 PC로 보내기

PC 수신 폴더를 바꾸거나 열 수 없어요.

메인·서브 PC의 설정 → 일반 → 파일 전송 → 수신 파일 저장 위치에서 변경·열기를 누르세요. 오류 시 쓰기 권한·USB/네트워크 연결을 확인하거나 다른 폴더를 선택하세요. 기존 파일은 옮기지 않고 스크린샷 저장 위치는 별도입니다. 수신 폴더 설정 보기

캡처 후 커서가 안 돌아오거나 미리보기가 닫혀요.

양쪽 앱의 지원 버전에서는 커서가 제어 기기에 남고, 메인 본창의 트레이·최소화 상태를 유지한 채 별도 미리보기만 표시됩니다. 복사·저장 성공 시 닫히며 저장 취소·실패 시 유지됩니다. 미리보기 조작은 커서를 직접 메인으로 옮기세요. 캡처 결과 사용법 보기

마우스 제스처가 시작되지 않아요.

PC·Android 지원 버전에서 Android 설정 → 입력 · 클립보드의 마우스 제스처를 켜고 현재 앱을 선택하세요(기본 꺼짐). 커서를 폰으로 넘겨 우클릭 드래그 후 놓으면 실행되며 Windows·Mac·미러링 창에는 적용되지 않습니다.

‘모든 앱’은 실행 아이콘이 있는 설치 앱과 홈 대상입니다. OneMouse·잠금·권한창 등 시스템 화면은 제외되며, 앱·화면마다 지원 동작이 다릅니다.

제스처 사용법과 전체 표 보기

‘앞으로’나 ‘새로고침’이 안 돼요.
앞으로는 다음 글이 아니라 뒤로 간 페이지로 복귀하는 기능입니다. 새로고침은 확인 가능한 브라우저 기본 버튼이 필요하며, 선택한 앱이라도 화면에 따라 지원되지 않을 수 있습니다.
아래 → 오른쪽은 앱을 닫는 동작인가요?
아니요. 아래로 그은 뒤 오른쪽으로 그리는 두 단계 동작이며, 대각선이 아닙니다. 홈으로 이동할 뿐 앱·탭·최근 앱 카드를 닫지 않습니다. 위 → 오른쪽은 최근 앱 목록을 열어 다른 앱을 선택하는 동작입니다.
위·아래 스크롤양은 어떻게 조절하고 멈추나요?

위·아래로 길게 그으면 많이, 짧게 그으면 조금 이동하며 우클릭을 놓아야 실행됩니다(그리는 중에는 움직이지 않음). 화살표·세로 게이지는 방향과 획 강도이며 문서 위치나 정확한 거리가 아닙니다.

  • 본문에서 시작하세요. 아주 짧은 획·미완성·취소는 실행되지 않고, 움직임 없는 짧은 우클릭은 기존 동작입니다.
  • 이동량은 앱마다 다르며 홈·앱 서랍은 한 번만 스와이프합니다. 일반 긴 스크롤은 여러 스와이프, 최대 8화면·10초입니다.
  • 클릭·새 제스처·앱 전환·제어 종료로 남은 스크롤을 취소합니다. 커서 이동만으로는 멈추지 않습니다.
10초쯤마다 계속 끊겨요.
대표 원인 네 가지입니다: ① 게스트/회사 Wi-Fi의 기기 간 격리, ② 배터리 최적화로 폰의 백그라운드 연결이 잘림, ③ Windows 방화벽 인바운드 차단, ④ 화면이 꺼지면 Wi-Fi가 절전(슬립). 배터리 예외를 켜고, 방화벽에서 OneMouse 인바운드를 허용하고, 가능하면 개인 Wi-Fi를 쓰세요.
폰에서는 PC가 보이는데, PC에서 폰이 안 보여요.
대개 Windows 방화벽 인바운드 문제입니다. 현재 네트워크가 ‘공용(Public)’이면 인바운드가 막힐 수 있으니 ‘개인(Private)’으로 바꾸거나, 방화벽에서 OneMouse의 인바운드를 허용하세요.
집에서는 되는데 회사·카페 Wi-Fi에서는 안 돼요.
공용/게스트 Wi-Fi는 보안을 위해 기기 간 통신을 격리(client isolation)하는 경우가 많습니다. 이럴 땐 같은 Wi-Fi여도 서로를 못 찾습니다. 블루투스 연결이나 개인 핫스팟을 이용하세요.
연결은 됐다는데 마우스·키보드가 안 먹어요.
Android 접근성 서비스가 꺼졌거나 시스템에 의해 재시작됐을 가능성이 큽니다. Android 설정 → 접근성에서 OneMouse를 다시 켜세요.
Mac은 보이는데 입력이 안 되면?
Mac의 손쉬운 사용 권한을 확인하고 OneMouse를 완전히 종료한 뒤 다시 실행하세요.
Mac 화면이나 창이 검게 보여요.
화면 공유를 사용할 때는 Mac의 화면 녹화 권한이 필요합니다. 권한을 허용한 뒤 공유를 껐다 켜세요. 기본 입력 제어에는 이 권한이 필요하지 않습니다.
커서가 폰/다른 PC에 갇혀서 안 돌아와요.
Ctrl+Alt+Backspace를 누르면 커서가 내 PC의 모니터 중앙으로 강제 복귀합니다.
화면이 꺼지면 연결이 끊겨요.
화면이 꺼질 때 폰의 Wi-Fi가 절전되거나 배터리 최적화로 앱이 잠들 수 있습니다. Android에서 OneMouse를 배터리 최적화 예외로 두면 안정적입니다. 연결 중 화면 꺼짐 방지 옵션도 확인하세요.
블루투스로 원격 화면 제어가 잘 안 돼요.
모바일 화면 원격 제어는 데이터가 많아 블루투스에서는 권장하지 않습니다. 원격 제어는 Wi-Fi로 쓰세요. 블루투스는 마우스·키보드·클립보드·파일에 적합합니다.
