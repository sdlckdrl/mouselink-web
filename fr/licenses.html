Disponibilité du code source et recombinaison des bibliothèques

Le code source correspondant à LazySodium Android 5.2.0 est fourni ci-dessous, y compris le code source original et la licence. OneMouse n’a pas modifié le code source de cette bibliothèque.

Code source correspondant : LazySodium Android 5.2.0

LazySodium Android 5.2.0 : archive JAR de sources publiée

Le code source correspondant et les éléments de recombinaison de zeroconf 0.151.3 sont disponibles pour les versions Windows ci-dessous. L’outil conserve le code objet de l’application distribuée et construit un exécutable distinct à partir de la source modifiée de zeroconf. Il n’écrase pas l’application d’origine et ne suppose pas que les modules de l’exécutable empaqueté puissent être remplacés automatiquement.
