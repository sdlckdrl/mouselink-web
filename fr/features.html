Envoie des fichiers ou partage le presse-papiersFichiers, texte copié, captures d'écran

Envoi des fichiers

Déposer les fichiers dans l'onglet Transfert ou Drop rapide (Ctrl+Alt+DVous pouvez également faire glisser des fichiers sur le bord de l'écran vers un PC ou un Mac Windows pris en charge. Sur Android, utilisez l'onglet Transfert ou OneMouse dans le menu partage.

Fichiers reçus sur votre PC : Paramètres → Général → Transfert de fichiers → Emplacement des fichiers reçus → Ouvrir le dossier.

Utiliser du texte copié sur un autre périphérique

Sur les connexions prises en charge, copiez du texte sur un appareil et collez sur l'autre. Pour envoyer le texte Android sélectionné directement sur un PC, ouvrez le menu de sélection et choisissez Plus → OneMouse vers le PC.

Capturez seulement la zone dont vous avez besoin

Sur Windows, utilisez Ctrl+Alt+Spour capturer une zone, puis copier ou enregistrer depuis l'aperçu. Vous pouvez l'envoyer via une connexion Wi-Fi ou LAN prise en charge. Coller l'image reçue dans une application qui accepte les images.

Ouvrir un écran distantContrôler un PC à partir d'un téléphone, ou afficher les appareils à partir d'un PC

Ouvrez Windows depuis Android

Sur les deux applications prises en charge, connectez-vous sur un réseau local ou via votre compte Google. Dans la liste des PC enregistrés sur Android, ouvrez Écran distantet accepter la demande dans Windows si demandé. Allumez la vue seulement si vous ne voulez pas contrôler le PC.

Voir un périphérique connecté depuis Windows

Ouvrez la fenêtre distante dans la gestion des périphériques. Sur Android, approuvez la capture d'écran sur le téléphone. Le partage d'un écran ou d'une fenêtre Mac nécessite la même autorisation de réseau et d'enregistrement d'écran.

Contrôles tactiles et pointeurs sur Android

En mode pointeur, faites glisser pour déplacer le pointeur, puis appuyez sur. Touchez et maintenez, puis relâchez pour un clic droit. Au zoom 1×, déplacez deux doigts pour défiler.

Contrôlez le PC avec un gamepad Android

Les applications Windows et Android prises en charge peuvent utiliser un gamepad à l'écran de style Xbox ou un contrôleur physique.

Bluetooth (beta) ne transporte pas de vidéo à distance. Les applications prises en charge peuvent ajuster la qualité et le taux d'image dans le panneau de commande.
