Recommandé · se connecter au même routeur

Connectez un téléphone ou une tablette Android

Utilisez un code QR ou un code à six chiffres. Un PC câblé peut se connecter tant qu'il utilise le même routeur. Vous n'avez pas besoin de vous connecter à Google. Connexion avec un compte Google · Se connecter via Bluetooth (beta)

  1. Ouvrez l'application et activez l'accessibilité Android

    Sur Windows et Android, installer OneMouse et se connecter à travers le même routeur. Sur votre téléphone, suivez ces étapes pour activer OneMouse Accessibilité service. L'exemple utilise un appareil Galaxy; les noms de menus peuvent varier selon l'appareil et la version Android.

  2. Trouvez le code QR ou le code à six chiffres sur Windows

    Appareils → Autres façons de se connecter → Le QR et le code d'appariement de ce PC.

  3. Saisissez le code ou scannez le code QR sur Android

    Accueil → Autres façons de se connecter → Ajouter un PC avec QR ou code d'appariement. Numéro vous permet d'entrer le code; ou utiliser Scannez le code QR → Ouvrez la caméra pour scanner l'écran du PC. Où trouver Ajouter un PC avec QR ou code d'appariement

  4. Arrangez les appareils et déplacez le curseur à travers

    Sur Android Home, vérifier PC enregistrés Sur Windows, placez le téléphone ou la tablette sur le côté où il se trouve dans la vie réelle, puis déplacez le curseur à travers le point d'entrée sur ce bord.

    Voir l'exemple de mise en page
Alternative: Bluetooth (bêta)

Se connecter via Bluetooth (beta)

Bluetooth est en beta. Aucun Wi-Fi, Google connexion, QR code, ou code d'appariement est requis.

  1. Activez Bluetooth sur les deux appareils. Dans les paramètres OneMouse Android, appuyez sur Démarrer le mode Bluetooth. Sur Android 12 ou plus tard, autoriser les périphériques à proximité si demandé. Activer OneMouse Accessibilité pour cliquer et taper.
  2. Joignez votre téléphone une fois dans les paramètres Bluetooth de Windows.
  3. Dans OneMouse pour Windows, ouvrez Appareils → Autres façons de se connecter → Bluetooth et allumez le commutateur de connexion pour votre téléphone. Une fois connecté, arrangez les appareils et déplacez le curseur à travers.

Bluetooth ne transporte pas de vidéo à distance.

Recommandé · se connecter sur le même réseau

Connexion d'un Mac depuis Windows

Utilisez un Mac Apple Silicon en cours d'exécution macOS 13 ou plus tard. Connectez les deux appareils au même Wi-Fi ou LAN via le même routeur pour vous connecter sans vous connecter. Connexion à un Mac avec un compte Google · Se connecter via Bluetooth (beta)

  1. Ouvrir OneMouse et permettre l'accessibilité sur Mac

    Installer OneMouse et l'ouvrir sur Windows et Mac. Pour recevoir l'entrée de souris et de clavier de Windows, permettre Accessibilité sur votre Mac. La mise en page peut varier selon la version macOS.

    Si OneMouse manque, cliquez sur + pour ajouter l'application installée. Sur macOS 15 ou plus tard, accorder également l'accès à la réseau local s'il y a lieu.

  2. Trouvez le code à six chiffres sur Mac

    Dans OneMouse sur Mac, ouvrez Appareils → Autres façons de se connecter → Afficher le code d'appariement de ce Mac pour voir le code.

  3. Sélectionnez et connectez-vous à Mac depuis Windows

    Dans OneMouse sous Windows, étendre Appareils → Autres façons de se connecter. Sous Même Wi-Fi · Pair, saisissez le code à six chiffres à côté de votre Mac, puis sélectionnez Paire. Utilisez le code affiché sur votre propre Mac, pas l'exemple.

  4. Arrangez les appareils et déplacez le curseur à travers

    Dans l'écran de mise en page de Windows, placez le Mac où il se trouve dans la vie réelle, puis déplacez le curseur vers le bord pertinent.

    Voir l'exemple de mise en page
Vous ne trouvez pas votre Mac ? Assurez-vous que les appareils sont sur le même réseau et vérifiez si macOS a demandé la permission du réseau local. Dépannage des connexions Mac
Connectez Windows et Mac via Bluetooth (beta)

Connectez un appareil directement à l'autre, sans connexion Wi-Fi ou Google. Premièrement, joignez les deux appareils dans les paramètres Bluetooth de leur système d'exploitation.

Dans OneMouse sur Mac, ouvrez Appareils → Autres façons de se connecter et, sur Bluetooth carte, sélectionnez Activer. La carte peut apparaître directement sur l'écran des périphériques pendant la connexion.

  • Contrôlez Mac depuis Windows : Sur le Mac, changez la direction d'entrée pour Recevoir l'entrée de la souris et du clavier, puis dans Windows Dispositifs activer la connexion Mac dans la liste Bluetooth.
  • Contrôlez Windows à partir de Mac : Sous Windows, ouvrez Appareils → Autres façons de se connecter → Bluetooth et allumer Recevoir l'entrée de la souris et du clavier. Sur le Mac, changez la direction d'entrée en Envoi de la souris et du clavier et choisissez le PC Windows dans la liste.

Pour recevoir les entrées sur Mac, autorisez Accessibilité . Pour envoyer l'entrée, permet également Surveillance des entrées . Bluetooth prend en charge l'entrée de la souris et du clavier, le partage de presse-papiers, et les transferts de fichiers et de dossiers.

L'écran Mac et le partage de fenêtres nécessite Wi-Fi ou LAN. Vous ne pouvez pas afficher un écran Mac ou une fenêtre sur Bluetooth.

Dois-je également autoriser l'enregistrement d'écran?

Non, pas pour le partage de souris et de clavier seul. Si vous voulez voir un écran ou une fenêtre Mac depuis Windows, ou capturer une capture d'écran avec OneMouse sur Mac, laissez-le sur que Mac.

Sur Mac, ouvrez Paramètres système → Confidentialité et sécurité → Enregistrement audio écran et système et allumez OneMouse. Le nom de l'option peut varier selon la version macOS. Guide d'écran à distance

Recommandé · paire sur le même réseau avec un code à six chiffres

Connectez un autre PC Windows

Commencez sur le PC avec la souris et le clavier. Si les deux PC partagent un routeur, vous pouvez vous connecter avec un code sans vous connecter. Connectez un autre PC avec un compte Google · Se connecter via Bluetooth (beta)

  1. Ouvrez OneMouse et les appareils sur les deux PC

    Sur les deux PC Windows connectés par le même routeur, installer OneMouse et ouvrez l'application. Dans le menu de gauche, sélectionnez Dispositifs.

  2. Trouvez le code à six chiffres sur l'autre PC

    Sur le PC, vous voulez contrôler, ouvrir Appareils → Autres façons de se connecter → Le QR et le code d'appariement de ce PC et cherchez le code à six chiffres.

  3. Sélectionnez l'autre PC et connectez-vous

    Sur votre PC, utilisez Appareils → Autres façons de se connecter pour sélectionner l'autre PC et entrer le code. Vérifiez la connexion et allumez son commutateur si nécessaire.

  4. Arrangez les appareils et déplacez le curseur à travers

    Dans l'éditeur de mise en page, placez l'autre PC où il se trouve dans la vie réelle, puis déplacez le curseur vers ce bord d'écran.

    Voir l'exemple de mise en page
Connectez deux PC Windows via Bluetooth (beta)
  1. Tout d'abord, jumelez les PC dans les paramètres Bluetooth de Windows.
  2. Sur le PC récepteur, ouvrez OneMouse et allez à Appareils → Autres façons de se connecter → Bluetooth, puis sélectionner Recevoir l'entrée de la souris et du clavier. Allumez Bluetooth s'il est éteint.
  3. Sur le PC d'envoi, utilisez le même menu pour passer à Envoi de la souris et du clavier Si nécessaire. Activez le PC de réception dans la liste et organisez vos appareils.

Vous n'avez pas besoin d'un compte Google ou d'un routeur. Pour afficher un écran distant, utilisez le même réseau.

Vous ne trouvez pas l'autre PC ? Seul le LAN exige que les deux PC soient sur le même réseau. Pour Bluetooth, vérifiez l'appariement du système, recevez le mode sur le PC récepteur, et la connexion s'allume sur le PC qui envoie. Dépannage des connexions

Connecté, mais le curseur ne traversera pas ?

  1. Mise en page: Assurez-vous que la disposition de l'appareil Windows corresponde aux positions physiques de vos appareils.
  2. Point d'entrée: Déplacez le curseur dans la section du bord de l'écran marquée dans la mise en page.
  3. Autorisations sur l'appareil récepteur: Vérifiez l'accessibilité OneMouse sur Android ou sur Mac.

Envoyer un fichier

  1. Dans l'application mobile Transfert onglet, touchez Choisissez les fichiers et envoyez-les au PC.
  2. Sélectionnez les fichiers et ils sont envoyés au PC actuellement sélectionné.
  3. À partir d'une application photo ou document, vous pouvez également choisir Partager et sélectionnez OneMouse.

Envoyer un texte

  1. Long-press texte sur Android, sélectionnez-le, puis ouvrez Plus.
  2. Appuyez sur OneMouse vers le PC pour le copier sur le presse-papiers PC.
  3. S'il manque la première fois, allumez OneMouse une fois dans la gestion de l'application, puis sélectionnez-la à nouveau.

Trouver les fichiers reçus sur le PC

En PC Paramètres → Général → Transfert de fichiers → Emplacement du fichier reçu, utilisation Modifier le dossier de choisir la destination et Ouvrir le dossier Ceci est disponible sur les ordinateurs principaux et sous-ordinateurs.

Paramètres du dossier et dépannage

raccourcis clavier et quand ils s'appliquent.

Dans les paramètres de PC → Raccourcis, vous pouvez changer chaque combinaison, désactiver les actions individuelles ou désactiver tous les raccourcis. Utilisez votre combinaison sauvegardée si vous l'avez modifiée.

Par défaut de l'application Windows

Ordre du périphérique et numéros de raccourci : Si au moins deux dispositifs non Bluetooth sont enregistrés, ouvrir Gestion des périphériques → Modifier l'ordre de la liste sur le PC principal. Les nombres changent pour correspondre à cet ordre pour les appareils qui prennent en charge les raccourcis numérotés.

Raccourci par défaut Action et conditions
Ctrl+Alt+1~9 PC principal : connectez le contrôle d'entrée au périphérique correspondant de la liste. Appuyez de nouveau sur le même numéro pour libérer le périphérique que vous contrôlez actuellement.
Ctrl+Alt+Shift+1~9 PC principal : ouvrez la fenêtre distante correspondante ou faites avancer une fenêtre existante. L'appuyer sur elle ne ferme pas la fenêtre. Elle utilise les mêmes numéros de périphérique que les raccourcis de connexion ; les périphériques Bluetooth sont exclus de la numérotation.
Ctrl+Alt+D Afficher / masquer la zone Quick Drop.
Ctrl+Alt+S Sélectionnez une zone sur le PC Windows, Mac ou Android périphérique que vous contrôlez et recevez sur le PC principal. Sans périphérique à distance sous contrôle, capturez ce PC. Les deux applications doivent prendre en charge la fonctionnalité, et la cible a besoin d'une permission de capture.
Ctrl+Alt+V PC principal: copiez un code de vérification pendant que sa notification téléphonique est visible sur le PC. Activez d'abord le relais de notification téléphonique.
Ctrl+V Recevez et collez les fichiers partagés copiés sur un autre PC. Sans les fichiers partagés en attente, la pâte ordinaire reste disponible.
Ctrl+Alt+Backspace PC principal : retournez immédiatement le curseur au centre de votre propre moniteur tout en contrôlant un autre appareil.

Tout en contrôlant directement Android

Ce sont des combinaisons d'entrée envoyées à Android, séparément des paramètres de raccourci de l'application PC ci-dessus. L'édition de texte dépend du support dans l'application cible et le champ texte.

Raccourci par défaut Action et conditions
PrintScreen Android 11+: capturez l'écran du téléphone pendant le contrôle direct et envoyez-le à l'ordinateur. L'accessibilité est requise.
Alt+Shift+↑ / Alt+Shift+↓ Augmenter / réduire la luminosité de l'écran Android. Nécessite la permission de modifier les paramètres du système.
Alt+↑ / Alt+↓ Augmenter / diminuer le volume des médias Android.
Alt+Tab / Alt+Shift+Tab Basculez les applications récentes / cycle en marche arrière. Relâchez Alt pour entrer dans l'application sélectionnée.
Ctrl+A / Ctrl+C / Ctrl+X / Ctrl+V Sélectionner tout / copier / couper / coller dans un champ de texte pris en charge.
Ctrl+Insert / Shift+Insert / Shift+Delete Copiez / collez / coupez dans un champ de texte pris en charge.
Ctrl+Z Annuler dans les applications et les champs de texte qui le supportent.

Utilisation d'un clavier Windows pour contrôler un Mac

La cartographie des raccourcis Windows par défaut envoie Ctrl en tant que commande et Alt en tant qu'option. Vous pouvez passer à la cartographie des modificateurs Mac natif dans les paramètres du clavier de l'application Mac. Cela ne signifie pas remplacer Ctrl par Commande dans les raccourcis de l'application Windows ci-dessus.
