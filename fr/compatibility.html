Compatibilité OneMouse

Comment puis-je connecter mes appareils?

Utilisez votre souris et votre clavier Windows sur un autre appareil. Choisissez un appareil pour la configuration du réseau local, la découverte de compte Google ou Bluetooth (beta).

Quelle connexion dois-je choisir ?

Si vous pouvez utiliser le même routeur Connectez-vous sur Wi-Fi ou réseau local câblé. L'appariement avec un code QR ou un code numérique n'exige pas l'ouverture d'un compte Google.

Pour trouver vos appareils sans code Connectez-vous aux deux applications avec le même compte Google. Cela nécessite un accès Internet. Le compte aide à trouver des appareils et à démarrer une connexion; les fonctionnalités telles que la visualisation à distance dépendent du réseau et des appareils.

Pour connecter des appareils à proximité sans routeur Toutes les connexions Bluetooth sont en bêta. Vous pouvez connecter les PC Windows entre eux, connecter Windows à Android, ou connecter Windows et Mac un à un. Guide Mac Bluetooth (beta). Bluetooth beta ne transporte pas de vidéo à distance. Utilisez le même réseau local (LAN câblé ou Wi-Fi), ou une connexion de compte Google quand pris en charge.

La télécommande affiche l'écran de l'autre périphérique. Il est différent du déplacement de votre curseur vers un périphérique voisin. Contrôlez Windows à distance depuis Android · Affichage d'un écran d'appareil connecté depuis Windows
