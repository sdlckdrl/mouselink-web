De PC Windows à Android, Mac et autres PC

Avec OneMouse, déplacez le curseur au-delà du bord de votre écran Windows pour contrôler un téléphone ou une tablette Android, un autre PC Windows ou un Mac sur son propre écran. Mac nécessite Apple silicium et macOS 13 ou plus tard.

  • Même réseau : paire par code QR ou code d'appariement sans connexion
  • A proximité de Windows → Android: Bluetooth sans routeur (beta)
  • Partager le texte copié et les fichiers sur les connexions prises en charge

Connectez-vous avec le même compte Google pour trouver et se connecter à vos appareils à partir de la liste des appareils OneMouse sur Windows, Mac et Android.

Avant de vous connecter

Quelle est la différence entre le contrôle direct et le miroir?

Avec le contrôle direct, vous regardez le propre écran de l'appareil. Avec miroir, vous le contrôlez dans une fenêtre sur votre ordinateur.

Est-ce qu'OneMouse a besoin d'une connexion Google ?

Aucune connexion Google n'est nécessaire pour associer un code QR ou un code d'appariement sur le même réseau, ou pour connecter des appareils pris en charge par Bluetooth (beta).
