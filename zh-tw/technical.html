本地第一

資料直接在連線的裝置之間穿行 。

滑鼠與鍵盤輸入、 檔案與剪貼簿資料直接在連線裝置之間穿行。 LAN 連線方式使用相同的本地網路( 線或 Wi- Fi )。 Google 帳號連線方式使用裝置清單與連線訊號的帳號服務, 而不是上傳輸入或檔案 。

許可權

只有一個功能真正需要的

Android 在應用程式開啟時可能要取得一些許可權。 參考以下的特性要求, 如存取和螢幕抓取 。

需要

無障礙服務

要用您的 PC 的滑鼠和鍵盤控制 Android, 以及處理遠端輸入與螢幕相關的動作, 需要存取服務。 OneMouse 的核心功能依賴於它 。

啟動遙控器時

螢幕抓取批准

當您開啟手機遙控視窗時, 透過Android 系統被批准。 有些內容, 如安全螢幕, 可能不會出現 。

當應用程式問起

接近無線電裝置

在 Android 13 上, app 可以在您第一次開啟時要求 Nearby Wi- Fi 裝置和通知許可權。 在 Android 12 上, 藍芽模式可以要求 Closeby 裝置的許可權 。

螢幕系統音效錄音( S)

只在與 Windows 分享 Mac 顯示時使用。 OneMouse 不捕捉系統音效 。

資料處理

資料處理

  • LAN/ 藍芽配對不需要簽署。 可選用 Google 帳號連線會用於一個帳號服務來提供裝置清單和連線訊號 。 帳號資料處理.
  • 您寄送的檔案不是儲存在伺服器上, 而是直接送到您選取的裝置上 。
  • 從來不使用存取資料做廣告或螢幕收集。 它只用於說明的功能,例如傳輸輸入和遙控.
  • 選擇一個裝置或拖曳檔案到它來傳送檔案。 使用剪貼簿共享已啟動, 您不必每次複製文字都選擇目的地 。
  • Mac 應用程式在 macOS 金鑰鏈中儲存其配對的會話金鑰。 清除配對會移除信任的連線 。

網路

網路條件

建議的設定

  • 個人Wi-Fi路由器上相同的Wi-Fi(2.4或5 GHz, 要麼很好)
  • 允許裝置對裝置通訊的網路
  • OneMouse 允許在 Windows 防火牆中入境
  • 在 macOS 15+ 上, OneMouse 在 Mac 上允許本地網路存取

有限設定

  • 客人或公司Wi-Fi的客戶端隔離
  • 以「公開」為標記的網路封鎖入境
  • 在這些情況下,使用直接的藍芽連線或個人熱點

裝置必須能直接互相交流 。

支援範圍

支援的平臺和連線

  • Windows 10 或 11 (x64): 連線到另一臺Windows PC, Android, 或 Mac.
  • Android 8.0 或以後: 手機和平板電腦可以接收 Windows 滑鼠和鍵盤輸入。 從 Android 開啟 Windows 遠端螢幕是另外一個功能 。
  • 使用 macOS 13 的 Apple Silicon Mac : 在 LAN 上連線 Windows , 使用 Google 帳號, 或是 Bluetooth (beta) 。 Mac- to- Windows 滑鼠和鍵盤輸入也可以在 Bluetooth 上建立 。
  • Bluetooth 是支援對對的β選項, 不需要 Wi- Fi 或 Google 簽署。 它不攜帶遠端影片。 要從 Windows 檢視 Mac 螢幕或視窗, 請使用同一個本地網路, 並在 Mac 上授權螢幕錄制 。
  • USB/ ADB 連線不正式支援 。
