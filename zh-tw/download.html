選擇您的裝置

先安裝

Windows

Windows 10 或 11。 先用滑鼠和鍵盤安裝在 PC 上。 要連線兩臺 PC, 請在兩臺上安裝 OneMouse 。

前往 Microsoft Store下載 Windows 安裝程式
要連線的裝置

Android手機和平板電腦

Android 8.0+ ^ 啟動 OneMouse 存取服務以接收 Windows 的滑鼠與鍵盤輸入 。

前往 Google Play前往 Galaxy Store
要連線的裝置

Mac

Apple Silicon, macOS 13 或以後。 授權 Mac 接收滑鼠與鍵盤輸入 。
