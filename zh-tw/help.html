連線與輸入

我的裝置使用相同的Google帳戶。 為什麼缺少一個 ?

在兩套裝置上開啟 OneMouse, 請檢查兩套裝置是否在網路上並簽署到同一個 Google 帳戶, 然後重新整理裝置清單。 如果裝置出現, 但游標不會交叉, 請檢查連線與裝置佈局 。 谷歌帳號設定

為什麼連線一直下降?

當螢幕啟動時, 請檢查兩套裝置是否仍然在預期的網路上, 以及問題是否跟隨特定路由器。 如果它只降在螢幕上, 請檢查Android 電源設定, 而不是將隔離當作一個診斷 。 自動連線區域網

我的手機怎麼能看到PC 但電腦看不到我的手機?

對 LAN 的發現, 請檢查 OneMouse 應用程式是否開啟並連線到同一路由器。 請檢查 Windows Firewall 是否允許 OneMouse 在信任的網路上。 不要關閉防火牆或標記公用網路為私有 。

為何配對在家裡工作,

有些網路阻擋裝置到裝置的流量, 甚至同名的 Wi- Fi 。 在相同的 Google 帳號下看到一個裝置, 並不能保證每個功能都在網路上工作。 試試一個可以讓裝置通訊的可信任的網路, 或是對支援裝置的藍芽( beta) 。

上面寫的是連結滑鼠和鍵盤的輸入在Android上有何作用?

Android 上, 請前往設定 → 存取 → 安裝應用程式並檢查 OneMouse。 如果啟動了, 但服務已斷線, 請關閉並重新啟動 。 在 PC 版式中, 請檢查遊標是否正在透過標示的輸入區域 。 設定 Android 輸入 · 看看如何重置和重連線

我怎麼重新設定裝置的連線?

更新並重新開啟 OneMouse 後，如果問題仍未解決，再使用重設功能。若只有一部裝置受影響，請先到裝置管理移除該裝置，再重新配對。

  1. 視窗的 OneMouse : 設定 → 高階 → 重置裝置。 這會移除此 PC 上儲存的所有配對、 裝置清單專案、 位置和暱稱。 您的一般設定和收到的檔案都保留 。
  2. Android: 電話設定 → Apps → OneMouse → 儲存 → 清除資料( 或清除儲存 ) 。 這可以清除 OneMouse 的本地設定和配對。 選單名稱因裝置而異。 重新開啟應用程式, 重新啟用 OneMouse 存取服務 。

重新連線 : 由 QR 或程式碼對齊同一路由器 · 連線同一個 Google 帳戶

如果遊標交叉, 但您仍然無法點選或輸入, 請檢查Windows和Android上安裝的 OneMouse 版本 。

Mac出現了,但為什麼我無法按下或打字?

在 Mac 上, 開啟系統設定 → 隱私與安全 → 可存取性與檢查 OneMouse 。 在授權存取後, 重新開啟 OneMouse, 然後試著移動遊標並打入純文字欄位 。 Mac 許可權

我的麥克螢幕或窗戶怎麼黑了?

在 Mac 上, 請檢查 OneMouse 的螢幕錄制許可權( 叫做 screen & System Audio Recording on some versions of macOS ) 。 如果您改變了它, 請在 macOS 要求時重新啟動應用程式, 然後再次啟動此共享 。 Mac 螢幕錄制許可權

我怎麼把我的游標帶回PC?

在 Windows 上, 預設的緊急回傳是 Ctrl + Alt + Backspace。如果您改變了它, 請使用已儲存的捷徑。 如果它被禁用, 請將遊標移回回邊緣 。 返回捷徑設定值

為什麼只有Android螢幕關閉時連線才會下降?

檢查 Android 是否限制 OneMouse 的背景電池使用 。 在提供它的手機上, 試著讓 OneMouse 不受限制地使用它 。 廠商的標籤和行為不同 。

我該先查一下藍芽的情況嗎?

藍芽不需要Wi- Fi或先前的 LAN 設定 。 在您的系統設定中對等裝置, 然後在 OneMouse 中啟動連線 。

請檢查藍芽是否啟動, 支援的裝置是否在 OneMouse 中對對並連線。 對遠端螢幕, 請使用您裝置對對的連線方法。 基本的藍芽輸入工作不表示在藍芽上支援螢幕共享 。 由裝置對對支援

為什麼我不能在Windows上重點裝置?

在主 PC 上, 當列出至少兩個符合資格的已登記裝置時, 開啟裝置管理並尋找編輯清單的順序 。 支援的編號捷徑遵循清單的順序; 螢幕布局保持相同 。 藍芽裝置被排除 。 裝置清單排序指南

通知、檔案和截圖

我為什麼不能回復我電腦上的通知

請檢查原Android通知是否提供了回覆欄位, 且仍在使用。 在主 PC 上, 請試用實用通知, 而不是歷史專案 。 隱藏或敏感的通知不合格 。 如果回覆時間已過, 請先檢查原應用程式再試用 。 PC 和Android 應用程式都需要支援回覆的版本 。 “ Passed to phone app ” 表示回覆已達到原應用程式; 它不確認是否傳送到接收者 。 通知和回覆設定值

我手機上分享的檔案怎麼沒傳到PC上?

如果藍芽已啟動, 連線的 PC 具有優先權。 否則, 請檢查Android OneMouse 中的 Wi- Fi/ LAN 預設 PC 是對對的, 可以使用, 並且設定為主的 PC 。 如果缺缺缺, 請在檔案共享螢幕中選擇另一款符合條件的配對 PC 。 從您的手機傳送檔案與文字

在 Windows 上接收到的檔案在哪裡 ?

在 OneMouse 中, 開啟設定 → General → 檔案傳輸並檢查收件資料夾。 如果它不開啟, 請試用一個可以寫入的資料夾來連線的磁碟。 改變此資料夾不會移動您已經收到的檔案。 螢幕截圖有他們自己的儲存位置 。 更改收件資料夾

為什麼截圖預覽會關閉, 或是遊標沒有返回 ?

當兩套裝置都支援時, 截圖抓取可以將您的遊標留在受控裝置上, 而不是強迫它返回。 將遊標移回操作預覽。 成功複製或儲存會關閉預覽。 取消儲存或儲存的錯誤會保留它 。

滑鼠手勢與遠端視窗

為什麼瀏覽器的手勢不能在 Windows 遠端視窗內工作?

Windows 遠端視窗中的右鍵拖曳被傳送到遠端裝置。 如果提供此裝置, 請在目標瀏覽器中開啟手勢支援。 這與 OneMouse 直接控制 Android 時的手勢是分離的 。 遠端視窗導覽

我該怎麼在Android上做一個OneMouse滑鼠手勢?

在 Android OneMouse 中, 開啟設定 → 輸入剪貼簿, 開啟滑鼠手勢並允許您想要的應用程式 。 將 PC 遊標移到 Android 上, 按住右鍵、 畫出並放出 。 Android 系統與許可權螢幕不是手勢目標 。 這些 Android 手勢不會在 Windows 、 Mac 或獨立的遠端視窗上執行 。 滑鼠手勢指南

為什麼不在Android的應用程式裡做前進和過載工作呢?

往前轉移回後的頁面; 它不轉移到 feed 中的下一個專案 。 重新載入取決於相容的瀏覽器控制, 因此在一些螢幕上可能無法使用, 甚至在啟用應用程式中也無法使用 。

畫下來了嗎然後關閉我的Android應用程式?

不,先往下拉, 再往右轉再放出來, 它會不關閉應用程式或分頁就到家了。 上, 右邊再開啟最近事件。 對角中風不是同樣的手勢 。

我怎麼控制或阻止Android的卷軸手勢?

在內容區域上下畫出並放出滑鼠右鍵。 畫時沒有任何卷動。 中鍵通常比更短的卷動要長; 距離因應用程式而異。 箭頭和垂直測量表顯示方向和中風強度, 而不是檔案位置。 延伸的卷軸會持續到8 螢幕或 10 秒。 點選、 啟動新手勢、 切換應用程式或結束控制會取消其他的 。 單靠指標移不會阻止它 。
