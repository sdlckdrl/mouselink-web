개인정보처리방침

OneMouse는 Windows PC와 Android·다른 Windows PC·Mac을 연결합니다. 기존 LAN·Bluetooth 페어링과 선택 기능인 Google 계정 연결의 정보 처리 및 권한 사용을 설명합니다.

시행일: 2026년 9월 1일 · 최종 수정일: 2026년 10월 31일

Google 계정 정보 처리 · 계정 및 데이터 삭제 요청

01

기본 원칙

기존 LAN·Bluetooth 페어링은 로그인 없이 사용할 수 있습니다. 지원되는 앱 버전에서 Google 계정 연결을 선택하면 같은 계정의 기기를 찾고 서로 다른 네트워크에서 직접 연결을 시도합니다. OneMouse 계정 서버는 연결을 위한 정보와 신호를 처리하며 파일·클립보드·입력·영상 내용을 저장하거나 중계하지 않습니다.

02

처리하는 정보

  • 기기 식별 정보: Android 기기 ID, 기기 이름, Windows·Mac 이름, 기기 ID 또는 로컬 네트워크 주소
  • 연결 정보: 페어링 상태, 세션 키, 선택된 기본 PC, 마지막 연결 시간
  • 화면 배치 정보: Android 화면과 Mac 디스플레이 크기·방향, Windows 모니터 주변의 기기 위치 설정
  • 전송 정보: 사용자가 직접 보낸 파일, 텍스트, 클립보드 내용과 사용자가 시작한 로컬 화면·창 공유 데이터
  • 결제 정보: Android Pro 구매 여부와 구매 복원 결과. 실제 결제 처리는 Google Play가 담당합니다.
  • 알림 정보(선택): Android 앱에서 'PC로 알림 보내기'를 켜고 알림 접근 권한을 허용한 경우, 사용자가 선택한 앱의 알림 제목·본문이 페어링된 PC로 전송되어 잠시 표시됩니다. Windows PC는 알림 제목·본문, 앱·기기 정보, 수신 시각과 이미지 포함 여부를 로컬 기록에 암호화해 보관할 수 있습니다. 이 기록은 서버에 업로드되지 않습니다.

03

플랫폼 권한 사용

Android 접근성 서비스와 Mac 앱의 손쉬운 사용 권한은 Windows에서 전달된 마우스·키보드 입력을 적용하는 데 사용됩니다. Mac 로컬 네트워크 권한은 macOS 15+에서 기기 검색과 연결에 사용되며 macOS 13/14에는 표시되지 않을 수 있습니다. Android의 Bluetooth 접근은 사용자가 Bluetooth 연결을 켤 때, Mac의 화면 녹화 권한은 사용자가 LAN에서 Mac 화면·창 보기를 시작했을 때만 사용됩니다. OneMouse는 이러한 권한을 광고 추적, 비밀번호 수집, 원격 서버 전송 목적으로 사용하지 않습니다.

04

파일과 클립보드

파일과 클립보드는 사용자가 직접 전송하거나 동기화를 켠 경우에만 지원 기기 사이에서 이동합니다. 전송 파일은 OneMouse 운영 서버에 업로드되지 않습니다.

05

보관, 백업, 삭제

페어링 정보, 세션 키, 기기 목록, 위치 설정은 앱 내부 저장소나 PC 설정 파일에 저장될 수 있습니다. Mac 앱은 세션 키를 macOS Keychain에 보관합니다. 사용자는 페어링 해제, 앱 데이터 삭제 또는 앱 제거로 저장 정보를 삭제할 수 있습니다.

알림 기록 보관은 기본으로 켜져 있으며, 이후 PC가 새로 받은 알림만 기본 7일, 최대 200개까지 보관합니다. 폰의 과거 알림을 가져오지는 않습니다. PC의 알림 탭에서 보관 기간을 1일·7일·30일로 선택하거나 새 기록 저장을 끄고, 지난 알림을 전체 삭제할 수 있습니다.

인증번호로 감지한 알림과 내용이 숨김·가림 처리된 알림은 기록에서 제외하며, 클립보드 내용과 사진·아바타 이미지는 기록에 저장하지 않습니다. 모든 민감한 내용을 자동으로 감지하는 것은 아닙니다. 운영체제의 안전한 암호화를 사용할 수 없으면 기록을 저장하지 않습니다.

저장을 꺼도 기존 기록은 보관 기간이 지나거나 사용자가 삭제할 때까지 남습니다. 앱이 종료된 동안 보관 기간이 지난 기록은 다음 실행 시 정리합니다. PC 기록 삭제는 폰의 알림을 삭제하지 않습니다.

06

제3자 제공 및 SDK

OneMouse는 사용자의 파일, 클립보드, 입력 내용을 데이터 브로커나 분석 사업자에게 판매하지 않습니다. Google Play Billing Library는 Android 앱에서만 사용되며, 어떤 앱에도 광고 SDK는 포함되어 있지 않습니다. Windows와 Mac 앱은 해당 결제 SDK를 사용하지 않습니다.

Android 앱은 QR 코드 스캔을 위해 ZXing 계열 오픈소스 라이브러리를 사용합니다.

07

사용자의 선택권

  • Android 접근성 서비스를 켜거나 끌 수 있습니다. Mac 손쉬운 사용·화면 녹화와 macOS 15+ 로컬 네트워크 권한도 직접 제어할 수 있습니다.
  • 알림 권한과 배터리 제한 예외를 허용하거나 거부할 수 있습니다.
  • OneMouse 서비스를 끄거나 앱을 종료할 수 있습니다.
  • 앱에서 특정 기기와의 페어링을 해제할 수 있습니다.
  • 앱 데이터를 삭제하거나 앱을 제거할 수 있습니다.
  • 파일, 클립보드 또는 화면 공유 기능을 사용하지 않을 수 있습니다.

08

웹사이트 방문 분석

이 웹사이트는 방문 통계를 확인하기 위해 Cloudflare Web Analytics를 사용합니다. 이 도구는 브라우저에 쿠키나 저장 데이터를 남기지 않고 방문자를 식별하는 값을 만들지 않으며, 조회한 페이지, 유입 경로, 국가, 브라우저와 기기 종류 같은 집계 통계만 처리합니다. 이름이나 연락처 등 개인을 직접 식별하는 정보는 수집하지 않습니다.

홈페이지의 다운로드 버튼은 최신 버전을 안내하기 위해 GitHub 릴리스 목록을 조회합니다. 이때 방문자의 IP 주소와 브라우저 정보가 GitHub에 전달됩니다.

이 항목은 웹사이트에만 해당하며, OneMouse 앱에는 분석 SDK가 포함되어 있지 않습니다.

09

앱의 업데이트 확인

각 앱은 새 버전과 기기 간 호환 여부를 안내하기 위해 버전 정보 파일을 주기적으로 내려받습니다. Android 앱은 onemouse.pages.dev의 버전 정보를, Windows와 Mac 앱은 GitHub의 릴리스 정보를 조회합니다.

이 요청에는 기기 식별자, 페어링 정보, 계정 정보, 사용 통계가 포함되지 않으며 앱은 파일을 내려받기만 합니다. 다른 인터넷 요청과 마찬가지로 접속 IP 주소와 시각이 서버 로그에 남을 수 있습니다. 설치 파일 내려받기는 사용자가 직접 선택했을 때만 이루어집니다.

11

선택 Google 계정 연결

Google 로그인으로 확인한 계정 식별자(sub)와 확인된 이메일 주소(제공되는 경우)를 계정 식별과 표시에 사용합니다. Google 비밀번호를 받거나 연락처·메일·Google Drive 파일에 접근하지 않습니다.

계정 서버에는 등록 기기의 공개키·공개키 기반 ID·이름·종류, 선택적 LAN 기기 ID, PC 역할(메인/서브), 등록·마지막 접속 시각, 세션 만료 정보와 연결 상태를 저장합니다. 같은 계정의 기기 검색, 연결 검증 및 보안에 사용합니다. 기기의 개인키와 Google 액세스·ID 토큰은 서버에 저장하지 않으며 앱 세션 토큰은 서버에서 해시로 보관합니다.

Google은 로그인 신원 확인에, Cloudflare Workers와 SQLite Durable Objects는 계정·기기 정보 보관 및 연결 신호 전달에 사용됩니다. SDP/ICE 연결 신호에는 IP 주소 등 네트워크 정보가 포함될 수 있으며 상대 기기에 전달되지만 OneMouse 계정 서버의 데이터베이스에는 저장하지 않습니다. 서비스 제공 과정에서 Google·Cloudflare 등 제공자는 접속 IP 등 네트워크 정보를 처리할 수 있습니다.

계정·기기 등록 정보는 해당 기기 등록 해제 또는 계정 연결 삭제 전까지 남을 수 있습니다. 앱 세션은 최대 7일, 로그인 임시 정보는 최대 10분, 일회용 연결 티켓은 30초 동안 유효하며 만료된 임시 정보는 서버의 주기적 정리 대상입니다. 재사용 방지·속도 제한 정보도 유효기간에 따라 정리합니다. 앱 종료, 연결 끊김 또는 앱 제거만으로 서버의 계정 등록이 삭제되지는 않습니다.

로그인만으로 화면 공유가 시작되지는 않습니다. 같은 계정의 연결 요청도 앱이 현재 기기·세션·서명을 검증하며, 직접 연결은 네트워크 환경에 따라 실패할 수 있습니다.
