개인정보처리방침

OneMouse는 Windows PC와 Android·다른 Windows PC를 로컬로 연결합니다. macOS 13+ 앱은 배포·실기기 검증 준비 중이며, 본 방침은 공개 예정 기능까지 포함한 정보 처리와 권한을 설명합니다.

시행일: 2026년 7월 28일

01

기본 원칙

OneMouse의 현재 연결 구조는 Windows PC와 Android 또는 페어링된 Windows PC 사이의 로컬 통신입니다. 출시 예정 Mac 앱도 같은 로컬 처리 원칙을 따르며, 별도 계정 서버에 파일·클립보드·입력 내용을 저장하지 않습니다.

02

처리하는 정보

  • 기기 식별 정보: Android 기기 ID, 기기 이름, Windows·Mac 이름, 기기 ID 또는 로컬 네트워크 주소
  • 연결 정보: 페어링 상태, 세션 키, 선택된 기본 PC, 마지막 연결 시간
  • 화면 배치 정보: Android 화면과 Mac 디스플레이 크기·방향, Windows 모니터 주변의 기기 위치 설정
  • 전송 정보: 사용자가 직접 보낸 파일, 텍스트, 클립보드 내용과 사용자가 시작한 로컬 화면·창 공유 데이터
  • 결제 정보: Android Pro 구매 여부와 구매 복원 결과. 실제 결제 처리는 Google Play가 담당합니다.
  • 광고 관련 정보: Android Free 모드 광고 제공을 위해 Google Mobile Ads SDK가 광고 식별자 등 광고 제공에 필요한 신호를 처리할 수 있습니다.

03

플랫폼 권한 사용

Android 접근성 서비스와 출시 예정 Mac 앱의 손쉬운 사용 권한은 Windows에서 전달된 마우스·키보드 입력을 적용하는 데 사용됩니다. Mac 로컬 네트워크 권한은 macOS 15+에서 기기 검색과 연결에 사용되며 macOS 13/14에는 표시되지 않을 수 있습니다. Bluetooth 접근은 사용자가 Bluetooth 연결을 켤 때, 화면 녹화 권한은 사용자가 LAN에서 Mac 화면·창 보기를 시작했을 때만 사용됩니다. OneMouse는 이러한 권한을 광고 추적, 비밀번호 수집, 원격 서버 전송 목적으로 사용하지 않습니다.

04

파일과 클립보드

파일과 클립보드는 사용자가 직접 전송하거나 동기화를 켠 경우에만 현재 지원 기기 사이에서 이동합니다. 출시 예정 Mac 앱도 같은 직접 전송 원칙을 따르며, 전송 파일은 OneMouse 운영 서버에 업로드되지 않습니다.

05

보관, 백업, 삭제

페어링 정보, 세션 키, 기기 목록, 위치 설정은 앱 내부 저장소나 PC 설정 파일에 저장될 수 있습니다. 출시 예정 Mac 앱은 세션 키를 macOS Keychain에 보관할 계획입니다. 사용자는 페어링 해제, 앱 데이터 삭제 또는 앱 제거로 저장 정보를 삭제할 수 있습니다.

06

제3자 제공 및 SDK

OneMouse는 사용자의 파일, 클립보드, 입력 내용을 데이터 브로커나 분석 사업자에게 판매하지 않습니다. Google Play Billing Library와 Google Mobile Ads SDK는 Android 앱에서만 사용됩니다. Windows와 출시 예정 Mac 앱은 해당 광고·결제 SDK를 사용하지 않습니다.

Android 앱은 QR 코드 스캔을 위해 ZXing 계열 오픈소스 라이브러리를 사용합니다.

07

사용자의 선택권

  • Android 접근성 서비스를 켜거나 끌 수 있습니다. 출시 후에는 Mac 손쉬운 사용·Bluetooth·화면 녹화와 macOS 15+ 로컬 네트워크 권한도 직접 제어할 수 있습니다.
  • 알림 권한과 배터리 제한 예외를 허용하거나 거부할 수 있습니다.
  • OneMouse 서비스를 끄거나 앱을 종료할 수 있습니다.
  • 앱에서 특정 기기와의 페어링을 해제할 수 있습니다.
  • 앱 데이터를 삭제하거나 앱을 제거할 수 있습니다.
  • 파일, 클립보드 또는 화면 공유 기능을 사용하지 않을 수 있습니다.
