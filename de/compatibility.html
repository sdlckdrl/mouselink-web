OneMouse Kompatibilität

Wie verbinde ich meine Geräte?

Verwenden Sie Ihre Windows-Maus und -Tastatur auf einem anderen Gerät. Wählen Sie ein Gerät für die lokale Netzwerkeinrichtung, die Google-Kontoerkennung oder Bluetooth (Beta).

Welche Verbindung soll ich wählen?

Wenn Sie den gleichen Router verwenden können Verbinden Sie sich über Wi-Fi oder kabelgebundenes LAN. Das Koppeln mit einem QR-Code oder einem numerischen Code erfordert keine Google-Anmeldung.

So finden Sie Ihre Geräte ohne Code Melden Sie sich bei beiden Apps mit demselben Google-Konto an. Das erfordert Internetzugang. Das Konto hilft beim Finden von Geräten und beim Starten einer Verbindung. Funktionen wie die Fernanzeige hängen vom Netzwerk und den Geräten ab.

Verbinden von Geräten in der Nähe ohne Router Alle Bluetooth-Verbindungen sind in der Beta-Phase. Sie können Windows-PCs miteinander verbinden, Windows mit Android verbinden oder Windows und Mac eins zu eins verbinden. Mac Bluetooth Guide (Beta)Bluetooth beta führt kein Remote-Video. Verwenden Sie das gleiche lokale Netzwerk (verdrahtetes LAN oder Wi-Fi) oder eine Google-Kontoverbindung, sofern unterstützt.

Die Fernbedienung zeigt den Bildschirm des anderen Geräts an. Es unterscheidet sich von dem Bewegen des Cursors zu einem nahe gelegenen Gerät. Windows fernsteuern von Android · Anzeigen des Bildschirms eines verbundenen Geräts von Windows
