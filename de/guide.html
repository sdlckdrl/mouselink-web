Empfohlen · Verbindung über den gleichen Router

Verbinden Sie ein Android-Handy oder Tablet

Verwenden Sie entweder einen QR-Code oder einen sechsstelligen Code. Ein kabelgebundener PC kann eine Verbindung herstellen, solange er denselben Router verwendet. Sie müssen sich nicht bei Google anmelden. Verbinden mit einem Google-Konto · Verbinden Sie sich über Bluetooth (Beta)

  1. Öffnen Sie die App und aktivieren Sie Android Accessibility

    Unter Windows und Android, Installieren Sie OneMouse und verbinden Sie sich über den gleichen Router auf Ihrem Telefon, folgen Sie diesen Schritten, um OneMouse's zu aktivieren Bedienungshilfen Das Beispiel verwendet ein Galaxy-Gerät; Menünamen können je nach Gerät und Android-Version variieren.

  2. Finden Sie den QR-Code oder den sechsstelligen Code unter Windows

    Geräte → Andere Möglichkeiten zum Verbinden → QR und Pairing-Code dieses PCs.

  3. Geben Sie den Code ein oder scannen Sie den QR-Code auf Android

    Home → Andere Möglichkeiten, sich zu verbinden → PC mit QR oder Pairing-Code hinzufügen. Nummercode Sie können den Code eingeben; oder verwenden QR-Code scannen: Offene Kamera um den PC-Bildschirm zu scannen. Wo finde ich Add PC mit QR oder Pairing-Code

  4. Ordnen Sie die Geräte an und bewegen Sie den Cursor über

    Auf Android Home, checken Registrierte PCs Unter Windows legen Sie das Telefon oder Tablet an der Seite, wo es im wirklichen Leben sitzt, und bewegen Sie dann den Cursor durch den Einstiegspunkt an diesem Rand.

Alternative: Bluetooth (Beta)

Verbinden Sie sich über Bluetooth (Beta)

Bluetooth befindet sich in der Beta-Phase. Es ist kein Wi-Fi, Google-Anmeldung, QR-Code oder Pairing-Code erforderlich.

  1. Schalten Sie Bluetooth auf beiden Geräten ein. in Android OneMouse Einstellungen, tippen Starten Sie den Bluetooth-Modus. Auf Android 12 oder höher können Sie bei Aufforderung Geräte in der Nähe zulassen. OneMouse Accessibility zum Klicken und Tippen aktivieren.
  2. Koppeln Sie Ihr Telefon einmal in den Windows Bluetooth-Einstellungen.
  3. In OneMouse für Windows, geöffnet Geräte → Andere Möglichkeiten zur Verbindung → Bluetooth und schalten Sie den Verbindungsschalter für Ihr Telefon ein. Einmal angeschlossen, ordnen Sie die Geräte an und bewegen Sie den Cursor.

Bluetooth führt kein Remote-Video.

Empfohlen · Verbindung im selben Netzwerk

Verbinden Sie einen Mac von Windows

Verwenden Sie einen Apple Silicon Mac mit macOS 13 oder höher. Verbinden Sie beide Geräte mit dem gleichen WLAN oder LAN über den gleichen Router, um eine Verbindung herzustellen, ohne sich anzumelden. Verbinden Sie sich mit einem Mac mit einem Google-Konto · Verbinden Sie sich über Bluetooth (Beta)

  1. Öffnen Sie OneMouse und ermöglichen Sie Accessibility auf dem Mac

    Installieren Sie OneMouse und öffnen Sie es sowohl unter Windows als auch unter Mac. Um Maus- und Tastatureingaben von Windows zu erhalten, erlauben Sie Bedienungshilfen auf Ihrem Mac. Das Layout kann je nach macOS-Version variieren.

    Wenn OneMouse fehlt, klicken Sie + Um die installierte App hinzuzufügen. auf macOS 15 oder höher, gewähren Sie auch Zugriff auf die Lokales Netz wenn es dazu aufgefordert wird.

  2. Finden Sie den sechsstelligen Code auf dem Mac

    In OneMouse auf dem Mac, geöffnet Geräte → Andere Möglichkeiten zur Verbindung → Zeigen Sie den Pairing-Code dieses Mac an um den Code zu sehen.

  3. Wählen und Verbinden mit Mac von Windows

    In OneMouse unter Windows erweitern Geräte → Andere Möglichkeiten zur Verbindung. Geben Sie unter Gleichem Wi-Fi · Pairing den sechsstelligen Code neben Ihrem Mac ein und wählen PaarVerwenden Sie den auf Ihrem eigenen Mac angezeigten Code, nicht das Beispiel.

  4. Ordnen Sie die Geräte an und bewegen Sie den Cursor über

    Platzieren Sie den Mac im Windows-Layout-Bildschirm dort, wo er sich im wirklichen Leben befindet, und bewegen Sie den Cursor dann an den entsprechenden Rand.

    Sehen Sie sich das Layoutbeispiel an

Verbinden Sie Windows und Mac über Bluetooth (Beta)

Verbinden Sie ein Gerät direkt mit dem anderen, ohne Wi-Fi oder Google-Anmeldung. koppeln Sie zunächst beide Geräte in den Bluetooth-Einstellungen ihres Betriebssystems.

In OneMouse auf dem Mac, geöffnet Geräte → Andere Möglichkeiten zur Verbindung und auf dem Bluetooth Karte, auswählen .Die Karte kann direkt auf dem Gerätebildschirm erscheinen, während sie angeschlossen ist.

  • Control Mac von Windows: Wechseln Sie auf dem Mac die Eingaberichtung auf Empfangen Sie Maus- und Tastatureingaben, dann in Windows Geräte Aktivieren Sie die Mac-Verbindung in der Bluetooth-Liste.
  • Windows von Mac aus steuern: Unter Windows, offen Geräte → Andere Möglichkeiten zur Verbindung → Bluetooth und sich einschalten Empfangen Sie Maus- und TastatureingabenÄndern Sie auf dem Mac die Eingaberichtung Senden Sie Maus- und Tastatureingaben Wählen Sie den Windows-PC aus der Liste.

Um Eingaben auf dem Mac zu erhalten, erlauben Bedienungshilfen Um Eingaben zu senden, erlauben Sie auch Input-Überwachung Bluetooth unterstützt Maus- und Tastatureingaben, Textclipboard-Freigabe sowie Datei- und Ordnerübertragungen.

Mac-Bildschirm- und Fensterfreigabe erfordert Wi-Fi oder LANSie können einen Mac-Bildschirm oder ein Fenster nicht über Bluetooth anzeigen.

Muss ich auch eine Bildschirmaufzeichnung zulassen?

Nein, nicht nur für Maus und Tastatur. Wenn Sie einen Mac-Bildschirm oder ein Fenster von Windows anzeigen oder einen Screenshot mit OneMouse auf dem Mac aufnehmen möchten, lassen Sie ihn auf Dieser Mac.

Auf dem Mac, offen Systemeinstellungen → Datenschutz & Sicherheit → Bildschirm & System Audio Recording und OneMouse einschalten. Der Optionsname kann je nach macOS-Version variieren. Fernbildschirmführung

Empfohlen · Paar im selben Netzwerk mit einem sechsstelligen Code

Verbinden Sie einen anderen Windows PC

Starten Sie auf dem PC mit Maus und Tastatur. Wenn beide PCs einen Router teilen, können Sie sich mit einem Code verbinden, ohne sich anzumelden. Verbinden Sie einen anderen PC mit einem Google-Konto · Verbinden Sie sich über Bluetooth (Beta)

  1. OneMouse und Geräte auf beiden PCs öffnen

    Auf beiden Windows-PCs, die über den gleichen Router verbunden sind, Installieren Sie OneMouse und öffne die App. Geräte.

  2. Finden Sie den sechsstelligen Code auf dem anderen PC

    Auf dem PC, den Sie steuern möchten, offen Geräte → Andere Möglichkeiten zum Verbinden → QR und Pairing-Code dieses PCs Suchen Sie nach dem sechsstelligen Code.

  3. Wählen Sie den anderen PC und verbinden

    Auf Ihrem PC, verwenden Geräte → Andere Möglichkeiten zur Verbindung Um den anderen PC auszuwählen und den Code einzugeben, überprüfen Sie die Verbindung und schalten Sie bei Bedarf den Schalter ein.

  4. Ordnen Sie die Geräte an und bewegen Sie den Cursor über

    Platzieren Sie im Layout-Editor den anderen PC, wo er im wirklichen Leben sitzt, und bewegen Sie dann den Cursor an diesen Bildschirmrand.

    Sehen Sie sich das Layoutbeispiel an
Verbinden Sie zwei Windows-PCs über Bluetooth (Beta)
  1. Verbinden Sie zunächst die PCs in den Windows Bluetooth-Einstellungen.
  2. Öffnen Sie auf dem empfangenden PC OneMouse und gehen Sie zu Geräte → Andere Möglichkeiten zur Verbindung → Bluetooth, dann auswählen Empfangen Sie Maus- und TastatureingabenSchalten Sie Bluetooth ein, wenn es ausgeschaltet ist.
  3. Verwenden Sie auf dem sendenden PC das gleiche Menü, um zum Senden Sie Maus- und Tastatureingaben Aktivieren Sie den empfangenden PC in der Liste und ordnen Sie Ihre Geräte an.

Sie benötigen kein Google-Konto oder Router, sondern verwenden dasselbe Netzwerk, um einen Remote-Bildschirm anzuzeigen.

Kannst du den anderen PC nicht finden? Nur LAN erfordert, dass sich beide PCs im selben Netzwerk befinden. für Bluetooth: Systempaarung, Empfangsmodus auf dem empfangenden PC und Verbindungsschalter auf dem sendenden PC. Fehlerbehebungsverbindungen

Verbunden, aber der Cursor wird nicht kreuzen?

  1. Aufbau: Stellen Sie sicher, dass das Windows-Gerätelayout den physischen Positionen Ihrer Geräte entspricht.
  2. Einfahrtsort: Bewegen Sie den Cursor durch den Abschnitt des Bildschirmrandes, der im Layout markiert ist.
  3. Berechtigungen für die Empfangseinrichtung: Überprüfen Sie OneMouse Accessibility auf Android oder Accessibility auf Mac.

Tastenkombinationen und wenn sie gelten.

Diese PC-Verknüpfungen sind standardmäßig. In PC-Einstellungen → Verknüpfungen können Sie jede Kombination ändern, einzelne Aktionen ausschalten oder alle Verknüpfungen deaktivieren. Verwenden Sie die gespeicherte Kombination, wenn Sie sie geändert haben.

Windows App Standard

Bestellung und Shortcut-Nummern des Geräts: Wenn mindestens zwei Nicht-Bluetooth-Geräte registriert sind, öffnen Geräteverwaltung → Liste bearbeiten auf dem Haupt-PC: Die Nummern ändern sich entsprechend der Reihenfolge für Geräte, die nummerierte Verknüpfungen unterstützen.

Default Shortcut Aktion und Bedingungen
Ctrl+Alt+1~9 Haupt-PC: Verbinden Sie die Eingabesteuerung mit dem passenden Gerät in der Liste. Drücken Sie die gleiche Nummer erneut, um das Gerät freizugeben, das Sie gerade steuern.
Ctrl+Alt+Shift+1~9 Haupt-PC: Öffnen Sie das passende Fernfenster oder bringen Sie ein vorhandenes Fenster nach vorne. Drücken Sie es erneut, schließt das Fenster nicht. Es verwendet die gleichen Gerätenummern wie Verbindungskombinationen; Bluetooth-Geräte sind von der Nummerierung ausgeschlossen.
Ctrl+Alt+D Zeigen / Ausblenden der Quick Drop Zone.
Ctrl+Alt+S Wählen Sie einen Bereich auf dem Windows-PC, Mac oder Android-Gerät, den Sie steuern, und erhalten Sie ihn auf dem Haupt-PC. Ohne Ferngerät unter Kontrolle, erfassen Sie diesen PC. Beide Apps müssen die Funktion unterstützen, und das Ziel benötigt Erfassungsberechtigung.
Ctrl+Alt+V Haupt-PC: Kopieren Sie einen Verifizierungscode, während die Telefonbenachrichtigung auf dem PC sichtbar ist.
Ctrl+V Freigegebene Dateien, die auf einen anderen PC kopiert werden, empfangen und einfügen. Da keine freigegebenen Dateien warten, bleibt gewöhnliches Einfügen verfügbar.
Ctrl+Alt+Backspace Haupt-PC: Bringen Sie den Cursor sofort in die Mitte Ihres eigenen Monitors zurück, während Sie ein anderes Gerät steuern.

Während Sie Android direkt kontrollieren

Dies sind Eingabekombinationen, die an Android gesendet werden, getrennt von den oben genannten Einstellungen für die PC-App. Die Textbearbeitung hängt von der Unterstützung in der Ziel-App und im Textfeld ab.

Default Shortcut Aktion und Bedingungen
PrintScreen Android 11+: Erfassen Sie den Telefonbildschirm während der direkten Kontrolle und senden Sie ihn an den PC.
Alt+Shift+↑ / Alt+Shift+↓ Erhöhen / Senken der Bildschirmhelligkeit von Android. Erfordert die Berechtigung, die Systemeinstellungen zu ändern.
Alt+↑ / Alt+↓ Erhöhen / senken Sie das Android-Medienvolumen.
Alt+Tab / Alt+Shift+Tab Wechseln Sie die letzten Apps / den letzten Zyklus in umgekehrter Reihenfolge.
Ctrl+A / Ctrl+C / Ctrl+X / Ctrl+V Wählen Sie all / copy / cut / paste in einem unterstützten Textfeld aus.
Ctrl+Insert / Shift+Insert / Shift+Delete Kopieren / Einfügen / Schneiden in einem unterstützten Textfeld.
Ctrl+Z Undo in Apps und Textfeldern, die es unterstützen.

Verwenden einer Windows-Tastatur zur Steuerung eines Mac

Das Standard-Windows-Verknüpfungs-Mapping sendet Strg als Befehl und Alt als Option. Sie können in den Mac-App-Tastatureinstellungen zum nativen Mac-Modifier-Mapping wechseln. Dies bedeutet nicht, dass Strg in den Windows-App-Verknüpfungen oben durch Befehl ersetzt wird.
