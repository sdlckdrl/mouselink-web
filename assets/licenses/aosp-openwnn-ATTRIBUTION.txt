Local changes: fixed-width 32-bit dictionary types on LP64; defined intptr_t JNI
handles; application SONAME library loading; explicit native owner close;
read-only operation without a personal SQLite/learning dictionary.
OneMouse supplies the bounded complete-sentence conversion adapter and native
build integration. No network conversion or toy replacement lexicon is used.
The upstream historic vocabulary is not Mozc or the current Google dictionary.

ASCII romaji/alphabet case conversion and internal SQL formatting explicitly
use Locale.ROOT so device language settings cannot alter conversion results.
