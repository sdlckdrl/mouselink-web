일반 사용자는 이 순서대로만 따라오면 됩니다. 어려운 네트워크 설명은 기술·보안, 안 될 때는 도움말에서 따로 봅니다.

Android 연결

Android 첫 연결은 이 순서만 따라가면 됩니다.

Wi-Fi(같은 공유기) 기준입니다. Android 제어에는 접근성 권한이 필요합니다. Mac은 아래의 Mac 연결을 따라가세요.

1

PC 앱을 켭니다

Windows에서 OneMouse를 실행하면 화면에 6자리 코드와 QR 코드가 나옵니다.

2

Android 접근성 권한을 켭니다

PC 마우스·키보드 입력을 받으려면 Android에서 OneMouse 접근성 서비스를 켭니다.

3

PC를 검색합니다

같은 Wi-Fi(같은 공유기)에서 PC를 찾습니다. Android 13 이상은 이때 ‘주변 Wi-Fi 기기’ 권한을 한 번 물어볼 수 있습니다.

4

QR 또는 6자리 코드로 페어링

QR을 스캔하거나 6자리 코드를 입력해 내 기기인지 확인합니다. 페어링을 마쳐야 입력·파일·클립보드 채널이 열립니다.

5

폰 위치를 맞춥니다

PC 화면의 어느 가장자리(좌·우·상·하)로 폰이 이어질지 실제 방향에 맞춰 배치합니다. 이 가장자리가 커서 진입 방향입니다.

6

넘겨 씁니다

배치한 가장자리로 마우스를 밀면 폰으로 넘어갑니다. PC 마우스·키보드로 사용하세요.

실제 UI 페어링 흐름 보기준비 → PC 코드 확인 → 숫자 입력 → QR 스캔

기기 위치

연결 후엔 기기를 실제 방향에 맞추면 됩니다.

배치 화면에서 기기를 실제 놓인 방향으로 끌어 놓으세요. 해당 가장자리로 커서가 이동합니다.

원격 제어

원격 화면은 기기 관리에서 엽니다.

기기 관리에서 페어링된 Android 행의 원격 제어 아이콘을 누르면, 폰 화면을 보여주는 별도 창이 열립니다. 처음 열 때는 Android 화면 캡처 승인이 필요합니다.

Android 창에서의 조작

  • 좌클릭·드래그·휠이 그대로 전달됩니다.
  • 우클릭 = 뒤로, 휠클릭 = 홈.
  • PC 키보드(한글 포함)는 폰의 현재 입력칸으로 갑니다.
  • 화면이 비어 보이면 캡처 승인 팝업을 확인하고, 원격 제어를 껐다 켜세요.

Windows 원격창에서도 우클릭 드래그

기기 관리의 원격 제어 아이콘이나 기본 Ctrl+Alt+Shift+1~9로 엽니다. 우클릭 드래그로 대상 PC 브라우저의 제스처 확장을 사용할 수 있으며, Android 자체 제스처와는 별개입니다.

Android 마우스 제스처

우클릭을 누르고 그리면, 더 빠르게.

켜는 방법, 7가지 제스처와 지원 범위를 확인하세요.

1. 제스처 켜기

설정 → 입력 · 클립보드에서 마우스 제스처를 켜고 사용할 앱을 선택하세요(기본은 꺼짐). PC·Android 모두 제스처 지원 버전이 필요합니다.

모든 앱을 선택하면 앱과 홈 화면에서도 사용할 수 있습니다. 지원 범위 보기

2. 누르고, 그리고, 놓기

PC 커서를 Android 폰·태블릿으로 넘긴 뒤 선택한 앱을 여세요.

  1. 페이지 본문 위에서 우클릭을 누른 채 유지하세요.
  2. 표시된 방향을 순서대로 그리세요. 빨간 궤적 옆에서 동작을 확인합니다.
  3. 버튼을 놓으면 실행됩니다. 그리는 중에는 스크롤되지 않습니다.

화살표와 세로 게이지는 방향과 그린 길이의 스크롤 강도이며, 페이지 위치나 정확한 이동량이 아닙니다.

제스처실행되는 동작
← 뒤로왼쪽으로 그으면 이전 페이지나 화면으로 돌아갑니다.
→ 앞으로오른쪽으로 그으면 뒤로 간 페이지로 복귀합니다.
↑ 위로 스크롤위로 그리고 놓으세요. 길게 그으면 많이, 짧게 그으면 조금 이동합니다.
↓ 아래로 스크롤아래로 그리고 놓으세요. 길게 그으면 많이, 짧게 그으면 조금 이동합니다.
↓ → 앱 최소화앱을 닫지 않고 홈 화면으로 이동합니다.
↑ ↓ 새로고침지원하는 브라우저에서 현재 페이지를 새로고침합니다.
↑ → 최근 앱최근 앱 목록을 열어 다른 앱을 선택합니다.

잘 안 될 때 확인

  • Android 직접 제어용이며 Windows·Mac 제어나 미러링 창에서는 사용하지 않습니다.
  • 앞으로는 방문 기록으로 복귀합니다. 앞으로·새로고침은 브라우저 지원이 필요합니다.
  • 스크롤은 페이지 본문에서 시작하세요. 짧게 우클릭만 하면 기존 동작을 유지합니다.
  • 실제 스크롤은 앱마다 다르며, 홈·앱 목록에서는 한 번만 스와이프합니다.

제스처 문제 해결 · 스크롤 한도·중단 방법

파일·클립보드

파일은 전송 화면, 빠른 드롭존, 기기 경계 드래그로 보냅니다.

  • 전송 화면 또는 작은 드롭존에 파일을 놓으면 선택한 Android, 다른 Windows PC 또는 Mac으로 갑니다.
  • 연결한 Windows PC나 Mac은 파일을 잡은 채 배치한 화면 경계를 넘어 놓으면 전송됩니다.
  • Android에서 PC로 보내기
  • 시작이 안 되면 연결 상태와 선택된 기기를 확인하세요.

빠른 드롭존

  • Ctrl+Alt+D로 드롭존을 숨기거나 보입니다.
  • 위치와 상태는 PC 앱에 저장됩니다.
빠른 드롭존 화면

모바일 → PC

폰에서 고른 파일과 텍스트를 PC로 보냅니다.

LAN으로 보낼 때는 모바일 앱 홈에서 기본 PC를 선택하고 페어링·연결 상태를 확인하세요. 파일은 전송 탭 또는 Android 공유 메뉴에서, 텍스트는 선택 메뉴의 OneMouse to PC에서 보낼 수 있습니다.

파일 보내기

  1. 모바일 앱의 전송 탭에서 파일 선택해서 PC로 보내기를 누릅니다.
  2. 보낼 파일을 고르면 선택된 PC로 바로 전송됩니다.
  3. 사진·문서 앱에서는 공유를 누른 뒤 OneMouse를 선택해도 됩니다.

텍스트 보내기

  1. Android에서 텍스트를 길게 눌러 선택하고 더보기를 엽니다.
  2. OneMouse to PC를 누르면 PC 클립보드로 전송됩니다.
  3. 처음 보이지 않으면 앱 관리에서 OneMouse를 한 번 켠 뒤 다시 선택하세요.

PC에서 받은 파일 찾기

PC의 설정 → 일반 → 파일 전송 → 수신 파일 저장 위치에서 폴더 변경으로 저장 위치를 정하고 폴더 열기로 확인하세요. 메인·서브 PC 모두 사용할 수 있습니다.

저장 위치·폴더 문제 해결

텍스트 전송 화면 보기선택 메뉴에서 OneMouse to PC를 켜고 사용하는 순서입니다.

알림·답장

폰 알림을 PC에서 보고, 지원되는 알림에 답장합니다.

알림 받기와 지난 알림

Android 앱에서 PC로 알림 보내기를 켜고 알림 접근 권한을 허용한 뒤, 보낼 앱을 선택하세요. 메인 PC의 설정 → 알림에서 기기 알림 표시를 켭니다.

같은 화면에서 지난 알림과 보관 설정을 확인합니다. 알림 설정 자세히 보기

실시간 알림에 답장

PC·Android가 답장을 지원하고 원본 폰 알림에 자유 입력 답장이 있을 때 답장이 나옵니다. 입력 후 전송 또는 Ctrl+Enter를 누르면 원래 폰 앱으로 보냅니다(Enter는 줄바꿈).

답장 버튼이 없거나 전송이 안 될 때

번호 단축키

기기 목록의 번호로 바로 연결합니다.

Ctrl + Alt + 1~9

  • 기본 설정에서 메인 PC 기기 목록의 앞 9개 LAN 기기에 Ctrl+Alt+1~9가 붙습니다. 키 변경은 단축키 안내를 확인하세요.
  • 번호를 누르면 그 기기에 연결됩니다.
  • 현재 입력 제어 중인 기기의 같은 번호를 다시 누르면 제어를 해제합니다.

자동 재연결

  • 켜두면 마지막 기기가 다시 나타나거나 준비된 기기가 하나일 때 PC 앱이 자동으로 다시 연결합니다.

기기 순서와 단축키 번호 바꾸기

메인 PC에 LAN 기기가 2개 이상 있으면 기기 관리 → 순서 편집을 누르세요. 손잡이나 ↑·↓로 옮기면 자동 저장되며 완료로 끝냅니다. 연결·원격창 단축키 번호에도 같은 순서가 적용됩니다.

순서 편집이 안 보일 때

블루투스

공유기 없이 블루투스로도 연결할 수 있습니다.

Windows↔Android와 Windows↔Windows는 블루투스로 직접 이어 입력·클립보드·파일을 주고받습니다.

이럴 때 좋아요

  • 공유 Wi-Fi가 없는 방·야외·차량
  • 게스트 Wi-Fi나 방화벽이 기기 검색을 막을 때
  • 가벼운 키보드·클립보드 위주 사용

알아두기

  • 큰 파일과 모바일 원격 화면은 Wi-Fi·LAN을 권장합니다.
  • Mac Bluetooth는 베타입니다(앱 설정에서 켜기, 기본 꺼짐). 공식 지원은 LAN이며 Mac 화면·창 공유는 LAN 전용입니다.

블루투스 연결 문제 해결

연결 순서

1

Android 설정 탭에서 블루투스 모드 켜기

2

Windows 블루투스 설정에서 폰 한 번 페어링

3

PC 앱이 자동 연결 → 기기 관리에 표시

4

Wi-Fi와 똑같이 입력·클립보드·파일 사용

블루투스 서브 기기 화면

다른 PC

다른 Windows PC는 설정 · 기기 관리 · 배치 순서로 붙입니다.

연결하기

  • 제어하는 PC는 메인, 제어받는 PC는 서브 역할로 둡니다.
  • 서브 PC를 페어링해 기기 관리에 추가합니다.
  • 배치 편집기에서 서브 PC를 실제 위치대로 놓습니다.
  • 그 방향으로 마우스를 넘기면 다른 PC를 제어하고, 파일도 경계 드래그로 주고받습니다.
배치 화면

macOS 13+ · Apple Silicon

Windows에서 Mac을 연결하는 절차입니다.

서명·공증된 공개 DMG를 Mac에 설치한 뒤 Windows에서 연결을 시작합니다. 아래 5단계로 페어링하고 실제 위치에 맞춰 배치할 수 있습니다.

1

Windows와 Mac에서 OneMouse 실행

Windows에서 연결을 시작하고 macOS 13 이상에서 Mac 앱을 엽니다.

2

Mac 권한 허용

입력 수신을 위한 손쉬운 사용을 허용합니다. macOS 15+에서는 기기 검색을 위한 로컬 네트워크도 허용하며, macOS 13/14에는 이 항목이 표시되지 않을 수 있습니다.

3

Windows에서 Mac 선택

Windows OneMouse의 기기 관리에서 검색된 Mac을 선택합니다.

4

Mac의 6자리 코드 입력

Mac에 표시된 페어링 코드를 Windows에 입력해 내 기기인지 확인합니다.

5

배치하고 경계로 이동

Windows 배치 화면에서 Mac 위치를 정한 뒤 그 방향으로 마우스를 밀어 제어합니다.

현재 공개 지원 범위

  • 마우스·키보드·스크롤·드래그 입력
  • 텍스트 클립보드와 파일·폴더 양방향 전송
  • 화면 경계를 넘는 파일 드래그
  • 같은 로컬 네트워크(LAN) 연결

화면 녹화 권한은 선택 사항

Windows에서 Mac 화면·창을 볼 때만 허용합니다. 기본 마우스·키보드 입력에는 필요하지 않습니다. Mac 화면·창 공유는 Bluetooth에서 지원하지 않고 LAN에서만 제공합니다.

권한

플랫폼과 기능에 필요한 권한만 켭니다.

Android는 접근성 서비스, Mac은 손쉬운 사용이 입력에 필요합니다. Android·Mac 원격 화면을 볼 때는 별도의 화면 캡처·녹화 승인을 허용하세요.

플랫폼별 권한 자세히 보기

키보드 단축키와 적용 조건.

아래 PC 단축키는 기본값입니다. PC의 설정 → 단축키에서 키 조합을 바꾸거나 각 항목·전체를 끌 수 있습니다. 키를 바꿨다면 설정한 조합을 사용하세요.

Windows 앱의 기본 단축키

기본 단축키 동작·조건
Ctrl+Alt+1~9 메인 PC: 목록의 해당 기기에 입력 제어를 연결합니다. 현재 제어 중인 기기의 같은 번호를 다시 누르면 제어를 해제합니다.
Ctrl+Alt+Shift+1~9 메인 PC: 해당 기기의 원격창을 열거나 이미 열린 창을 앞으로 가져옵니다. 다시 눌러도 닫지 않습니다. 연결 단축키와 같은 LAN 기기 번호를 사용하며 Bluetooth 기기는 번호 배정에서 제외합니다.
Ctrl+Alt+D 빠른 드롭존 보이기 / 숨기기.
Ctrl+Alt+S 제어 중인 Windows PC·Mac·Android의 화면에서 영역을 선택해 메인 PC로 받습니다. 다른 기기를 제어하지 않을 때는 내 PC를 캡처합니다. 양쪽 앱의 기능 지원과 대상 기기의 캡처 권한이 필요합니다.
Ctrl+Alt+V 메인 PC: 인증번호가 포함된 폰 알림이 PC에 떠 있는 동안 해당 번호를 복사합니다. 폰 알림 전송을 먼저 켜야 합니다.
Ctrl+V 다른 PC에서 복사한 공유 파일을 이 PC로 받아 붙여넣습니다. 받을 공유 파일이 없으면 일반 붙여넣기를 사용합니다.
Ctrl+Alt+Backspace 메인 PC: 다른 기기 제어 중 커서를 내 PC의 모니터 중앙으로 즉시 되돌립니다.

캡처 후에도 커서는 제어 중인 기기에 남습니다. 메인 PC의 미리보기는 복사·저장이 성공하면 닫힙니다. 양쪽 앱이 이 기능을 지원해야 합니다.

캡처 미리보기 도움말

서브 PC에서는 빠른 드롭존·이 PC 스크린샷·공유 파일 붙여넣기를 사용합니다. 메인 PC의 키보드로 서브 PC를 제어할 때는 메인 PC의 단축키 설정이 적용됩니다.

전체 단축키를 끄면 긴급 복귀도 작동하지 않습니다. 화면 경계로 커서를 되돌리세요. 키가 작동하지 않으면 설정 → 단축키에서 켜짐 상태와 키 충돌을 확인하세요.

Android를 직접 제어할 때

아래는 Android로 전달하는 입력 조합입니다. PC 앱의 단축키 설정 표와 구분하며, 텍스트 편집은 대상 앱·입력창의 지원에 따라 달라집니다.

기본 단축키 동작·조건
PrintScreen Android 11 이상: 직접 제어 중인 폰 화면을 찍어 PC로 보냅니다. 접근성 권한이 필요합니다.
Alt+Shift+↑ / Alt+Shift+↓ Android 화면 밝기 올리기 / 내리기. 시스템 설정 변경 권한이 필요합니다.
Alt+↑ / Alt+↓ Android 미디어 음량 올리기 / 내리기.
Alt+Tab / Alt+Shift+Tab 최근 앱 전환 / 반대 방향 전환. Alt를 놓으면 선택한 앱으로 이동합니다.
Ctrl+A / Ctrl+C / Ctrl+X / Ctrl+V 지원하는 텍스트 입력창에서 전체 선택 / 복사 / 잘라내기 / 붙여넣기.
Ctrl+Insert / Shift+Insert / Shift+Delete 지원하는 텍스트 입력창에서 복사 / 붙여넣기 / 잘라내기.
Ctrl+Z 실행 취소. 지원하는 앱·입력창에서 동작합니다.

Windows 키보드로 Mac을 제어할 때

기본 Windows 단축키 매핑에서는 Ctrl이 Command, Alt가 Option으로 전달됩니다. Mac 앱 설정의 키보드 수정키 매핑을 Mac 원래 방식으로 바꿀 수 있습니다. 위 Windows 앱 단축키의 Ctrl을 Command로 바꾸라는 의미는 아닙니다.
