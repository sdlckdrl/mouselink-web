Android 폰·태블릿 연결하기

QR 또는 6자리 번호, 둘 중 하나만 쓰면 돼요. PC가 유선이어도 같은 공유기에 연결돼 있으면 됩니다. Google 로그인은 필요 없어요. Google 계정으로 연결하려면 · Bluetooth로 연결하기 (베타)

  1. 앱 열고 Android 접근성 켜기

    Windows와 Android에 OneMouse를 설치하고, 같은 공유기에 연결해요. 폰에서는 아래 순서로 OneMouse의 접근성을 켜세요. 갤럭시 기준이며, 메뉴 이름은 기기와 Android 버전에 따라 다를 수 있어요.

  2. Windows에서 QR·인증번호 열기

    기기 관리 → 다른 방법으로 연결 → 이 PC의 QR·인증번호를 누르세요.

  3. Android에서 번호 입력 또는 QR 스캔

    홈 → 다른 방법으로 연결 → QR·인증번호로 PC 추가를 누르세요. 숫자 코드에서 번호를 입력하거나, QR 코드 스캔 → 카메라 실행으로 PC 화면을 스캔하세요. ‘QR·인증번호로 PC 추가’ 버튼 위치

  4. 기기 위치를 맞추고 마우스 넘기기

    Android 홈의 등록된 PC에서 연결을 확인하세요. Windows에서 폰·태블릿을 실제 놓인 방향으로 배치하고, 그쪽 가장자리의 진입 통로로 마우스를 밀어 보세요.

다른 연결 방법: Bluetooth (베타)

Bluetooth로 연결 (베타)

두 기기의 Bluetooth를 켜세요. Android OneMouse의 블루투스 모드 시작과 Windows Bluetooth 설정의 기기 페어링이 필요해요. 연결한 뒤 OneMouse 기기 목록에서 상태와 배치를 확인하세요. 원격 동영상은 Bluetooth로 전송되지 않아요.

Windows에서 Mac 연결하기

Apple Silicon Mac과 macOS 13 이상이 필요해요. 두 기기를 같은 공유기의 Wi-Fi 또는 LAN에 연결하면 로그인 없이 사용할 수 있어요. Google 계정으로 Mac 연결하기 · Bluetooth로 연결하기 (베타)

  1. Windows와 Mac에서 앱 열기

    OneMouse를 설치하고 두 기기에서 실행하세요. 연결은 Windows에서 시작해요.

  2. Mac에서 손쉬운 사용 허용

    Windows의 마우스·키보드를 받으려면 Mac에서 손쉬운 사용을 허용하세요. macOS 버전에 따라 화면 배치가 다를 수 있어요.

    목록에 OneMouse가 없다면 +를 눌러 설치한 OneMouse를 추가하세요. macOS 15 이상에서 로컬 네트워크 접근을 요청하면 함께 허용하세요.

  3. Mac에서 번호 확인, Windows에 입력

    Mac OneMouse의 기기 관리 → 다른 방법으로 연결 → 이 Mac의 인증번호 보기에서 번호를 확인하세요. Windows OneMouse의 기기 관리 → 다른 방법으로 연결을 펼치고, ‘같은 Wi-Fi · 페어링’에 보이는 Mac 옆에 6자리 번호를 넣은 뒤 페어링을 누르세요.

    그림 속 숫자 대신 내 Mac에 표시된 번호를 쓰세요.

  4. Mac 방향으로 마우스 넘기기

    Windows의 배치 화면에서 Mac을 실제 놓인 방향에 배치하고, 그쪽 가장자리로 마우스를 밀어 보세요.

Mac이 목록에 안 뜨나요? 같은 네트워크인지 확인하고, macOS에서 요청한 로컬 네트워크 권한을 확인해요. Mac 문제 해결
Windows와 Mac을 Bluetooth로 연결하기 (베타)

한 대씩 직접 연결하는 방식이에요. 같은 Wi-Fi나 Google 로그인은 필요 없어요. 먼저 두 기기를 운영체제의 Bluetooth 설정에서 페어링하세요.

Mac OneMouse의 기기 관리 → 다른 방법으로 연결을 펼친 뒤 Bluetooth 카드에서 켜기를 누르세요. 연결 중이면 카드가 ‘기기 관리’에 바로 나타날 수 있어요.

  • Windows에서 Mac 조작: Mac에서 입력 방향을 마우스·키보드 입력 받기로 바꾸고, Windows 기기 관리의 Bluetooth 목록에서 Mac 연결을 켜세요.
  • Mac에서 Windows 조작: Windows의 기기 관리 → 다른 방법으로 연결 → 블루투스에서 마우스·키보드 입력 받기를 켜세요. Mac에서 입력 방향을 마우스·키보드 입력 보내기로 바꾼 뒤 목록에서 Windows PC를 선택하세요.

Mac은 입력을 받을 때 손쉬운 사용 권한, 보낼 때는 입력 모니터링 권한도 필요해요. 마우스·키보드, 텍스트 클립보드, 파일·폴더 전송을 지원해요.

Mac 화면·창 공유는 Wi-Fi·LAN 전용이에요. Bluetooth로는 화면·창을 볼 수 없어요.

화면 녹화 권한도 켜야 하나요?

마우스·키보드만 쓸 때는 필요 없어요. Windows에서 Mac 화면·창을 보거나, Mac에서 OneMouse로 스크린샷을 찍을 때 해당 Mac에서 허용하세요.

Mac의 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 OneMouse를 켜세요. macOS 버전에 따라 항목 이름이 다를 수 있어요. 원격 화면 안내

다른 Windows PC 연결하기

마우스·키보드가 꽂힌 PC에서 시작해요. 같은 공유기에 연결하면 로그인 없이 번호로 연결할 수 있어요. Google 계정으로 다른 PC 연결하기 · Bluetooth로 연결하기 (베타)

  1. 두 PC에서 기기 관리 열기

    같은 공유기에 연결한 두 Windows PC에서 OneMouse를 설치·실행하고, 왼쪽 메뉴에서 기기 관리를 여세요.

  2. 상대 PC에서 번호 확인

    제어할 PC에서 기기 관리 → 다른 방법으로 연결 → 이 PC의 QR·인증번호로 가서 6자리 번호를 확인하세요.

  3. 내 PC에서 상대 PC 선택·연결

    내 PC의 기기 관리 → 다른 방법으로 연결에서 상대 PC를 선택하고 코드를 넣으세요. 연결 상태를 확인하고 필요하면 연결 스위치를 켜세요.

  4. 다른 PC 방향으로 마우스 넘기기

    배치 편집기에서 상대 PC를 실제 놓인 위치에 두고, 그쪽 가장자리로 마우스를 밀어 보세요.

두 Windows PC를 Bluetooth로 연결하기 (베타)
  1. 두 PC를 Windows의 Bluetooth 설정에서 먼저 페어링하세요.
  2. 받는 PC의 OneMouse에서 기기 관리 → 다른 방법으로 연결 → Bluetooth를 열고 마우스·키보드 입력 받기를 선택하세요. Bluetooth가 꺼져 있으면 켜세요.
  3. 보내는 PC의 같은 메뉴에서 필요하면 마우스·키보드 입력 보내기로 바꾼 뒤, 목록에서 받는 PC의 연결 스위치를 켜고 기기 배치를 맞추세요.

Google 로그인이나 공유기는 필요 없어요. 원격 화면을 보려면 같은 네트워크를 사용하세요.

상대 PC가 보이지 않나요? 두 앱이 켜져 있고 같은 네트워크인지 먼저 확인하세요. 연결 문제 해결 보기

연결됐는데 커서가 안 넘어가나요?

  1. 배치 방향: Windows의 기기 배치가 실제 놓인 방향과 같은지 확인하세요.
  2. 진입 통로: 배치에서 표시한 화면 가장자리 구간으로 커서를 밀어 보세요.
  3. 받는 기기의 권한: Android는 OneMouse 접근성, Mac은 손쉬운 사용을 확인하세요.

Google 계정으로 내 기기 찾기

Windows, Mac, Android의 OneMouse 앱에서 사용할 수 있어요. 양쪽 앱을 최신 버전으로 업데이트하고, 인터넷에 연결한 뒤 같은 Google 계정으로 로그인하세요.

Windows ↔ Windows

두 PC의 기기 관리에서 로그인하세요. 마우스가 연결된 PC에서 상대 PC를 고르고, 필요하면 연결 스위치를 켜세요.

Windows → Mac

Windows의 기기 관리와 Mac 앱의 기기 관리에서 로그인하세요. Windows 기기 목록에서 Mac을 골라 연결하세요. Windows 로그인 버튼 위치 · Mac에서 입력을 받으려면 손쉬운 사용을 허용하세요.

Windows → Android

Windows의 기기 관리와 Android의 OneMouse 홈에서 로그인하세요. 폰의 등록된 PC에서 내 PC를 선택해 연결하고, Android의 접근성을 켜세요.

허용 요청이 나오면 상대 기기에서 확인하세요. 로그인은 기기를 찾는 방법이에요. 실제 연결 가능 여부와 쓸 수 있는 기능은 네트워크와 기기에 따라 달라요. 기기가 안 보일 때

모바일 → PC

폰에서 고른 파일과 텍스트를 PC로 보냅니다.

LAN으로 보낼 때는 모바일 앱 홈에서 기본 PC를 선택하고 페어링·연결 상태를 확인하세요. 파일은 전송 탭 또는 Android 공유 메뉴에서, 텍스트는 선택 메뉴의 OneMouse to PC에서 보낼 수 있습니다.

텍스트 보내기: 화면으로 따라 하기

이미지를 누르면 크게 볼 수 있어요. 먼저 폰의 OneMouse 홈에서 보낼 PC가 연결됐는지 확인하세요.

OneMouse to PC가 메뉴에 안 보이나요?

파일 보내기

  1. 모바일 앱의 전송 탭에서 파일 선택해서 PC로 보내기를 누릅니다.
  2. 보낼 파일을 고르면 선택된 PC로 바로 전송됩니다.
  3. 사진·문서 앱에서는 공유를 누른 뒤 OneMouse를 선택해도 됩니다.

텍스트 보내기

  1. Android에서 텍스트를 길게 눌러 선택하고 더보기를 엽니다.
  2. OneMouse to PC를 누르면 PC 클립보드로 전송됩니다.
  3. 처음 보이지 않으면 앱 관리에서 OneMouse를 한 번 켠 뒤 다시 선택하세요.

PC에서 받은 파일 찾기

PC의 설정 → 일반 → 파일 전송 → 수신 파일 저장 위치에서 폴더 변경으로 저장 위치를 정하고 폴더 열기로 확인하세요. 메인·서브 PC 모두 사용할 수 있습니다.

저장 위치·폴더 문제 해결

키보드 단축키와 적용 조건.

아래 PC 단축키는 기본값입니다. PC의 설정 → 단축키에서 키 조합을 바꾸거나 각 항목·전체를 끌 수 있습니다. 키를 바꿨다면 설정한 조합을 사용하세요.

Windows 앱의 기본 단축키

기본 단축키 동작·조건
Ctrl+Alt+1~9 메인 PC: 목록의 해당 기기에 입력 제어를 연결합니다. 현재 제어 중인 기기의 같은 번호를 다시 누르면 제어를 해제합니다.
Ctrl+Alt+Shift+1~9 메인 PC: 해당 기기의 원격창을 열거나 이미 열린 창을 앞으로 가져옵니다. 다시 눌러도 닫지 않습니다. 연결 단축키와 같은 LAN 기기 번호를 사용하며 Bluetooth 기기는 번호 배정에서 제외합니다.
Ctrl+Alt+D 빠른 드롭존 보이기 / 숨기기.
Ctrl+Alt+S 제어 중인 Windows PC·Mac·Android의 화면에서 영역을 선택해 메인 PC로 받습니다. 다른 기기를 제어하지 않을 때는 내 PC를 캡처합니다. 양쪽 앱의 기능 지원과 대상 기기의 캡처 권한이 필요합니다.
Ctrl+Alt+V 메인 PC: 인증번호가 포함된 폰 알림이 PC에 떠 있는 동안 해당 번호를 복사합니다. 폰 알림 전송을 먼저 켜야 합니다.
Ctrl+V 다른 PC에서 복사한 공유 파일을 이 PC로 받아 붙여넣습니다. 받을 공유 파일이 없으면 일반 붙여넣기를 사용합니다.
Ctrl+Alt+Backspace 메인 PC: 다른 기기 제어 중 커서를 내 PC의 모니터 중앙으로 즉시 되돌립니다.

Android를 직접 제어할 때

아래는 Android로 전달하는 입력 조합입니다. PC 앱의 단축키 설정 표와 구분하며, 텍스트 편집은 대상 앱·입력창의 지원에 따라 달라집니다.

PrintScreen Android 11 이상: 직접 제어 중인 폰 화면을 찍어 PC로 보냅니다. 접근성 권한이 필요합니다.
Alt+Shift+↑ / Alt+Shift+↓ Android 화면 밝기 올리기 / 내리기. 시스템 설정 변경 권한이 필요합니다.

Windows 키보드로 Mac을 제어할 때

기본 Windows 단축키 매핑에서는 Ctrl이 Command, Alt가 Option으로 전달됩니다. Mac 앱 설정의 키보드 수정키 매핑을 Mac 원래 방식으로 바꿀 수 있습니다. 위 Windows 앱 단축키의 Ctrl을 Command로 바꾸라는 의미는 아닙니다.
