Terms

이용약관

OneMouse는 Windows와 Android·다른 Windows PC·macOS 13+ Apple Silicon Mac을 연결합니다. 아래 약관은 지원 플랫폼의 연결과 사용 조건을 설명합니다.

시행일: 2026년 8월 5일

01

서비스 목적

OneMouse는 사용자가 소유하거나 사용 권한이 있는 Windows PC와 Android, 페어링된 Windows PC 또는 Mac을 연결하는 로컬 생산성 도구입니다.

02

사용자의 책임

  • 사용자는 Android 접근성을 직접 관리합니다. Mac 손쉬운 사용·화면 녹화와 macOS 15+ 로컬 네트워크 권한도 기능에 맞게 허용해야 합니다.
  • 전송하는 파일과 클립보드 내용에 대한 책임은 사용자에게 있습니다.
  • 회사망, 공용망, 보안 정책이 있는 환경에서는 관리자 정책을 따라야 합니다.

03

Free / Pro

Android 앱의 Free / Pro 제공 범위와 구매 조건은 앱 및 각 스토어에 표시된 최신 안내를 따릅니다. Windows 앱은 결제를 직접 처리하지 않으며, Mac 앱에는 별도의 Pro 구매 절차가 없습니다.

04

지원 환경

OneMouse는 Windows 10/11에서 연결을 시작하고 Android, 다른 Windows PC, macOS 13+ Apple Silicon Mac을 이어 씁니다. Mac 앱은 Developer ID로 서명·공증해 배포합니다.

05

광고와 결제

광고와 스토어 결제는 해당 Android 배포판에서만 제공될 수 있으며 각 스토어의 약관과 정책이 적용됩니다. Windows와 Mac 앱은 Google Mobile Ads 또는 Google Play 결제를 사용하지 않습니다.

06

지원 범위

Windows↔Android와 Windows↔Windows는 LAN/Bluetooth 연결을 지원합니다. Windows↔Mac은 LAN 연결을 지원하며 Mac 화면·창 공유도 LAN 전용입니다. Mac Bluetooth와 USB/ADB 연결은 사용자용 지원 범위에 포함되지 않습니다.

07

보증의 제한

OneMouse는 네트워크, 운영체제 권한, 보안 프로그램, 기기 제조사 정책의 영향을 받을 수 있습니다. 모든 환경에서 중단 없는 연결 또는 파일 전송을 보장하지 않습니다.

08

약관 변경

기능, 결제 방식, 배포 정책이 변경되면 본 약관도 갱신될 수 있습니다. 중요한 변경 사항은 웹사이트 또는 앱 배포 페이지를 통해 안내합니다.
